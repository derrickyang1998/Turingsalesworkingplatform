# 主流社媒平台档案与商业化路径 v1.0

> 用途：帮助商务新人先理解客户生意，再完成平台、达人、内容与转化路径的第一轮判断。本文件是动态平台知识参考，不是效果承诺、固定报价表或替代运营终审的执行清单。

## 0. 使用方法与证据边界

### 0.1 先问生意，再选平台

统一决策链：**客户目标 → 目标市场与受众 → 产品购买阻力 → 平台角色 → 达人类型 → 内容证据 → 商业合作形式 → 链接与转化路径 → 指标与归因 → 合规和风险**。

- **A｜平台官方事实**：来自平台官方 Help、Policy、Business 或 Creator 页面，可用于解释机制；仍须核对目标市场、账号、类目和资格。
- **B｜图灵内部事实**：来自可追溯 CRM、财务或项目复盘；必须带样本、市场、品类、格式、周期和证据位置。
- **C｜图灵经验判断**：用于形成条件式建议，不可包装成普遍规律。
- **D｜项目假设**：为本项目待验证的选型、内容或转化假设，必须写明验证方法与停止条件。
- **E｜外部线索**：来自尚未完成官方或内部交叉核验的外部资料，仅用于触发核验，不得直接写入对客承诺。

来源等级 A–E 只表示结论来源，不等同于**达人证据置信度 H/M/L**，也不等同于**达人推荐等级 A–D**。本文件各平台第 14 项中的内联官方链接均为受治理记录，适用与 [07 事实核验台账](07-平台事实与来源维护台账-v1.0.md) 相同的 Owner、核验日期、状态和复核周期；A 级结论发生变化时，须在 07 登记或交叉引用稳定 `claim_id` / `source_id` 后才能发布。台账中的来源行数仅表示已登记记录数，不能证明所有事实字段均已覆盖。

### 0.2 职责边界

- 商务负责客户信息补齐、平台解释、达人初筛、推荐逻辑说明和重大风险识别。
- 红人运营负责最终达人名单、执行可行性、档期、报价、权利和交付风险的专业复核。
- 策略负责人维护平台事实；法务、财务和广告投放负责人分别复核合规、付款税务和广告权限。

### 0.3 主要受众的教学规则

本手册只描述**市场与受众倾向**，不固化全球年龄占比、月活、使用时长或购买力数字。正式提案前必须在目标国家的广告规划工具、平台后台或有口径的权威资料中重新核验，并记录日期、可触达定义、样本和限制。

## YouTube

**层级：核心平台｜教学角色：Proof＋Search**

1. **平台定位和用户心智**：用户既会主动搜索“怎么选、怎么用、是否值得买”，也会通过首页、相关推荐和Shorts被动发现。C｜图灵经验判断：当产品高客单、功能复杂、需要演示或比较时，YouTube常适合承担证据与信任角色；是否优先必须结合市场、竞争、创作者供给和历史转化验证。
2. **平台特性**：搜索、推荐、订阅和长短内容并存；长内容可沉淀搜索资产，Shorts适合拓新或把核心证据切成更低门槛入口。A｜平台官方事实：自2024-10-15起上传的方形或竖屏视频最长3分钟可被归类为Shorts，上传日期、画幅及版权仍会影响分类和可播放性。

## Discord

**层级：特殊场景平台｜教学角色：Owned Community＋Retention**

1. **平台定位和用户心智**：由服务器、频道、角色、活动、语音/直播和机器人构成自有社区，核心是成员关系、留存、客服与共创。C｜图灵经验判断：适合已有用户基础、会员/开发者/游戏/硬件社区和长期运营，不是通用达人播放量采购平台。
2. **平台特性**：A｜平台官方事实：服务器可通过邀请链接加入，并可启用Community及角色/权限；符合条件的服务器可申请Discovery或使用申请制加入，具体功能有资格与分阶段开放限制。C｜图灵经验判断：品牌拥有运营责任但不拥有成员，服务器安全、Moderator、机器人权限和响应SLA比单次内容曝光更重要。
3. **主要受众**：倾向覆盖主动加入特定品牌、产品、游戏、开发或兴趣社区的人群；成员国家、语言、角色、活跃、付费状态和隐私同意需在服务器内合规统计。
4. **发现机制**：A｜平台官方事实：有效Invite Link可打开加入流程，并可设置有效期、次数或权限；Server Member Applications支持邀请制、申请制与可发现等加入模式，但正在分阶段推出。Server Discovery须启用Community并满足成员数、服务器存续、活跃、安全与2FA等条件。C｜图灵经验判断：多数品牌项目先通过合规邀请、既有创作者/品牌渠道、社区活动与成员推荐获客，不得用未经请求的批量私信。
5. **内容类型和原生语法**：公告、主题频道、FAQ、Stage/活动、直播、客服工单、机器人流程、会员内容和共创。内容是持续服务与治理，不以单条播放量为核心。
6. **内容对应的商业合作形式**：品牌自有服务器建设、创作者引流到社群、大使/Moderator计划、AMA/活动、客服协作、会员、Beta测试和共创；创作者发布在外部平台的部分另按该平台规则签约。
7. **常规商业合作要求**：确认服务器Owner、Moderator权限、成员同意、合同主体、搭建/运营范围、响应SLA、活动频次、内容修改、数据保留、商业披露、邀请/站外链接、数据权限、机器人/素材权、排他、危机/退出/取消和付款。
8. **链接能力**：A｜平台官方事实：已核验可点击——有效Discord Invite Link会打开加入服务器流程；是否可加入仍受链接有效期、次数、封禁、权限及服务器加入模式限制。服务器消息中的外部链接与机器人按钮：未核验—不得对客承诺。自然邀请与外部平台付费获客不同；链接仅面向自愿加入成员，不得以批量私信发送。
9. **转化路径**：外部创作者/品牌内容→自愿邀请→服务器入门/角色→教育/客服/活动→站外会员或商品页→支付/续费；也可购买后→入群→服务→留存/复购。Discord本身承担关系与留存，不强行归为首次触达。
10. **创作者合作和付费放大**：A｜平台官方事实：合资格 Server Subscription 可在桌面端或 iOS 购买，Android 当前不支持购买；iOS 展示价格包含平台费用。创作者变现资格包括年满18岁、邮箱已验证、启用2FA及账号保持良好状态，且变现内容不得以推广第三方业务为主要目的。因此它不是通用品牌商品结账或代销入口；Server Shop/App Subscription 也不得从单一服务器类推。C｜图灵经验判断：合作重点是创作者带来合格成员、主持活动或担任大使；Discord没有已核验的通用“达人帖子白名单放大”，未核验—不得对客承诺。外部引流平台的自然发布和广告权在相应平台另行授权。
11. **数据和指标定义**：A｜平台官方事实：Server Insights仍属有限能力，通常要求Community Server、超过500名成员及相应权限，可查看Growth & Activation、Engagement和Audience等匿名汇总指标。C｜图灵经验判断：另记录合格加入、激活、周/月活跃成员、关键频道参与、活动到场、问题解决时间、留存、流失、会员/站外转化和安全事件；不用通用红人播放量评分法。
12. **产品、客户目标和达人适配**：适合会员、游戏、开发者工具、硬件早期用户、客服与复购；创作者需有社区召集与治理能力。一次性广覆盖、无社区运营人力或无法提供持续价值的项目不适用。
13. **风险、披露、版权和限制**：A｜平台官方事实：Discord禁止未经请求的批量消息、虚假互动和人工放大成员数。必须处理未成年人、隐私、权限泄露、诈骗/仿冒、Moderator行为、机器人权限、版权和危机升级。
14. **官方来源、核验日期和适用市场**：核验日期：2026-09-09；建议复核日：2026-12-08；Owner：策略负责人。适用市场：Community Guidelines覆盖所有账号、服务器和App；Discovery、Applications、Insights和Monetization依服务器、设备、账户、地区、年龄、规模与权限。来源：[Invites 101](https://support.discord.com/hc/en-us/articles/208866998-Invites-101)、[Server Member Applications](https://support.discord.com/hc/en-us/articles/29729107418519-Server-Member-Applications)、[Enabling Server Discovery](https://support.discord.com/hc/en-us/articles/360030843331-Enabling-Server-Discovery)、[Enabling Community](https://support.discord.com/hc/en-us/articles/360047132851-Enabling-Your-Community-Server)、[Server Insights FAQ](https://support.discord.com/hc/en-us/articles/360032807371-Server-Insights-FAQ)、[Server Subscriptions for Members](https://support.discord.com/hc/en-us/articles/4415163187607-Server-Subscriptions-for-Members)、[Monetization Policy](https://support.discord.com/hc/en-us/articles/10575066024983-Monetization-Policy)、[Discord Community Guidelines](https://discord.com/guidelines)。

**何时启用 / 何时不适用**：品牌能持续提供成员价值、配置Owner/Moderator/客服、建立安全和数据规则时启用；若只想购买曝光、批量私信、虚增人数或项目结束后无人治理，则不启用。

### 4.1 统一转化链与归因最小集

统一转化链：**内容触达 → 有效观看或互动 → 主页/描述/贴纸/商品标签/评论等入口 → 平台店铺或站外落地页 → 商品详情 → 加购或留资 → 支付 → 退货期结束 → 有效收入与毛利**。

每个项目至少记录：平台/账号/内容ID、自然或付费、市场、链接位置、UTM/联盟ID/折扣码、点击、落地页Sessions、加购/表单、支付、取消/退货、净收入、媒体/达人/产品成本、归因窗口和数据提取日期。无法直接归因时，将品牌搜索、直接流量、问卷和VOC标为辅助证据，不冒充确定订单。

### 4.2 四类路径写法

- **站内闭环**：只有在目标国家、账号、商家、达人、类目和支付界面完成真实下单测试，且支付未跳到商家/零售商站点时，才写“内容/直播→平台商品入口→平台内支付”。商品入口存在不等于站内结账；一旦跳商家站即按站外转化记录。
- **站外转化**：内容→可点击入口→带UTM/联盟ID的独立站或零售页→支付；同时检查移动加载、币种、库存、支付和Cookie同意。
- **辅助归因**：折扣码、品牌搜索、直接流量、客户调研、评论意向用于补充判断，不能与可匹配订单重复计功。
- **长决策转化**：内容→搜索/保存/比较/多次触达→数天或数周后留资/成交；设7/30/90天等适合产品周期的观察窗口，具体窗口写入项目假设。

## 6. 项目级平台与商业化核验清单

### A. 客户生意与受众

- [ ] 记录客户主目标：认知、种草、搜索占位、引流、销售、线索、VOC、留存或复购；区分主次。
- [ ] 记录目标国家/地区、语言、币种、销售渠道、上线期、库存、物流、售后和预算。
- [ ] 明确产品客单价、购买频率、解释复杂度、可视化速度、合规/功效风险和决策周期。
- [ ] 用目标市场实时工具核验受众；记录来源、日期、可触达定义和限制，不引用无口径全球数字。

### B. 平台角色与内容假设

> 本节 A–G 只是项目核验清单的章节字母，不是来源等级；每条结论仍须另标来源等级 A–E。

- [ ] 为每个平台写一个角色，而不是仅写平台名；说明主平台、辅助平台与不选平台的理由。
- [ ] 内容采用平台原生语法，写明格式、Hook、证据、异议处理、CTA和内容寿命。
- [ ] 至少设计一个对照：达人类型、内容角度、平台或CTA；写清胜出指标和停止条件。
- [ ] 平台/内容建议标注 A 官方事实、B 可追溯内部事实/政策、C 条件式内部经验/方法、D 项目假设或 E 外部线索；不得与达人证据置信度 H/M/L、达人推荐等级 A–D 混用。

### C. 达人与合作要求

- [ ] 商务完成第一轮账号/身份、目标市场受众、近20—30条稳定性、商单、品牌安全与异常筛查。
- [ ] 红人运营完成最终达人名单、档期、报价、沟通、制作、风险和执行可行性复核。
- [ ] 合同主体、收款主体、税费、币种、报价有效期和付款节点一致；异常升级。
- [ ] 交付物、修改轮次、发布时间、保留期、数据回传、竞品排他、取消/延期/补救完整。

### D. 链接、Shop与站内能力（逐项实测）

- [ ] 在目标账号截图记录链接位置、是否可点击、自然/付费差异和核验日期。
- [ ] 核验国家、账号类型、粉丝/年龄、商家、达人、类目、广告账户及平台计划资格。
- [ ] 商品标签、Shop、LIVE、Catalog、Creator Marketplace/Partnership工具分别核验，不相互推定。
- [ ] 跳转后的移动落地页、语言/币种、加载、Cookie、库存、支付、优惠码和客服链路完成测试订单或表单测试。

### E. 追踪、数据与归因

- [ ] 每个链接有唯一UTM/联盟ID；每个达人/平台有唯一折扣码或可匹配标识（若业务允许）。
- [ ] Pixel/CAPI/服务器回传、平台内归因和CRM Lead Source已由有权限人员配置并验证。
- [ ] 指标写明平台、格式、自然/付费、定义、分母、时间窗、提取日期和数据证据位置。
- [ ] 订单按支付、取消、退货和净收入分层；联盟佣金与折扣、广告归因去重。
- [ ] 长决策产品设置7/30/90天或更合适窗口，并记录品牌搜索、直接流量和问卷等辅助证据。

### F. 披露、版权、素材与广告权

- [ ] 现金、赠品、借用、佣金、大使等利益关系按平台工具与当地法规披露。
- [ ] 音乐、字体、图片、场地、第三方人员、产品声明和限制行业完成上线前检查。
- [ ] 自然发布、素材下载、剪辑、字幕/翻译、地域、期限、媒体、转授权、肖像/声音、AI处理逐项授权。
