# 图灵集市商务新人产品—平台—达人—内容匹配案例库 v1.0

- **版本：**v1.0（受控试运行）
- **发布日期：**2026-09-08
- **适用对象：**商务新人、商务主管、参与方案评审的策略与运营同事
- **用途：**产品方案训练、题库、Roleplay、面试校准和销售交接练习。
- **关联文件：**[基础培训手册](01-商务新人海外红人营销基础培训手册-v1.0.md)；[平台档案与商业化路径](02-主流社媒平台档案与商业化路径-v1.0.md)。

> **使用声明：**本文件的八个正式案例均为**教学模拟**，用于训练条件式判断；除非另有经批准、可追溯的证据记录，不得把它们说成客户证明、可复制业绩或 ROI 承诺。行业只提供起始假设，不是“行业＝平台”的公式。链接资格、Shop、创作者合作工具、广告授权和平台能力均以《平台档案》及目标市场、账号、类目当期实测为准。

## 0. 使用方式与责任边界

统一决策链为：**客户目标 → 目标市场与受众 → 产品购买阻力 → 平台角色 → 达人类型 → 内容证据 → 商业合作形式 → 链接与转化路径 → 指标与归因 → 合规和风险**。

商务的输出是条件式的第一轮推荐、达人初筛和重大风险识别；运营拥有最终达人质量、报价、档期、样品可达性、内容制作与上线风险的复核确认权。信息不足时，合格答案是追问、缩小试点或暂停敏感传播，不是补一个看似完整的结论。

### 0.1 产品诊断卡（所有案例的固定共同入口）

先完整填写下列字段，才可选平台与达人。字段名称不得删改；“未知”应写成待补信息和 Owner。

| 固定字段 | 诊断问题 |
|---|---|
| 市场 | 首轮验证的国家/地区、语言、法规和零售环境是什么？ |
| 受众 | 谁在什么情境下购买；谁使用、谁付款、谁否决？ |
| 客单价 | 含税/运费后价格带与当地购买力如何？ |
| 决策周期 | 冲动、数天比较，还是数周/月的长决策？ |
| 品牌阶段 | 当前主要约束是验证、认知、教育、转化还是放大？ |
| 购买阻力 | 用户不买是不了解、不信任、不会用、嫌贵、担忧安全，还是承接摩擦？ |
| 可视化速度 | 优势在 3 秒、30 秒、3 分钟、30 天还是不可见？ |
| 解释深度 | 用户需要什么程度的教程、对比、数据或专家解释？ |
| 信任要求 | 用户需要真实使用、长期体验、专业人士、第三方证据还是售后保证？ |
| 合规风险 | 披露、功效/安全、隐私、儿童、当地法规、版权等风险是什么？ |
| 样品物流 | 样品成本、重量、危险品、保险、回收、维修和可供数量如何？ |
| 销售渠道 | 独立站、亚马逊、零售商、经销商、线索销售或站内店铺？ |
| 主目标 | 本轮只验证哪一个主假设：发现、证据、内容资产、点击、合格线索或订单辅助？ |
| 预算 | 总成本范围要含达人、样品、物流、权利、服务、媒体、税费与不可预见项；当前报价待运营询价。 |
| 时间窗 | 从寄样、审核到发布、数据冻结可用多久？ |
| 已有数据 | 有哪些后台、销售、评论、搜索、退货、CRM 或历史素材；口径、日期、局限是什么？ |

### 0.2 通用作答约束

1. 平台角色与当期链接资格按《[平台档案](02-主流社媒平台档案与商业化路径-v1.0.md)》的[快速比较矩阵](02-主流社媒平台档案与商业化路径-v1.0.md#1-十二平台快速比较矩阵)、[链接与转化路径矩阵](02-主流社媒平台档案与商业化路径-v1.0.md#4-链接与转化路径矩阵)和项目级核验清单引用；本案例库不重复动态平台事实。
2. 每位候选达人先过硬门槛：目标市场错位、数据异常、竞品冲突、资质/授权缺失或重大品牌安全风险，均不能靠评分补偿。再按基础手册的质量与证据规则完成初筛，并交运营终审。
3. 内容必须写出“痛点钩子 → 使用/测试 → 可见结果 → 条件与局限 → CTA”。敏感品类的体验内容不等于科学、医疗或安全证据。
4. 每个链接采用唯一 UTM/联盟 ID 或可匹配折扣码（业务允许时），记录内容 ID、自然/付费状态、数据源、冻结日、归因窗口、退款/取消处理和数据 Owner。辅助指标不能冒充确定订单。

## 1. 统一评分与判定

### 1.1 每个案例 10 分

| 维度 | 分值 | 满分表现 |
|---|---:|---|
| 购买阻力与变量 | 2 | 写出市场、受众、主目标、阻力和至少一个会改变结论的条件。 |
| 平台分工 | 2 | 主/辅助平台分别承担不同漏斗任务，且说明不选其他平台的原因或条件。 |
| 达人及核验 | 2 | 说清原型、硬门槛、可核验证据及运营最终复核事项。 |
| 内容证据和 CTA | 2 | 用可观察证据回答阻力，CTA、链接路径和承接页逻辑完整。 |
| 合规/物流/归因 | 2 | 写出关键红线、样品/权利/物流动作，以及分母、窗口和数据 Owner。 |

### 1.2 统一扣分、红线与阅卷法

- **只按行业选平台：扣 2 分。**例如“储能必做 YouTube”而未写购买阻力、市场、预算或内容任务。
- **只按粉丝量选达人或承诺 ROI：扣 2 分。**粉丝量与历史数字可以作为筛选证据，不能替代受众、证明能力、品牌安全和当期可行性；任何确定 ROI、爆款、销量承诺均不合格。
- **漏掉医疗、安全、隐私红线：本题不合格。**阅卷人停止计分，标记为“需重新培训”；补写后才可复测。
- 允许不同方案得分，只要先说明条件、证据和风险，且不把未核验平台能力写成确定交付。运营终审边界漏写时，“达人及核验”最多 1 分。

## 2. 3C：$39 手机支架促销测试

### 2.1 教学情境与产品诊断卡

**情境：**美国市场的 $39 手机支架，三周后促销，预算 $12K；客户希望验证桌搭、通勤与手机摄影场景中，何种演示最能带来有效点击或加购信号。

| 固定字段 | 本案填写 |
|---|---|
| 市场 | 美国；英语内容；独立站促销页与库存状态待客户确认。 |
| 受众 | 桌搭办公、通勤导航和轻量手机摄影用户；购买者多为使用者。 |
| 客单价 | $39，低摩擦购买，但需考虑运费、折扣和替代品。 |
| 决策周期 | 小时至数天；促销窗口压缩比较时间。 |
| 品牌阶段 | 转化/验证：验证场景与入口，不测试全部品牌定位。 |
| 购买阻力 | “是否稳、是否好收纳、是否适配我的手机/场景”，以及低价同类替代。 |
| 可视化速度 | 3–30 秒可展示吸附、角度、收纳和使用切换。 |
| 解释深度 | 低；兼容性、限制条件需明确。 |
| 信任要求 | 真实日常使用与不夸张的稳定性演示。 |
| 合规风险 | 商业披露、竞品排他、无线/磁吸相关表述准确性。 |
| 样品物流 | 小件、可多寄，但颜色/SKU、库存和寄达时间要锁定。 |
| 销售渠道 | 独立站；落地页、支付、折扣和退货政策待检查。 |
| 主目标 | 验证场景化短内容是否带来有效点击/加购信号。 |
| 预算 | $12K 教学假设；先留出达人、寄样、授权、服务与必要测试成本，运营询价后再定组合。 |
| 时间窗 | 三周；优先已能快速交付且可核验受众的创作者。 |
| 已有数据 | 待提供：落地页 CVR、库存、过往素材和目标场景评论。 |

### 2.2 示范答案

- **主平台：**[TikTok](02-主流社媒平台档案与商业化路径-v1.0.md#tiktok)，承担快速场景发现与多创意测试；不是因为“3C 就应做 TikTok”。
- **辅助平台：**[Instagram](02-主流社媒平台档案与商业化路径-v1.0.md#instagram)，承担桌搭/通勤的社交证明与主页、Story 等补充入口；其具体入口必须项目实测。
- **平台分工：**TikTok 测试三种痛点钩子（通勤导航、桌搭角度、手机拍摄）；Instagram 以同一核心证据做更完整的视觉场景与保存/分享观察。若出现明显兼容性追问，再追加短教程或 FAQ，不机械复制同一条片。
- **达人原型与核验：**美国桌搭、通勤、手机摄影或生产力微型创作者；核验受众国家、近期同类演示质量、评论中的购买意图、商单披露、数据稳定性、竞品冲突和按期能力。排除只做开箱、无法清楚展示安装/稳定性，或受众明显非美国的账号。运营确认最终名单、报价、档期和样品地址。
- **内容证据：**“骑车/开车前手机无处固定”或“桌面拍摄角度不稳”钩子 → **仅在静止状态安装、设置和调整** → 不同动作下的稳定/收纳可见结果 → 说明适配机型、表面/路况等限制 → CTA。拍摄不得在驾驶/骑行中触摸、调整或操作设备；须遵守当地道路规则。
- **链接与 CTA：**“查看促销页并确认你的机型兼容性”；每达人分配 UTM 或可匹配码。链接位置、点击性和账户资格按[平台档案链接矩阵](02-主流社媒平台档案与商业化路径-v1.0.md#4-链接与转化路径矩阵)在账号上实测；若未通过，就把主页访问或码使用设为辅助证据，不承诺直接点击。
- **指标：**主指标为有效点击或加购（先定义事件与去重）；同时看前段留存、完整演示出现率、主页访问/入口点击。数据 Owner 为客户电商后台；窗口覆盖促销期并记录冻结日、折扣、退款和取消。
- **预算假设：**$12K 不把全部成本压在单条长视频；采用有限的场景创作者与可比较创意，预留样品、授权、服务和失败替补。实际人数和费用需运营拿到当期报价后确认。
- **风险：**三周内寄样/审核延误、促销断货、兼容性投诉、未披露、落地页移动端摩擦和码泄漏；**安全停止条件：**任何需要驾驶/骑行中拍摄、触摸或调整手机/支架的脚本或镜头一律停止，改为静止状态演示，并遵守当地道路规则。漏写或违反该安全停止条件，按第 1.2 节安全红线判定本题不合格。
- **替代方案：**若客户已有可信的摄影/桌搭长评测素材且核心问题变为“与特定设备兼容”，可由 [YouTube](02-主流社媒平台档案与商业化路径-v1.0.md#youtube)教程承担解释，TikTok 只做发现；前提是内容窗口与预算允许。

### 2.3 条件变化题、学员任务与阅卷要点

**条件变化题：**把同一产品改为高价摄影主机，价格显著提高、用户要比较画质/镜头/稳定系统，决策周期为数周。推荐如何变？

**模型答案：**将 YouTube 的深评、对比或教程列为证据主场，短视频用于发现与导流；达人转为有可核验实测流程的摄影/器材评测者；CTA 引到规格、比较和购买页；时间窗与预算应覆盖寄样、深度制作和长窗口归因。不是“价格高所以一定 YouTube”：若用户无搜索需求、产品只能即时演示或库存极少，应重新缩小测试。

**可接受替代：**以 Instagram 专业摄影 Carousel/Story 做社交证明，但必须补充可检验的样张条件、设备设置和链接承接，并说明为什么不需要长评测。

**学员任务：**用 12 分钟完成本案的两平台分工、三项达人核验、一个内容分镜和一条归因路径；再用 3 分钟回答条件变化题。

**阅卷重点：**满分必须区分低价配件与高价主机，写出兼容性和促销承接；“3C 都做 TikTok”触发扣分。

## 3. 储能：$1,499 户外电源十周验证

### 3.1 教学情境与产品诊断卡

**情境：**$1,499 户外电源，预算 $40K，十周窗口，面向美国 RV、露营和备电场景。客户要验证真实负载、充电、噪音和连续使用证据是否降低高客单购买不确定性。

| 固定字段 | 本案填写 |
|---|---|
| 市场 | 美国；当地电气、安全、运输及售后条件待项目核验。 |
| 受众 | RV、离网生活、露营、应急备电用户；家庭购买可能有共同决策者。 |
| 客单价 | $1,499，高客单，需结合保修、运输与替代方案比较。 |
| 决策周期 | 数周至数月，用户会比较容量、功率、重量和安全。 |
| 品牌阶段 | 教育/考虑；本轮验证证据格式，不承诺成交。 |
| 购买阻力 | 不信容量与带载、担忧安全/噪音、觉得重/贵、担心售后。 |
| 可视化速度 | 单项带载可快速演示；可靠性与续航需连续记录。 |
| 解释深度 | 高：输入输出、使用条件、限制和比较方法。 |
| 信任要求 | 真实长期使用、可复核测试方法；安全材料先审。 |
| 合规风险 | 电气/安全宣称、危险品运输、商业披露、环境或应急夸大。 |
| 样品物流 | 重件/电池类；运输限制、保险、回收、损坏责任和样品数量先定。 |
| 销售渠道 | 独立站或零售商待确认；保修、库存和售后页需可承接。 |
| 主目标 | 验证深度实测是否产生合格观看质量、比较页访问和高意图问题。 |
| 预算 | $40K 教学假设；费用还应覆盖重货运输、保险、测试准备、权利和延期风险。 |
| 时间窗 | 十周；适合预留寄样、连续使用、审核与补拍。 |
| 已有数据 | 待提供：认证/测试材料、常见问题、退货原因、库存和售后能力。 |

### 3.2 示范答案

- **主平台：**[YouTube](02-主流社媒平台档案与商业化路径-v1.0.md#youtube)，作为可检索的深度证明与比较假设。
- **辅助平台：**[Instagram](02-主流社媒平台档案与商业化路径-v1.0.md#instagram)用于 RV/露营生活方式中的场景化社交证明；若要扩展短钩子，TikTok 仅在强演示素材已经成立时再考虑。
- **平台分工：**YouTube Dedicated/深度整合展示预设的负载、充电、噪音、连续使用及边界；Instagram 展示“为何在一次真实出行中有用”，引向完整证据，不把同一长评测缩成无条件的广告。
- **达人原型与核验：**美国 RV、太阳能、离网生活、露营或具备相关技术表达能力的创作者。核验真实使用场景、测试透明度、受众国家、既往安全表达、品牌冲突、内容保留期和重货接收能力。运营确认样品协议、报价、档期、地址、保险及最终测试者。
- **内容证据：**真实用电需求 → 列明测试设备/功率与起始条件 → 带载、充电、噪音、连续使用记录 → 展示重量、天气、容量衰减或无法覆盖的条件 → CTA 进入规格/比较/保修页面。
- **链接与 CTA：**“查看完整规格、保修和适用场景，再决定是否适合你的负载”；采用可追踪描述链接或其他已核验入口，具体以[平台档案](02-主流社媒平台档案与商业化路径-v1.0.md#4-链接与转化路径矩阵)为准。设置内容 ID、UTM、七/三十/九十天或项目适当窗口；订单以退款后净收入为准。
- **指标：**主指标为深度内容的有效观看/比较页访问或高意图咨询之一，首轮仅选一个主验证指标；记录观看留存、链接点击、搜索/直接流量和 FAQ 作为分层证据，不把播放量等同销售。
- **预算假设：**$40K 先保障一个深度证据锚点与必要的运输/保险/权利，再视首轮质量增补场景内容；不能因 Nano 报价低就忽略固定物流与审核成本。
- **风险：**安全材料未审、测试方法不可复现、危险品/重货运输、产品故障、极端场景夸大、库存不足、竞品排他和长制作周期。

**条件变化题：**产品改为低价非机动车骑行配件，样品充足、无需本地试骑，用户决策很短。如何改变？

## 10. 结业综合练习与参考答案框架

### 10.1 抽题规则

从八案中抽一案，再随机替换一个变量：市场、价格、决策周期、证据材料、样品数量、预算、时间窗、销售渠道或合规等级。学员须在 15 分钟内提交一页方案，5 分钟口头答辩。阅卷人必须追问：“**哪个条件一变，你的推荐会改变？**”

### 10.2 一页答案结构

1. 完整产品诊断卡（未知项和 Owner 不得省略）。
