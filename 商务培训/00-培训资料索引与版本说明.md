# 培训资料索引与版本说明

> 本文件是图灵集市商务新人海外红人营销培训包的唯一导航入口。培训材料用于建立判断能力，不替代适用法律、平台当前规则、合同、财务或法务审批。

## 1. 适用对象与能力边界

| 项目 | 规定 |
|---|---|
| 适用对象 | 商务新人、商务主管、参与方案评审的策略、红人运营与项目管理人员 |
| 培训 Owner | 商务负责人：课程安排、讲师协调、考核、签收与版本发布 |
| 平台 Owner | 策略负责人：12个平台事实、来源、适用市场与账号条件的季度复核 |
| 执行复核 | 红人运营负责人：达人名单、执行可行性、品牌安全及交付风险的最终专业复核 |
| 商务能力边界 | 商务负责达人一轮初筛、推荐逻辑说明和重大风险识别；不得以初筛代替运营最终专业复核 |
| 独立上岗门槛 | 理论考试不低于85分且红线题100%正确；平台与产品案例不低于80分；达人评估实操不低于85分；Roleplay不低于80分；完整项目答辩无重大漏判 |

### 内部资料引用规则

- SOP中的已批准流程与门禁属于当前内部制度；若与法律、平台规则或已签合同冲突，按更高权威执行并升级。
- CRM、财务、订单和项目复盘中可追溯的数据可形成“内部事实”，必须记录市场、品类、达人量级、内容格式、样本量、周期和提取日期。
- 两本手册中的数字、价格、互动率、平台功能和案例结果仅作素材线索，除非能在当前官方来源或内部证据中重新核验。
- Roleplay旧版保留为历史考核素材，不再作为平台事实和上岗门槛的当前权威文件。

## 4. 来源等级与引用标签

| 等级 | 标签 | 定义 | 客户材料使用规则 |
|---|---|---|---|
| A | 官方事实 | 适用法律法规、平台官方Policy、Help、Business、Creator或官方公告 | 可作为事实引用；必须带官方URL、适用市场、资格条件和核验日期，提案前复核 |
| B | 内部事实 | CRM、财务、订单、平台后台或项目复盘形成的可追溯证据 | 可作为图灵内部基准；必须说明样本、时间窗、分母和适用范围，不外推为全球结论 |
| C | 内部经验 | 经Owner批准的手册、案例和方法论形成的条件式判断 | 必须写成“在……条件下，建议优先测试……”；不得写成保证或普遍事实 |
| D | 项目假设 | 针对特定客户、市场、产品和预算提出的待验证判断 | 必须附验证计划、样本、预算、指标和停止条件，不得当成既有结果 |
| E | 外部线索 | 第三方报告、媒体、未核验文章、达人自述或公开主页数字 | 仅用于发现问题和提出核验方向；未经交叉验证不得进入客户承诺或闭卷标准答案 |

任何结论都必须显式标记为“官方事实、内部事实、内部经验或项目假设”。固定全球MAU、统一互动率、达人统一报价和无条件ROI不进入闭卷背诵题，也不得作为客户承诺。

## 5. 更新与发布机制

### 5.1 季度更新

1. 每季度首个完整工作周，由策略负责人检查07中的每条官方URL、功能名称、链接能力、商店/联盟/广告授权、音乐、披露、指标定义、市场和账号资格。
2. 红人运营负责人用最近一季度执行记录校验“官方可用”是否等于“项目可执行”，并记录区域、账号、类目和权限差异。
3. 商务负责人据复核结果更新01、02、05和06中受影响的教学口径，组织变更培训并保留签收证据。
4. 事实台账每条保留“核验日期、建议复核日、Owner、状态”；超过建议复核日的动态事实自动视为“待复核”，不得直接用于正式提案。
5. 即使未到季度复核日，平台重大政策、产品命名、市场准入、监管或计数口径变化也触发即时复核。

### 5.2 提案前复核

正式客户提案、报价或达人合作启动前，由Sales或Strategy针对目标市场重新核验功能可用性。商店、联盟、直播、链接和付费放大必须逐项确认市场、账号、类目、广告账户、创作者资格和授权期限。

### 5.3 版本号与旧版保留

- 重大课程结构、能力边界或认证门槛变化：升级主版本号，并新建文件，不覆盖旧版。
- 平台事实、案例或评分细节的兼容更新：升级次版本号；当前文件名和索引同步更新。
- 旧版移入版本归档并标记“历史版本/不得用于当前提案”；保留原文件名、发布日期、状态、变更摘要和SHA256。
- 同一编号只允许索引一个当前有效版本。历史版本可供审计和复盘，但不得继续作为当前速查卡或标准答案。
- 培训包正式发布时同步工作区、Obsidian版本归档和Git版本记录；复制后比对SHA256，不删除工作区源文件。
