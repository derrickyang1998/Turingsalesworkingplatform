# 图灵集市商务新人海外红人营销基础培训手册 v1.0

- **版本：**v1.0（受控试运行）
- **发布日期：**2026-09-08
- **适用对象：**商务新人、商务主管，以及参与方案评审的策略/运营同事
- **定位：**五周课程的稳定知识教材与案例答题框架；不是报价单、平台功能说明、法律/税务意见或效果承诺。
- **关联文件：**[平台档案与商业化路径](02-主流社媒平台档案与商业化路径-v1.0.md)；[商务团队客户全生命周期与日常作业 SOP v2.1](../商务团队客户全生命周期与日常作业SOP-v2.1.md)。

> **学习目标：**新人完成本手册后，能够从客户生意而非平台热度出发，提出可验证的“市场—受众—阻力—内容—路径—指标—风险”假设；能完成达人**初筛与风险识别**，并清楚说明数据、权利、合规与承诺边界。最终达人名单的专业复核由运营负责。

## 0. 先学会给结论分层

同一句建议的可靠程度不同。培训、方案和客户沟通都要标记结论所属层级，避免把经验、价格或平台变化当成定律。

| 来源等级 | 是什么 | 可以怎样说 | 不可以怎样说 |
|---|---|---|---|
| **A｜官方事实** | 已核验的法律法规、平台官方 Policy、Help、Business、Creator 文档或官方公告 | 写明官方 URL、核验日、适用市场和账号/类目资格。 | 用旧截图、其他国家或其他账号的功能作保证。 |
| **B｜可追溯内部事实/政策** | 当前受控 SOP、CRM、财务、订单、后台或项目复盘中的可追溯事实 | “按当前 SOP，正式报价前需完成必填信息。”同时写明版本、样本、窗口和证据位置。 | 把内部默认规则说成法律、全球事实或永久规则。 |
| **C｜条件式内部经验/方法** | 经 Owner 批准、可跨项目复用但受市场、品类和时间约束的方法或经验 | “若需要深度证明，可将长内容列为待验证假设。” | “这个行业在这个平台一定更好。” |
| **D｜项目假设** | 本项目待通过测试、后台或客户数据验证的判断 | “在该市场先以此内容原型测试。”并写验证和停止条件。 | “预计值就是承诺值。” |
| **E｜外部线索** | 第三方报告、媒体、未核验文章、达人自述或公开主页数字 | 只用于发现问题和提出核验方向。 | 未经交叉验证进入客户承诺、标准答案或内部事实。 |

STP、漏斗、公式和权利拆分等稳定方法本身不另占一个来源等级：引用外部规则时按 A/E 标记，引用当前内部制度或批准方法时按 B/C 标记，落到具体客户判断时按 D 标记。`来源等级 A–E`、`达人证据置信度 H/M/L` 与 `达人推荐等级 A–D` 是三套不同标签，不得混用。

**权威顺序：**适用法律、平台规则与已签合同 > 已批准例外/发布单 > 当前 SOP > 内部手册/可追溯案例 > 未核验文章或达人自述。没有来源、日期、地区、统计窗口和分母的数字，不是标准答案，也不能成为对客承诺。

## 1. 从客户生意开始：STP、ICP 与购买阻力

### 1.1 客户旅程不是一条“平台漏斗”

客户旅程从用户的真实购买情境开始：用户是否意识到问题、如何比较替代方案、在哪一步失去信任、购买后为何复购或推荐。红人内容只是其中一个触点；库存、价格、物流、页面、支付、客服和产品本身同样会决定结果。

```text
用户/客户生意问题
  └─ 细分与优先人群（STP/ICP）
      └─ 购买情境与购买阻力
          └─ 客户旅程：认知 → 考虑 → 购买 → 复购/推荐
              └─ 红人内容承担的特定角色
                  └─ 内容入口、承接页与可测量路径
```

### 1.2 STP：不是“品类等于平台”

- **Segmentation（细分）：**按目标市场与语言、价格带/购买力、使用场景、痛点、购买成熟度、销售渠道、合规限制、内容消费方式和品牌阶段切分。年龄或品类只是变量，不是答案。
- **Targeting（目标）：**选一个可服务、可测量、且与预算和时间相称的首要人群；同时写明不优先谁及原因。
- **Positioning（定位）：**把产品特性翻译成该人群在具体情境下可相信的收益。内容要提供证据，而不是重复品牌口号。

**四个必问：**

1. 谁在什么场景下需要解决什么问题？
2. 他现在会选什么替代方案，为什么不换？
3. 最大的购买阻力是什么：不了解、看不懂、不信、嫌贵、担心效果，还是无法顺利购买？
4. 点击后的库存、页面、价格、物流、支付和客服是否能承接？

### 1.3 ICP：先判断能否服务，再判断是否值得投入

| 对象 | 需要判断的内容 | 最低证据 | 常见混淆 |
|---|---|---|---|
| **客户 ICP** | 图灵是否适合服务该品牌/代理机会 | 海外销售或上市计划、可演示产品、合规主体、样品/库存、预算和付款路径、决策链 | ICP 是初筛，不是项目准入或成交概率。 |
| **买方角色** | 谁出钱、谁负责、谁否决、谁采购/法务/财务审批 | 角色、利益、权限、采购与付款路径 | 联系人喜欢，不代表经济决策人批准。 |
| **项目 fit** | 这一轮是否可交付、可衡量、可控风险 | 市场、SKU、目标、预算、排期、合规、物流、归因 | 必须按 SOP 的资格评分、红线和准入判断。 |
| **达人原型** | 谁能向目标受众提供需要的内容证据 | 受众、真实性、内容说服力、商单表现、品牌安全、可靠性 | 粉丝量或报价低，不是适配和质量的替代品。 |

当前 SOP 规定：进入 L3 准入评审时，需求完整度不得低于 80%；正式报价前，影响范围、价格、交付和风险的必填信息必须达到 100%。信息不足时，商务的正确动作是追问、缩小测试范围或暂不报价，而不是补一个“看起来完整”的名单。

### 1.4 品牌阶段、购买阻力与红人营销的位置

品牌阶段指当前**主要约束**，不是品牌成立年限；同一品牌可在不同市场或 SKU 同时处于不同阶段。

| 品牌阶段 | 首要问题 | 常见购买阻力 | 红人营销可承担的角色 | 不应误判为 |
|---|---|---|---|---|
| 0 准备/问题验证 | 产品是否被理解、谁会在乎 | 本地语言/场景不对、价值未说清 | 受众语言研究、小样本反馈、内容原型 | 用少量订单推断市场规模。 |
| 1 进入/认知 | 正确人群是否发现并记住品牌 | 无认知、缺少社会证明 | 场景化发现、初始信任、搜索语境 | 曝光就是销售。 |
| 2 教育/考虑 | 用户为何选择而非替代方案 | 解释成本高、证据不足、评价不可信 | 测评、演示、对比、教程、FAQ | 点击差一定是达人问题。 |
| 3 转化/验证 | 如何降低购买摩擦并得到可信数据 | 链接、页面、价格、库存、支付、退货 | CTA、链接/码、联盟、转化素材 | 最后点击等于全部增量价值。 |
| 4 放大/效率 | 哪些组合值得增加投入 | 频次疲劳、边际成本变差、授权不足 | 复投、获授权的付费放大、预算实验 | 首次结果可以线性外推。 |
| 5 留存/品牌资产 | 怎样形成复购、推荐与内容资产 | 创意疲劳、合作失配、售后教育不足 | 大使、社区、使用教育、UGC 再利用 | 单条内容能独自解释全部复购。 |

红人营销可服务于品牌发现、内容生产、搜索与比较、销售协助和用户洞察，但不是万能媒体位。它的价值至少分为：

- **发现：**进入合格人群的信息流或搜索语境；
- **证明：**通过真实使用、实测、教程、比较或专家解释降低不确定性；
- **社会证明：**让用户看见可信的人如何使用；
- **内容资产：**生产可交付素材，是否发布、自然复用或广告使用另行约定；
- **转化协助：**用清晰 CTA、可用链接/码和承接页减少摩擦；
- **学习：**用受控测试发现哪种人群、创意、合作和路径值得下一轮投入。

### 1.5 自检：先写业务，再写平台

面对“某智能家居产品想做海外红人”这一信息，以下哪种写法合格？

- 不合格：“选平台 A，因为它流量大；找 20 位粉丝多的达人。”
- 合格：“先确认目标国家、主推 SKU、价格带、用户购买场景、最大不信任点和独立站承接。若用户需要看到安装/稳定性证据，再把相应内容和平台角色列为测试假设，并明确链接与归因窗口。”

## 2. 统一决策链：从目标到风险

所有客户建议、案例答题和达人推荐按同一顺序展开：

```text
客户目标
→ 目标市场与受众
→ 产品购买阻力
→ 平台角色
→ 达人类型
→ 内容证据
→ 商业合作形式
→ 链接与转化路径
→ 指标与归因
→ 合规和风险
```

### 2.1 十步决策卡

| 步骤 | 要回答的问题 | 最低输出 |
|---|---|---|
| 1. 客户目标 | 这轮优先验证认知、教育、转化、资产还是留存？成功与失败如何定义？ | 一个主目标、一个辅助目标、停止/放大条件。 |
| 2. 目标市场与受众 | 哪个国家/语言/人群、哪个购买情境优先？ | 首要人群与非优先人群。 |
| 3. 产品购买阻力 | 用户为何现在不买或不信？ | 一条可被内容、页面或服务验证的阻力。 |
| 4. 平台角色 | 该平台承担发现、证明、社交证明、线索还是社区？ | 主/辅平台及不选其他平台的理由。 |
| 5. 达人类型 | 谁最能提供该证据，谁应排除？ | 达人原型、硬门槛、达人证据置信度 H/M/L。 |
| 6. 内容证据 | 需要实测、对比、教程、生活方式、专家解释还是口碑？ | 内容假设、必讲点、禁用表达。 |
| 7. 商业合作形式 | 买的是发布、内容、佣金、广告权还是长期关系？ | 交付范围与逐项权利。 |
| 8. 链接与转化路径 | 用户从哪里进入，在哪一步流失，谁负责承接？ | 内容→入口→页面/店铺→订单的路径图。 |
| 9. 指标与归因 | 每一步用什么分母、窗口、数据源和成本范围测量？ | 测量口径表与数据 Owner。 |
| 10. 合规和风险 | 合规、权利、受众真实性、竞品、物流、付款和平台资格是否受控？ | 风险、Owner、升级/停止动作。 |

也可用 **PEPER** 快速复盘：**P**roblem（问题）→ **E**vidence（证据）→ **P**ath（路径）→ **E**conomics（经济性）→ **R**isk（风险）。五项中任何一项只有猜测而无明确待验证动作，就不能把建议写成确定结论。

### 2.2 达人初筛的边界

商务负责“是否值得送入评审”的初筛与风险识别，不负责替代运营做最终名单专业复核或最终放行。初筛顺序如下：

1. **硬门槛：**目标市场/语言、产品可用性、品牌安全、竞品冲突、必要披露意愿、身份与收款主体异常、数据造假风险。出现红旗即排除或升级。
2. **质量判断：**按已批准的 100 分卡评估受众匹配（25）、真实性稳定（20）、内容说服力（20）、历史商单（10）、品牌安全合规（15）、沟通交付可靠性（10）。
3. **商业可行性：**报价、档期、内容形式、修改、授权、付费放大、排他、物流、税费和项目贡献毛利，不能被高质量分掩盖。
4. **证据置信度：**H=后台或可核验导出；M=第三方与公开内容交叉验证；L=主页公开数字或自述。写明抓取日期。

**一票否决/升级示例：**可核实刷量或身份异常、拒绝必要披露、重大品牌安全问题、竞品排他冲突、可核实恶意删商单或跑单。最终复核由运营确认，商务不得以“已联系到”或“粉丝多”越过该边界。

### 2.3 三个反例：单一漂亮数据为何会误导

**反例 A：高曝光不等于合格需求。**某内容获得大量播放，但受众国家、语言和购买力与目标不匹配，且没有可用入口。它可能证明内容被看见，不能证明目标市场有购买意图，更不能直接证明销售。下一步应检查合格受众、观看质量、搜索/站点变化与承接，而不是据此放大预算。

**反例 B：高互动不等于商业说服。**抽奖、争议或娱乐性内容可带来评论、点赞和分享；这些互动未必来自潜在买家，也未必回答了产品的购买阻力。应分项看保存、分享、评论质量、主页访问、有效点击和后续行为，并检查内容是否真正展示了产品证据。

**反例 C：高点击不等于转化责任在达人。**点击很多但加购/支付低，可能是落地页加载慢、断货、价格与内容不一致、物流不可达或结账失败。商务应把链路拆开，不能仅凭 CVR 低就否定达人。

**反例 D：高 ROAS 不等于客户营销 ROI 或图灵项目盈利。**ROAS 的分子是双方约定的归因销售收入，必须标明为毛销售收入或净销售收入；净口径须按约定处理折扣、取消和退款，两种口径不得共用一个未标注的“ROAS”。ROAS 不扣 COGS，因而不是利润；客户营销 ROI 必须基于客户侧贡献毛利和总投入；图灵项目贡献毛利又以图灵财务确认净收入和项目直接成本衡量。三者分别回答不同问题，不能互相替代。

## 3. 目标与指标树：先锁口径，再报结果

### 3.1 指标树与因果边界

```text
认知：曝光/播放 → 有效观看
兴趣：互动、保存/分享、搜索、主页访问
行动：可点击展示 → 追踪点击 → 加购/留资 → 购买
留存：复购、推荐、内容再利用
经济性：约定归因销售收入（毛/净必标）→ ROAS；客户贡献毛利 → 客户营销 ROI；图灵确认净收入 → 项目贡献毛利率
```

箭头是待验证的业务路径，不是自动因果。搜索、点击、购买和复购可能来自多个触点；自然与付费内容、不同平台、不同国家和不同归因模型不得未经说明合并。

### 3.2 测量口径表：计算前必须确认

每个项目在发布前写清：数据源与平台/内容 ID、统计窗口和冻结日、曝光或播放定义、有效观看门槛、互动项、可点击展示是否可得、UTM/码/联盟 ID、转化事件、归因窗口与模型、币种及汇率、客户侧和图灵侧成本范围、收入是否扣折扣/取消/退款、以及数据 Owner。

**零与未知的统一规则（适用于本手册和 SOP 中全部比率/单价）：**

- 分母经核验为 0，或分母未知/不可信：比率/单价标注“不可计算”；未知时可同时标“未知/不可比较”，不以其他字段替代。
- 分子为 0 且分母为已核验的正数：结果为 0；同时说明统计窗口和数据完整性。
- 任何情形都不得输出无穷大、用 0 代替未知，或为了填表虚构分子、分母或结果。
- 无可靠点击、订单或收入：只报告已核验的上游数据，不反推“估算销量”。

### 3.3 KPI 公式卡（均为教学算例，不是基准或预测）

下表的“成本/收入边界”是计算的一部分。除特别说明外，例子假设数据已在同一币种、同一窗口、去重后冻结；例如 **有效观看**必须在项目开始前约定为“达到某平台可取得的时长或完播门槛”，不能临时换定义。

| KPI | 公式：分子 / 分母 | 零/未知处理 | 成本或收入边界 | 已核对算例 |
|---|---|---|---|---|
| **CPM** | 项目约定投放成本 ÷ 有效曝光 × 1,000 | 曝光=0 或未知：不可计算。 | 成本须列明是否含达人费、媒体费、服务费、授权、物流、税费；本例为内容/媒体/服务总成本。 | $20,000 ÷ 500,000 × 1,000 = **$40.00**。 |
| **CPV** | 项目约定投放成本 ÷ 有效观看次数 | 有效观看=0 或未知：不可计算。 | 使用同 CPM 的明确成本；观看门槛、平台字段和窗口必须固定，不能用总播放替代。 | $20,000 ÷ 100,000 有效观看 = **$0.20**。 |
| **CPE** | 项目约定投放成本 ÷ 约定互动数 | 互动=0 或未知：不可计算。 | 互动包含哪些赞/评/转/藏须预先写明；成本范围同 CPM。 | $20,000 ÷ 25,000 = **$0.80**。 |
| **CTR** | 追踪点击 ÷ 可点击展示量 × 100% | 可点击展示量=0 或未知：不可计算；不能改用播放量后仍称 Link CTR。 | 不以成本或收入为分子；点击需来自可追踪入口，去除已知重复/无效流量。 | 12,500 ÷ 250,000 = **5.00%**。 |
| **CPC** | 项目约定投放成本 ÷ 追踪点击 | 点击=0 或未知：不可计算。 | 成本范围同 CPM；点击仅计入约定 UTM/联盟/码可识别的入口。 | $20,000 ÷ 12,500 = **$1.60**。 |
| **CVR** | 归因转化数 ÷ 追踪点击 × 100% | 点击=0 或未知：不可计算；订单=0且点击有效：0%。 | “转化”须写明是留资、加购、下单还是支付；不把退款后无效订单当有效购买。 | 500 已支付订单 ÷ 12,500 = **4.00%**。 |
| **CPA** | 项目约定投放成本 ÷ 归因转化数 | 转化=0 或未知：不可计算。 | 成本范围同 CPM；转化事件与 CVR 完全一致，不能用留资分子与订单分子混算。 | $20,000 ÷ 500 已支付订单 = **$40.00**。 |
| **ROAS** | 双方约定的归因销售收入 ÷ 约定投放成本 | 成本=0 或未知：不可计算；收入=0且成本为有效正数：0.00x。 | 指标名称必须标成“毛 ROAS”或“净 ROAS”。毛收入不扣折扣、取消、退款；净收入按项目约定扣除这些项目。二者不得混用或省略标签。收入是客户侧销售收入，**不是利润**；成本不自动含 COGS。 | 净归因销售 $50,000 ÷ $20,000 = **净 ROAS 2.50x**。 |
| **客户营销 ROI** | （客户侧归因贡献毛利 − 客户营销总投入） ÷ 客户营销总投入 × 100% | 总投入=0 或未知：不可计算；贡献毛利为负时可得负 ROI。 | 客户侧贡献毛利须先定义，例如净销售扣退款、折扣、COGS及约定变动成本；总投入须列达人、媒体、服务、授权等全部约定投入。 | ($25,000 − $20,000) ÷ $20,000 = **25.0%**。 |
| **图灵项目贡献毛利额** | 图灵财务确认净收入 − 项目贡献成本；**非比率，分母不适用** | 任一财务确认输入未知：不可计算。 | 净收入=财务确认收入−折扣−退款−折让−冲销；贡献成本含达人费、支付手续费、物流/寄样、授权、项目专属第三方成本、不可抵扣税费、已实现汇兑损失及财务规定的直接成本。 | $30,000 − $18,000 = **$12,000**。 |
| **图灵项目贡献毛利率** | 图灵项目贡献毛利额 ÷ 图灵财务确认净收入 × 100% | 净收入=0 或未知：不可计算。 | 这是 SOP 用于准入/报价的项目经济性口径，**不等于客户营销 ROI 或 ROAS**；最终以财务锁定数据为准。 | $12,000 ÷ $30,000 = **40.0%**。 |

**复算检查：**上例中 ROAS 为 2.50x，而客户营销 ROI 为 25.0%，两者不矛盾：前者看收入/投放成本，后者只在定义了客户贡献毛利和全投入后才判断回报。图灵项目贡献毛利则回答图灵是否按自身确认收入和直接成本盈利，不能拿客户 $50,000 销售额替代图灵收入。

### 3.4 指标题自检

1. 没有“可点击展示量”，但有 500,000 播放和 12,500 追踪点击，能否叫 Link CTR？**不能。**可在事前约定后称“播放点击率”=2.50%，但要明确分母不是可点击展示。
2. 追踪点击为 0，能否写 CPC=$0？**不能。**投入仍发生，分母为 0，应写“不可计算”；$0 会错误暗示没有成本。
3. 有订单却没有退款数据，能否报告 ROAS？**可以按已约定口径暂报“预估毛 ROAS”，并标注未扣折扣/取消/退款及窗口未结束；不得省略“毛”标签，也不能与净 ROAS 直接比较。**

## 4. 合作形式、付款与权利：逐项拆开，不靠默认推定

### 4.1 常见合作形式

| 形式 | 核心交付 | 不自动包含 | 必须在合同/发布单写清 |
|---|---|---|---|
| **赠品/测评** | 样品交付；是否发布取决于协议 | 正面评价、固定发布时间、素材权、销量 | 是否保证发布、样品归属/退还、真实体验、披露、税费。 |
| **固定费原生发布** | 创作并在指定账号发布 | 广告投放、二剪、跨平台、排他 | 账号、格式、数量、保留期、审核/修改、数据回传、披露。 |
| **Dedicated / Integration** | 独立评测或既有内容中的植入 | 额外社媒分发、额外位置、效果保证 | 位置、时长、产品露出、CTA、初稿/终稿、保留期。 |
| **佣金/联盟** | 约定码/链接带来的合格交易佣金 | 最低曝光、独家、所有订单归因、素材权 | 归因窗口、有效订单、退款冲回、去重、结算、税费、披露。 |
| **混合模式** | 固定费与佣金/绩效触发并存 | 一方条款自动覆盖另一方 | 各部分交付、触发、数据源、上限、退款和争议处理。 |
| **UGC 内容生产** | 文件/素材交付 | 达人发布、全媒体广告权、无限期修改 | 原始/成片规格、交付、剪辑、字幕、翻译、人物/音乐/第三方权利。 |
| **付费放大** | 对指定自然帖子/素材进行广告使用 | 自然帖以外的任意素材/地域/期限 | 广告主、帖子/素材、平台、地域、期限、版位、预算、撤回/下线。 |
| **长期品牌大使** | 多期内容与关系管理 | 永久排他、无限使用、自动续约 | 频次、主题、续约、披露、每条权利、竞品范围、复盘与终止。 |

### 4.2 七项权利清单

以下权利彼此独立，不能因为买了其中一项就推定拿到了另一项：

1. **自然发布权：**达人在指定账号、指定内容和保留期内发布。
2. **有机复用权：**品牌在自有非付费渠道转发/嵌入该内容。
3. **编辑/二剪权：**裁切、重组、事实修订、字幕、翻译、配音或版本化；须规定允许范围。
4. **付费媒体/白名单（whitelisting）权：**将达人帖子或素材用于广告；应使用相应平台授权机制。
5. **地域权：**哪些国家/地区可使用。
6. **期限权：**起止日期、续期、下线宽限和历史投放处理。
7. **转授权（sublicensing）权：**客户、代理、零售商、媒体伙伴或其他第三方能否再使用。

还应按需要单列平台/媒体、素材版本、肖像/声音、音乐/场地/其他第三方权利、AI 处理、排他和数据访问。**自然发布权不等于素材使用权，更不等于付费投放权。**任何扩大使用范围、地域、期限、媒体或转授权的要求，都要书面确认、重新定价和必要审批。

### 4.3 商务在权利谈判中的正确说法

- 可以说：“我们会把发布、素材、剪辑、付费投放、地域、期限和转授权逐项列入发布单，待对应授权和平台资格核验后执行。”
- 不可以说：“达人同意发帖，品牌就能拿去投广告/随便剪/全球永久使用。”
- 可以要求准确表达、既定交付和合理品牌安全标准；不得要求达人发表虚假或误导性好评。对删帖、延期、退款、赔付与排他争议，以已签合同和法务意见为准。

## 5. 合规、承诺与品牌安全边界

> 本章是业务培训，不构成法律意见。美国项目以 FTC 的真实性与披露原则作为最低培训边界；**其他市场以及跨境项目必须由项目负责人按目标市场进行项目级法律、平台和合同复核**，不能以本章替代当地审查。

### 5.1 美国披露最低边界（FTC）

出现报酬、免费/折扣产品、佣金、雇佣、家庭或其他可能影响受众判断的关系（material connection）时，应作清晰、显著的**商业披露**。披露应贴近背书内容、让受众容易看到和理解；视频通常应在视频中呈现，直播应按需要重复。披露不能被藏在简介页、展开后文字、长串标签或含糊缩写里。背书应反映真实意见和体验；不得就无充分依据的健康等功效作虚假或误导表述。

**发布前检查：**

- 关系性质是否明确（赞助、广告、收到免费产品、佣金等）且使用与内容相同的语言？
- 披露是否在用户实际看到背书的位置出现，并在视频/直播中可理解？
- 达人是否实际体验了所称体验？产品宣称是否有客户提供并经审查的证据？
- 是否把单个异常结果伪装成一般结果，或遗漏必要限制条件？

官方资料：FTC [Disclosures 101 for Social Media Influencers](https://www.ftc.gov/business-guidance/resources/disclosures-101-social-media-influencers)；FTC [Endorsement Guides: What People Are Asking](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides-what-people-are-asking)。两者均强调具体情境决定适用性，因此项目仍需复核。

### 5.2 其他必须识别并升级的风险

| 风险 | 商务需要识别的信号 | 正确动作 |
|---|---|---|
| **健康/安全宣称** | 治疗、预防、绝对效果、前后对比、儿童/医疗敏感产品 | 停止把它写为卖点；取得资质/证据并交项目级合规或法务审查。 |
| **版权音乐与第三方素材** | 热门音乐、场地、人物、商标、截图、素材库来源不清 | 逐项确认使用媒体、地域、期限和广告用途的权利；自然发布许可不推定广告许可。 |
| **隐私与数据** | 像素、名单、私信、儿童信息、跨境数据、未同意追踪 | 最小必要收集；按适用法律、平台规则和客户/法务要求确认授权与保留。 |
| **儿童与未成年人** | 内容面向儿童、未成年人出镜、敏感品类定向 | 先升级审查；不得假设普通成人营销规则足够。 |
| **竞品排他** | 同类合作、未定义竞品/国家/期限、过宽排他 | 把类目、品牌、地域、期限、被动露出例外和费用写清。 |
| **品牌安全** | 仇恨/歧视、虚假信息、暴力、成人、违法、欺诈、争议舆情 | 留证、停止承诺或发布、按 SOP 升级；不在未核验前公开指控。 |

### 5.3 对客承诺红线

商务应说明可控动作、测试范围、数据口径与合同补救边界，而非承诺不可控结果。以下改写可用于 Roleplay：

| 不合格表达 | 合格表达 |
|---|---|
| “一定爆 / 保证 ROI。” | “我们会在筛选、Brief、审核、追踪和复盘设置控制点；平台分发与消费者购买不可无条件保证，可先约定测试窗口和成功标准。” |
| “所有产品都适合某平台。” | “若产品需要某类内容证据且目标市场/账号条件可行，可将该平台作为待验证的主或辅角色。” |
| “任何市场都能用这个 Shop、链接或广告工具。” | “功能须在目标国家、账号、类目、商家和广告资格下项目级核验后确认。” |
| “效果不好我们一定补量/退款。” | “补救、替换、延期、退款和责任边界以已签合同、发布单和审批为准。” |

## 6. 平台档案：本手册只教角色，不复制动态事实

平台的内容格式、链接位置、可点击性、Shop/Creator/广告工具、账号或地区资格、音乐规则、用户规模、受众数字、报价和基准会变化。本手册不重复这些动态信息，也不把它们当闭卷答案。

提案前必须使用 [《02-主流社媒平台档案与商业化路径 v1.0》](02-主流社媒平台档案与商业化路径-v1.0.md) 逐项核验，并记录官方来源、核验日期、目标市场、账号/类目条件和截图。该档案将每个入口标记为“已核验可点击 / 已核验不可点击 / 未核验—不得对客承诺”。

稳定的教学问题只有四个：

1. 该平台在此项目中承担发现、证明、社交证明、线索、社区还是留存角色？
2. 用户需要什么原生内容证据，达人原型是否能持续交付？
3. 自然内容和付费内容的入口、数据和授权是否不同？
4. 从内容到店铺/落地页/支付的哪一步会失去用户，谁负责修复？

不要因“某平台人多”“别人都在做”“账号上看见入口”直接推荐。所有动态平台格式、链接、Shops、Creator 工具、广告资格和受众数字都以《02》及其官方来源的当前核验为准。

## 7. 五周学习与案例答题框架

| 周次 | 重点 | 应交作业 | 最低验收 |
|---|---|---|---|
| 第 1 周 | 客户旅程、购买阻力、品牌阶段、指标、归因、权利与合规 | 拆解两个脱敏项目的目标、阻力与 KPI 树 | 理论≥85；红线题全对。 |
| 第 2 周 | 动态平台档案、平台角色、内容路径 | 同一产品完成三平台分工与核验清单 | 平台案例≥80；无绝对化承诺。 |
| 第 3 周 | 产品适配、达人原型、初筛与风险识别 | 三个产品策略、十张达人初筛卡 | 初筛实操≥85；重大红旗零漏判。 |
| 第 4 周 | 需求诊断、方案、报价与异议 | 需求会 Roleplay、测量口径表、初步方案 | Roleplay≥80；证据和边界完整。 |
| 第 5 周 | 从线索到交接的商业闭环 | 完整研究、诊断、策略、短名单、交接答辩 | 无重大流程、合规或承诺错误。 |

### 7.1 所有案例的固定答题模板

```text
1. 客户业务目标（主/辅）与成功窗口：
2. 目标市场、首要受众与购买情境：
3. 产品购买阻力与替代方案：
4. 品牌阶段与本轮不解决的事情：
5. 平台主/辅角色（动态能力请链接《02》并标明核验项）：
6. 达人原型、硬门槛、达人证据置信度 H/M/L 与需运营复核事项：
7. 内容证据、真实体验边界、CTA 与禁用表述：
8. 商业形式；发布、素材、二剪、付费投放、地域、期限、转授权分别列明：
9. 内容→入口→承接页/店铺→加购/支付→退款期后的转化路径：
10. KPI、分母、窗口、归因、成本/收入边界、数据 Owner：
11. 合规、版权、隐私、儿童、竞品、品牌安全、物流/付款风险及 Owner：
12. 待验证假设、替代方案、放大/停止条件：
```

**评分原则：**先写客户目标、市场/人群和购买阻力，才谈平台/达人；每个 KPI 都要有分母、窗口、归因和成本边界；信息不足时提出要补的事实或小范围测试，优于编造精确答案。允许有不同平台组合，只要因果逻辑、证据和风险控制完整。

### 7.2 结业自检清单

- [ ] 我能区分来源等级 A–E，并且不与达人证据置信度 H/M/L、达人推荐等级 A–D 混用。
- [ ] 我能从客户旅程和购买阻力出发，而不是从平台或粉丝量出发。
- [ ] 我能解释曝光、互动、点击、ROAS 为什么都不能单独代表成功。
- [ ] 我能为 CPM、CPV、CPE、CTR、CPC、CVR、CPA、ROAS、客户营销 ROI 和项目贡献毛利给出可复算口径。

- [ ] 我知道美国 FTC 披露是最低培训边界；其他市场必须项目级复核。
- [ ] 我只完成达人初筛和风险识别，并把最终名单交给运营专业复核。
