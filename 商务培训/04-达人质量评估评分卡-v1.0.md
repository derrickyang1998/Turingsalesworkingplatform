# 达人质量评估评分卡 v1.0

> 用途：供商务完成达人**质量初筛、评分、推荐理由与风险识别**，并把完整证据交给红人运营作最终专业复核。本卡是培训与作业控制工具，不是对达人作事实指控的工具，也不构成效果、报价、档期、授权或合作承诺。

## 1. 使用边界：先门禁，后评分，再商业可行性

### 1.1 职责边界

| 角色 | 可以做 | 不可以替代 |
|---|---|---|
| 商务（Sales） | 按本卡筛选、打分、说明推荐理由、保存证据、识别重大风险并发起升级 | 最终专业核验、确认报价/档期/权利、批准最终名单 |
| 红人运营（Operations / Ops） | 复核证据与专业判断；确认报价、排期、身份/合同/收款、交付、授权、披露与最终名单 | 用未证实疑点作指控，或跳过合同与项目门禁 |
| 策略/法务/财务 | 分别复核平台事实与项目适配、敏感合规/宣称、毛利与付款例外 | 替代 Ops 的执行可行性终审 |

**结论顺序固定为：**硬门槛/一票否决 → 100 分质量评分 → 商业可行性门槛 → Ops 最终批准。质量总分高，不能覆盖前面的否决项，也不能覆盖后面的商业不可行。

### 1.2 一票否决与暂停项（先于评分）

下列任一项有**已核验证据**时，结论为“暂停/淘汰，转 Ops（及 Legal，按需）”，不再以质量总分放行：

1. 确认伪造后台截图、购买假粉、刷量或伪造合作结果。
2. 身份、合同主体与收款主体存在无法合理解释的不一致，或拒绝完成必要核验。
3. 拒绝适用的广告/赞助披露，或坚持虚假、未经证实的功效、安全、医疗等宣称。
4. 存在严重仇恨、歧视、违法、剥削、性安全、暴力或重大品牌不相容内容。
5. 未解决的竞品排他（exclusivity）冲突。
6. 账号正处于重大处罚、封禁，或有高概率下架且无可接受恢复证据。
7. 有可核验的跑单、恶意删除商单、拒不履行已确认义务或拒不退款记录。

**中性处置语言：**单一异常、截图不完整、播放偏低或评论可疑，只记为“待核验异常/红旗”，不得写成“造假”。先保存链接、截图、抓取日期和说明，暂停推荐并交叉复核；只有证据达到核验标准才适用上述否决项。

### 1.3 不计入质量分的商业可行性门槛

以下事项是独立门槛，**不是质量加分项**；通过后才可由 Ops 批准进入最终名单：

| 门槛 | 必须确认的事实 | 未确认/不通过时的动作 |
|---|---|---|
| 报价与毛利 | 报价币种、税费、服务成本、预算及批准毛利 | 不承诺、不锁档；转 Ops/Finance 重算 |
| 档期与可用性 | 发布时间、样品到达、脚本/初稿/修改窗口、旺季冲突 | 标“待确认”，不得写进已确认名单 |
| 权利与授权 | 自然发布、素材下载、二剪、白名单/广告、地域、期限、平台与署名 | 按项目单列，未书面确认不得假定拥有 |
| 合同与付款 | 合同主体、收款路径、取消/延期、付款节点及审批 | 按 SOP 走合同与财务门禁 |
| 竞品排他 | 竞品范围、排他期、地域、品类及冲突解除证明 | 未解决即一票否决；不可用评分抵消 |

## 2. 证据规则、置信度与口径

### 2.1 证据置信度 H / M / L

| 等级 | 定义 | 可支持的动作 |
|---|---|---|
| H（高） | 平台后台截图/导出，能识别账号、统计窗口、抓取日期和指标定义，且可与公开内容合理勾稽；或有可核验合同/历史项目记录 | 可用于最终推荐和高预算首单的核心依据 |
| M（中） | 第三方工具数据、公开内容、品牌案例等至少两类来源相互支持，但关键后台字段仍缺失 | 可进入短名单；核心项须向达人/Ops 补证 |
| L（低） | 仅主页公开数字、单张无法验证的截图、达人自述或无日期的转述 | 仅用于批量初筛；不得据此锁档、承诺效果或支持高预算首单 |

规则：每一个评分子项都要写“证据位置＋抓取日期＋H/M/L”。数据缺失**不是**造假的证明。达人拒绝提供通常可提供的核心证据时，相关子项按 0 分计，并升级人工复核；不要把“拒绝”直接写成“造假”。

**“高预算首单”分类控制：**本卡不设置通用金额。打分前必须引用当期有效的审批矩阵或项目风险分类，记录项目币种、首单总预算、适用的高预算阈值及版本、是否命中高预算首单、风险等级、批准人和批准日期。没有这份分类记录时，评分可以用于内部诊断，但**最终推荐暂停，待完成分类**。只有项目已被有效记录为“高预算首单”，且核心受众、核心留存或核心历史商单证据缺失时，最终达人推荐等级才上限为 **C**；未被归类为高预算首单的项目不得套用该 C 上限，但证据缺口仍须按各子项和其他门禁处理。

### 2.2 指标与互动率统一口径

- 每次写互动率（ER）必须写完整公式和**分母**，例如：`ER（按 Reach）=(点赞+评论+分享+收藏)/Reach`；不得把 Views、Reach、Followers 混作同一分母。
- 有机与付费放大、普通内容与商单、长内容与短内容分开统计；记录样本量、窗口（通常近30–90天）和是否剔除明显不相关内容。
- 优先看中位数、四分位区间/分布和持续命中率；均值与单个爆款只能作补充解释。
- 所有截图/导出保存原文件或链接，标注抓取人、日期、账号、平台、时区与计算表版本。

### 2.3 三个平台的必看差异

| 平台/格式 | 必取指标与判断 | 互动率/效率口径示例 | 禁止混算 |
|---|---|---|---|
| YouTube 长视频 | 近20–30条同类型有机内容的播放中位数、平均观看时长、平均观看百分比、首30秒留存、植入段前后留存、流量来源、描述点击 | `互动率（按 Views）=(点赞+评论)/Views`；或单列 `描述CTR=描述链接点击/视频Views` | 长视频 Views/留存不得与 Shorts 混算 |
| YouTube Shorts | 同格式中位播放与分布、Engaged views 口径、平均观看时长/视频时长、完播、分享/评论和受众 | `分享率（按 Engaged views）=分享/Engaged views` | 不得拿 Shorts 爆款代替长评测影响力 |
| Instagram Reels | Reach、播放、平均观看时长、分享/收藏/评论、非粉触达、主页访问 | `ER（按 Reach）=(赞+评+分享+收藏)/Reach` | Reels 的 Views 与 Reach 不可互换 |
| Instagram Feed / Carousel | Reach、收藏、分享、评论质量、主页访问及内容寿命 | `保存率（按 Reach）=收藏/Reach` | 不得与 Reels/Stories 合并成“IG平均互动” |
| Instagram Stories | 首帧 Reach、逐帧留存、退出/前进/返回、链接贴纸点击、回复 | `链接CTR（按首帧Reach）=链接贴纸点击/首帧Reach` | 不得用首帧 Reach 代表全程送达 |
| TikTok | 最近20–30条播放**中位数**、四分位区间/持续命中率、平均观看时长/视频时长、完播、分享/收藏/评论、For You流量、单条受众地区、主页/商品点击 | `ER（按 Views）=(赞+评+分享+收藏)/Views`；`完播率=看完次数/视频播放次数`（以后台定义为准） | 不得只按粉丝数推断单条触达；均值不能掩盖异常分布 |

## 3. 100 分质量评分标准

### 3.1 可复现计算方法

1. 每个子项只填 `0 / 1 / 3 / 5`：0=不合格或无可用证据；1=偏弱/明显缺口；3=可接受且有基本证据；5=强表现且有充分、可复核证据。
2. 子项折算分=`原始档位 ÷ 5 × 子项满分`。保留一位小数；不要自行四舍五入到整数后再求和。
3. 维度分=该维度所有子项折算分之和；总分=六个维度分之和，满分100。
4. 任一硬门槛触发时结果为“暂停/淘汰”，总分仅可留作内部诊断，不能用于推荐。
5. 原始质量总分保留一位小数，并按无空档的连续区间确定**原始质量等级**：**A：85.0≤总分≤100.0**，优先推荐；**B：75.0≤总分<85.0**，可正常推荐；**C：65.0≤总分<75.0**，仅小额验证、里程碑付款并配置替补；**D：总分<65.0**，不推荐。随后再依次应用硬门槛、商业可行性门槛及证据封顶，形成**最终推荐等级/门禁结果**。若触发“高预算首单核心证据缺失”上限，原始质量等级即使为 A/B，最终推荐等级也记为 C；若硬门槛触发、适用商业门槛未通过或高预算首单分类记录缺失，则最终结果写“暂停/淘汰”，不得用原始等级替代。

### 3.1.1 锚点可复现协议（适用于以下全部26项）

本卡**不设固定的全球外部阈值**。每次打分前，评估人必须在项目口径中建立或引用一份“项目评分基线”，记录平台×格式×目标市场×达人量级、样本窗口、指标分母、内部对标样本版本和批准人；没有可用内部对标时，必须标注“项目阈值（待复盘校准）”并由 Ops 复核，不能把个人经验伪装成通用标准。

| 判断类型 | 打分前必须预设 | 0 / 1 / 3 / 5 的边界 |
|---|---|---|
| 数据项 | 为每个指标写入项目下限 `L1`、合格线 `L3`、优先线 `L5`；来源只能是该项目批准阈值或平台×格式×市场×量级的图灵内部可比基线 | `0`=无可用证据、低于L1或出现已核验反向事实；`1`=L1≤值<L3；`3`=L3≤值<L5；`5`=值≥L5，且格式、分母、窗口一致。等于边界时进入较高档。 |
| 定性项 | 为该子项建立可观察检查单，逐项写“命中/未命中/不适用”、证据ID和最低命中数 `Q1`、合格命中数 `Q3`、优先命中数 `Q5`；必备项另标 `M` | `0`=无证据、任一M项反向事实或命中<Q1；`1`=Q1≤命中<Q3且无M项反向事实；`3`=命中≥Q3且所有M项命中；`5`=命中≥Q5且所有M项命中、证据可交叉复核。 |

**子项适用表：**A1、A2、B1、B2、B4、D1、D3使用“数据项”规则；A3、A4、**B3、B5**、C1–C5、D2、E1–E4、F1–F5使用“定性项”规则。对包含数据与内容审查的子项（例如A3、E1），优先用定性检查单，并把相关数据作为一个可观察命中项。表中“基本匹配、强匹配、可接受、稳定、显著低于”等描述只能作为提示词，实际档位一律由上述 `L1/L3/L5` 或 `Q1/Q3/Q5` 决定。

**一致性与降档规则：**

1. 每项只可使用项目评分基线中**同一平台、格式、市场、量级、窗口和分母**的数据；无法同口径比较时，不能按5分解释。
2. 混合条件时取最低成立档：例如一项同时有5档和3档条件，只能给3；任何必备项未命中或反向事实，给0。缺失数据是“无证据/0分”，不是造假结论。
3. 证据冲突按 `H > M > L` 决定事实；H与H冲突或无法解释的同等级冲突，相关项暂记1分并人工复核；M与M或M与L冲突，使用较低的可支持档；L证据不能推翻H证据，但须记录为待核验。
4. 任何评分为3或5的子项，必须能在模板中回溯到阈值/检查单版本、证据ID、抓取日期和评估备注；否则降至1分。硬门槛仍优先于上述规则。

### A. 受众与项目匹配（25分）

| 子项（满分） | 0 分 | 1 分 | 3 分 | 5 分 | 必要证据 |
|---|---|---|---|---|---|
| A1 目标国家/地区（8） | 受众明显不在目标市场或无可用数据 | 仅粉丝所在地/自述，且与目标偏差大 | 有近30–90天目标地区受众或单条地区证据，基本匹配 | 后台受众地区与近期内容/评论/流量来源一致，目标市场占比和项目需求强匹配 | 平台 Audience/单条受众后台、目标市场定义、截图日期（H优先） |
| A2 年龄、性别、语言（5） | 与项目人群冲突 | 仅公开语言/主观判断，存在明显缺口 | 至少年龄或性别、语言可确认，基本满足项目要求 | 年龄、性别、语言三项均有后台或可靠证据，且内容表达适配当地语境 | 受众人口统计后台、近10条内容语言/评论样本、证据日期 |
| A3 兴趣与购买相关性（7） | 内容/受众兴趣与品类无关或冲突 | 偶有相关内容，缺少真实兴趣信号 | 有持续品类/场景内容、相关评论或互动，购买相关性可解释 | 长期垂类权威或高相关场景，评论/问答/历史合作显示真实需求与购买决策影响 | 近10条相关内容、评论语义样本、历史合作/受众兴趣证据 |
| A4 品牌调性与内容形式（5） | 内容风格、价值观或形式不适配 | 形式可做但表达生硬/样本少 | 可稳定完成所需格式，调性基本匹配 | 格式、叙事、审美和产品展示与品牌/项目目标高度契合，有可复用案例 | 项目 Brief、近10条同格式内容、至少1个同类案例 |

### B. 数据健康（20分）

#### B3 / B5 定性检查单（项目化 Q1 / Q3 / Q5，不设全球数值基准）

评估人须在项目评分基线中，为下列清单填写该项目的 `Q1/Q3/Q5` 命中数；`M` 为必备项。每个项目只按“可核验命中”计1次，不得以同一截图重复计数。下列检查项目定义了B3/B5的可观察事实，0/1/3/5档位严格按第3.1.1节的定性项规则执行。

| 子项 | 可观察检查项（逐项填命中/未命中/不适用，并填证据ID） | 必备项 |
|---|---|---|
| B3 互动真实性 | ①抽样内容清单、格式、窗口与互动率分母已记录；②抽样评论/互动账号可回溯至具体内容及账号；③评论或回复与视频主题、产品场景或真实提问相关；④评论语言/受众信号与目标市场或公开内容语境不矛盾；⑤抽样中未见无解释的重复短语、整齐时间涌入或明显无关账号模式，或已附可核验证据解释；⑥公开互动走势与后台/第三方趋势（如可得）不发生未解释冲突 | ①、②为M |
| B5 后台证据完整性 | ①后台截图/导出可识别账号；②可识别抓取日期与统计窗口；③指标名称、定义/分母及内容格式可识别；④原始文件或导出路径可追溯，截图未裁掉判读所需字段；⑤同窗口公开内容、发布记录或其他来源可合理勾稽；⑥证据提供者、文件版本和保存位置已登记 | ①、②、③为M |

`Q1/Q3/Q5` 必须是整数，并满足 `0 <= Q1 <= Q3 <= Q5 <= 该子项适用检查项数`。标记 `N/A` 时必须填写不适用理由、证据和 Ops 批准人；只有经批准的**非必备项**可从适用检查项数中排除，标为 `M` 的必备项不得静默改为 `N/A`。阈值、适用项数或 N/A 状态变更后必须生成新的项目评分基线版本，不得在评分后倒改阈值。

**B3/B5锚点对照：**

- **0分**：B3 已核验刷量/假互动（同时触发否决），或B3/B5无可用检查单证据、任一M项出现反向事实；B5 对通常可提供的核心证据明确拒绝，仍按0分并升级人工复核。
- **1分**：无M项反向事实，但命中数仅达到项目 `Q1` 且低于 `Q3`；记录未命中项与补证动作。
- **3分**：命中数达到项目 `Q3` 且全部M项命中；少量非必备缺口已记录，不得以主观“基本可接受”补足。

## 5. 9 步作业流程与交接

1. **锁定项目口径**：写明市场、受众、产品风险、格式、KPI、互动率分母、窗口及不可接受事项。
2. **批量初筛**：建立约20–30人候选池，筛地区、语言、垂类、格式和近期活跃度；L级证据只用于此步。
3. **量化预审**：按近30–90天分格式统计有机/商单中位数、四分位区间、增长、更新和明确分母的互动率。
4. **红旗扫描**：检查异常增长、评论质量、删帖、账号状态、披露、内容安全和竞品冲突；记录来源与抓取日期。
5. **短名单取证**：对拟提客户的5–10人索取/核验后台受众、留存、流量、Reach、点击和历史商单证据，登记H/M/L。
6. **人工内容审查**：至少看最近10条相关有机内容、3–5条商单及近期最高/最低异常样本；审查评论、披露、宣称、原创、CTA。
7. **商业可靠性审查**：由 Ops 书面确认身份、报价、档期、交付物、修改、权利、排他、保留期、数据回传、取消与付款；不把这些内容计入质量分。
8. **评分与决策**：先确认硬门槛，再填评分卡、等级、证据置信度、风险和推荐理由；C级只小额验证且设替补，高预算/敏感品类双人复核。
9. **上线后回填**：在上线当日、24小时、48小时、7天、30天回填表现、交付、删帖和合规结果，形成可复用的达人历史信用。

## 6. 三个完整评分算例

> 以下均为培训虚拟案例；分数是按“原始档位÷5×子项满分”计算，不代表真实达人或效果承诺。

### 案例一：质量高，但触发竞品排他否决

**情境：**YouTube科技长视频创作者，目标为美国智能家居新品评测。后台与公开数据大多为 H，近期30条长视频中位播放稳定、首30秒留存良好；但其与直接竞品的书面排他期尚未结束。

| 维度 | 子项原始档位（按表内顺序） | 折算分 |
|---|---|---:|
| A 受众匹配 | 5 / 5 / 5 / 5 | 25.0/25 |
| B 数据健康 | 5 / 5 / 5 / 5 / 5 | 20.0/20 |
| C 内容说服 | 5 / 5 / 5 / 5 / 3 | 18.8/20 |
| D 历史商单 | 5 / 5 / 3 | 8.8/10 |
| E 品牌安全 | 5 / 5 / 5 / **0** | 13.0/15 |
| F 交付可靠 | 5 / 5 / 5 / 5 / 5 | 10.0/10 |
| **质量合计（仅诊断）** |  | **95.6/100（A）** |

**证据与结论：**YouTube长视频数据按长视频独立统计；`互动率（按Views）=(点赞+评论)/Views`，留存含首30秒和植入段前后曲线，均为H。E4为0不是普通扣分，而是“未解决竞品排他”的硬门槛。**最终：暂停/淘汰，不推荐，不得以95.6分或低价替代排他处理。**交 Ops/Legal 核验排他期、地域、品类与书面解除；解除后重新评估。

### 案例二：粉丝大，但发现数据异常

**情境：**TikTok 80万粉创作者，美容品类。近20条播放均值看似可观，但中位播放低、区间很宽，评论多为重复泛化短语且语言与目标美国受众错配；后台受众与留存只提供无日期截图。

| 维度 | 子项原始档位（按表内顺序） | 折算分 |
|---|---|---:|
| A 受众匹配 | 1 / 1 / 1 / 3 | 7.0/25 |
| B 数据健康 | 1 / 1 / 1 / 1 / 1 | 4.0/20 |
| C 内容说服 | 3 / 3 / 1 / 3 / 3 | 10.0/20 |
| D 历史商单 | 1 / 1 / 1 | 2.0/10 |
| E 品牌安全 | 3 / 3 / 3 / 1 | 8.2/15 |
| F 交付可靠 | 1 / 3 / 3 / 3 / 1 | 4.4/10 |
| **质量合计** |  | **35.6/100（D）** |

**证据与结论：**TikTok按近20条统计中位播放、四分位区间、平均观看时长/视频时长、完播和 `ER（按Views）=(赞+评+分享+收藏)/Views`；证据为M/L。该案例只有异常疑点，**不得写“刷量”或直接指控**。商务结论为D、不推荐；保存异常样本，交 Ops 复核增长来源、单条受众地区、流量来源、完整后台和互动账号。若对方拒绝补通常可提供的核心证据，相关项保持0并人工复核。

### 案例三：受众匹配且稳定的微型创作者

**情境：**Instagram 4.2万粉户外徒步微型创作者，面向德国轻量露营用户。Reels、Feed、Stories分开取数；受众地区、语言和近期内容均为H/M，报价、档期和授权尚未由 Ops 确认。

| 维度 | 子项原始档位（按表内顺序） | 折算分 |
|---|---|---:|
| A 受众匹配 | 5 / 5 / 5 / 5 | 25.0/25 |
| B 数据健康 | 5 / 3 / 5 / 3 / 3 | 15.6/20 |
| C 内容说服 | 5 / 5 / 5 / 5 / 5 | 20.0/20 |
| D 历史商单 | 3 / 5 / 3 | 7.2/10 |
| E 品牌安全 | 5 / 5 / 5 / 5 | 15.0/15 |
| F 交付可靠 | 3 / 5 / 5 / 5 / 3 | 8.4/10 |
| **质量合计** |  | **91.2/100（A）** |

**证据与结论：**Reels以 `ER（按Reach）=(赞+评+分享+收藏)/Reach`，Feed另列保存率，Stories以链接贴纸点击/首帧Reach；三种格式不混算。尽管粉丝较少，目标地区、语言、内容场景、稳定发布和高质量互动更匹配项目。商务可推荐为A，并把报价、档期、素材/广告权、合同主体、排他与毛利作为**未确认的商业门槛**交 Ops；未经 Ops 批准，不能列为最终确认名单。

## 7. 运营交接与审计最小包

商务提交 Ops 的每位达人最小交接包应包含：

- 完整评分卡、原始质量总分/等级、最终推荐等级/门禁结果、硬门槛结论、红旗与中性事实描述；
- 原始档位、公式、样本窗口、互动率分母、内容格式与计算表；
- 每个核心子项的证据位置、抓取日期、H/M/L和未解决缺口；
- 最近10条相关有机、3–5条商单、最高/最低异常样本的链接或归档；
- 商务推荐理由、替补建议、需 Ops 复核的报价、档期、授权、身份、收款、排他和风险；
- Ops 最终名单结论、复核人、日期、例外批准及上线后回填链接。

Ops 完成最终专业验证、报价/排期/权利确认并批准最终名单前，商务只能表述“初筛推荐/待运营复核”，不得向客户表述为“已锁定”“已确认”或保证表现。
