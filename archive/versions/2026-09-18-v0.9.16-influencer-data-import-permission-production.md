## Explicit Data Boundary / 明确数据边界

The existing `influencers` inventory is a shared global resource and currently has no `org_id` ownership column. This release gates who may import into that inventory; it does not claim row-level tenant isolation. Adding organization ownership, migration/backfill rules, and cross-organization row tests remains a separate schema release under Phase 8. / 现有 `influencers` 主表是全局共享资源且没有 `org_id` 归属字段。本版限制谁可以向该资源导入，不宣称已经实现行级租户隔离；组织归属、迁移/回填规则及跨组织行测试继续作为 Phase 8 的独立 schema 版本实施。
