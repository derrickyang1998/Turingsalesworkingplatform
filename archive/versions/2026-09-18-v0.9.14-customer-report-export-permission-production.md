## Scope / 范围

**EN:** This release adds one organization-scoped action permission, `campaign.customer_report.export`, to the existing customer-report HTML and PPTX delivery paths. It does not change report ownership, sealing, preview, snapshot content, templates, schema, or any external write.

**中文：** 本版仅为既有客户报告 HTML 与 PPTX 交付路径增加组织范围动作权限 `campaign.customer_report.export`。报告归属、封存、预览、快照内容、模板、数据库结构和外部写入均未改变。

- Allowed / 允许：company owner, administrator, manager, and read-write member / 企业所有者、管理员、经理及可写成员。
- Denied / 拒绝：read-only member and platform-admin-only identity without a tenant export role / 只读成员及仅具平台管理员身份但无租户导出角色的账号。
- Denial / 拒绝结果：`403 CUSTOMER_REPORT_EXPORT_FORBIDDEN` before the delivery service and attachment bytes / 在交付服务与附件字节生成前拒绝。
- Audit failure / 审计失败：`503 CUSTOMER_REPORT_EXPORT_AUDIT_UNAVAILABLE`, with no attachment headers or bytes / 无附件头或附件字节。
- Audit events / 审计事件：`customer_report_exported` and `customer_report_export_denied` under module `campaign.customer_report`, with bounded metadata only / 仅保存有界元数据。
- Frontend / 前端：login and `/api/auth/me` project the action; dynamic HTML/PPTX controls are hidden or disabled without permission, and direct function calls reject before network access / 登录与当前用户接口投影权限，未授权界面和直接函数调用均失败关闭。
