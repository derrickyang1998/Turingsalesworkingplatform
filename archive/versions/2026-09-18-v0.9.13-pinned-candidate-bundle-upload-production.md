## Scope / 范围

**EN:** This release changes only the shared deployment transport. The immutable action plan still contains all 403 pinned files, but one deployment attempt now sends them through one deterministic binary stream and one SSH child process instead of creating one SSH process per file.

**中文：** 本版只修改共享部署传输。不可变动作计划仍包含全部 403 个钉住文件，但每次部署尝试改为通过一个确定性二进制流和一个 SSH 子进程传输，不再为每个文件单独建立 SSH 进程。

- Bundle framing uses `TMCB0001`, a record count, recomputed plan identity, per-record path/length/SHA-256/payload, and `TMCBEND1`. / 包帧包含固定头、记录数、重算计划身份、逐记录路径/长度/SHA-256/载荷及固定尾。
