## Root Cause / 根因

- The production host received verified Ubuntu security updates on 2026-09-10: Python 3.14 packages moved from the `.1` build to `.2`, and glibc from `.3` to `.4`. A fresh parser build therefore kept the same 3,476 files and 435 directories but changed 67 host-derived files and became exactly 4,419 bytes smaller. / 生产主机于 2026-09-10 安装了已核实的 Ubuntu 安全更新：Python 3.14 包由 `.1` 更新到 `.2`，glibc 由 `.3` 更新到 `.4`；因此新构建仍为 3,476 个文件、435 个目录，但有 67 个主机派生文件变化，总大小精确减少 4,419 字节。
- v0.8.21 correctly stopped before production mutation because the rebuilt tree no longer matched the previously pinned parser identity. This release treats the new identity as an explicit reviewed refresh, not as automatic acceptance of arbitrary host drift. / v0.8.21 因重建目录不再匹配旧钉住身份而在生产变更前正确停止；本轮把新身份作为经审查的明确刷新，而非自动接受任意主机漂移。
