## Delivery / 交付

- The current M3 PPT entry enriches `/api/ai/ppt-outline` with the active Campaign, audited demand and proposal conversation/message IDs, authorized knowledge IDs, request ID, and a stable business-input idempotency key. / 当前 M3 PPT 入口向大纲接口注入 Campaign、已审计需求与方案会话/消息、授权知识 ID、请求 ID 和稳定业务幂等键。
- Campaign outline generation is knowledge-only in this slice: web search is fixed off and caller input cannot widen the server retrieval limit of eight Campaign chunks. / 本切片固定仅使用知识库，调用方不能扩大服务端 8 个 Campaign 检索分块上限。
- The linked outline uses the shared AI/RAG service and atomically persists the conversation, paired messages, knowledge references, token/latency status, and one `ai_run` link. An unconfirmed outline is not archived. / 关联大纲复用统一 AI/RAG 服务并原子保存会话、成对消息、知识引用、token/延迟状态和一条 `ai_run` 关联；未确认大纲不归档。
- Duplicate generation is single-flight. Switching Campaign invalidates and aborts the old request, suppresses legacy proposal persistence, and prevents a stale response from rendering or mutating the new context. / 重复生成保持单飞；切换 Campaign 会使旧请求失效并中止，同时禁止旧方案持久化和陈旧响应渲染或改写新上下文。
- The stable idempotency fingerprint changes only with relevant Campaign, demand, proposal, knowledge, or outline input. Retrying the same business input replays the same audited result. / 稳定幂等指纹仅随 Campaign、需求、方案、知识或大纲业务输入变化；相同输入重试复用同一审计结果。
- Frozen `platform/ppt.js` remains byte-for-byte unchanged, and the unlinked legacy PPT path retains its prior search/archive behavior. / 冻结 `platform/ppt.js` 字节不变，未关联旧版 PPT 路径继续保持原有检索与归档行为。

## Audit Provenance / 审计来源

- Demand and proposal audit pairs are accepted only when the actor can read the conversation, the source module is exact, the message is the matching assistant message owned by that conversation, and every link/metadata value points to the same active Campaign. / 需求与方案审计对仅在会话可读、来源模块精确、消息为该会话 assistant 消息且所有关联/元数据均指向同一当前 Campaign 时接受。
- Foreign, incomplete, cross-Campaign, mismatched-message, or misleading audit provenance is rejected before provider work. / 外部、不完整、跨 Campaign、消息错配或误导性审计来源会在调用 Provider 前拒绝。
