# v0.2.9 Production Static Exposure Hotfix

- Date: 2026-07-12
- Branch: `codex/ai-knowledge-foundation`

- Backup: `/root/turingmarket/platform/backups/backup-v029-20260712-152827`

## Incident

The Express application exposed the entire `platform/` directory as static files. Anonymous HTTP requests could read backend source, the SQLite database and WAL file, and deployment scripts.

## Remediation

- Replaced broad static serving with an explicit public asset policy.
- Allowed only the UI entry files, required JSON data, registered SPA paths, and existing API routes.
- Added JSON `404` handling for unknown API routes.
- Added Nginx denial rules for backend directories, database paths, dotfiles, build files, and deployment files.
- Made Nginx installation transactional with candidate validation and rollback.
- Made session invalidation the default deployment behavior; 14 existing sessions were deleted and zero remained.
