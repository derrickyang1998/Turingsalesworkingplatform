## Recovery Incident / 恢复事件

- After cutover, the original accepted-release finalizer closed the public guard, which stopped Nginx, and later attempted only `systemctl reload nginx`. Reload cannot start an inactive service, so local deployment control ended with an error while production remained fail closed behind the exact `503` maintenance configuration. / 切换后，旧最终化流程关闭公网守卫并停止 Nginx，随后仅尝试 reload；reload 无法启动已停止服务，因此本地发布控制报错，而生产继续以精确 503 维护配置失败关闭。
- Nginx was restored only under the closed maintenance guard, the accepted run was finalized, the exact public Nginx gate passed, and the deployment lock was released. No database or business-data loss occurred. / Nginx 仅在 closed 维护守卫下恢复，已接纳运行完成最终化，精确公网 Nginx 门禁通过并释放发布锁；无数据库或业务数据丢失。
- The first controller patch was not accepted because its fallback could never work after arming. The final patch moves validated maintenance-listener startup before `arm`, retains a plain reload after the public swap, and adds executable success/rejection fixtures plus ordering assertions. / 首个控制器补丁因 arm 后回退不可执行而未被接受；最终补丁将经过验证的维护监听启动移至 arm 之前，公网切换后仍使用普通 reload，并新增可执行成功/拒绝夹具及顺序断言。

## Delivery Cadence / 交付节奏

- Every independently useful normal feature now ships in its own development round after exact affected tests, syntax/contract/secret checks, one independent approval, a verified backup, immediate production deployment, and focused online acceptance. / 每个可独立使用的普通功能在同一开发轮完成精确受影响测试、语法/合同/密钥检查、一次独立批准和可验证备份后，立即部署并完成线上定向验收。
- Exhaustive regression is not a default per-feature requirement. It remains mandatory only for phase closeout or risk triggers such as authentication, schema, tenant authority, shared deployment infrastructure, or real external writes. / 每功能不默认执行繁重全量回归；仅阶段收口，或认证、schema、租户权威、共享部署基础设施及真实外部写入等风险触发时扩展门禁。
