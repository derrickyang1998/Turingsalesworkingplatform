# v0.2.5 Brand Intelligence Workspace

Date: 2026-07-02
Branch: `codex/ai-knowledge-foundation`

## Scope

This release redesigns M1 Brand Library into a brand intelligence workspace while preserving the latest PPT UI and knowledge bridge baseline.

## Changes

- Replaced the old sparse brand-card layout with a three-zone workspace:
  - industry taxonomy and search history
  - searchable/sortable brand result list
  - right-side brand intelligence detail panel
- Added workspace stats for brand count, tag count, knowledge-ready records, and current filter count.
- Added selected brand state, detail rendering, knowledge status, content opportunity panel, social source cards, related/competitor brand chips, and demand/proposal handoff.
- Kept `AI Search` on the existing backend path:
  - `POST /api/brands/enrich`
  - `POST /api/brands`
  - backend brand archive through `business_knowledge_service.archiveBrand`
- Added static regression coverage for the M1 workspace and PPT bridge preservation.

## Protected Baseline
