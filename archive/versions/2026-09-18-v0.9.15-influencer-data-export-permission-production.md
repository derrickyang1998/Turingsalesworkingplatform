## Scope / 范围

It preserves the accepted import, search, column filters, saved views, Feishu, collaboration ordering, UI, schema, AI/knowledge, proposal, and frozen PPT behavior.

**中文：** 本版为既有网红 CSV 的全部、当前筛选和选中三种导出模式增加实时组织范围操作者权限 `influencer.data.export`。已验收的导入、搜索、逐列筛选、保存视图、飞书、合作下单、界面、数据库结构、AI/知识库、方案和冻结 PPT 均保持不变。

## Explicit Data Boundary / 明确数据边界

The existing `influencers` inventory is a shared global resource and currently has no `org_id` ownership column. This release gates who may export that inventory; it does not claim row-level tenant isolation. Adding organization ownership, migration/backfill rules, and cross-organization row tests is a separate schema release under the existing Phase 8 tenant-isolation work item. / 现有 `influencers` 主表是全局共享资源且没有 `org_id` 归属字段。本版限制谁可以导出，不宣称已经实现行级租户隔离；组织归属、迁移/回填规则及跨组织行测试继续作为 Phase 8 的独立 schema 版本实施。

The exact `POST /api/influencers/export` endpoint bypasses only the generic read-only mutation classifier so the stricter named permission can return its stable denial and persist a bounded audit. The exception never grants access by itself. / 精确导出端点仅跳过通用只读写入分类器，随后仍必须通过更严格的命名权限门禁；该例外本身不授予访问权。
