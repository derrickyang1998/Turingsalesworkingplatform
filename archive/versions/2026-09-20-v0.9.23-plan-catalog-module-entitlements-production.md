## Security And Data Contract / 安全与数据合同

- Catalog and entitlement rows are seeded as one exact immutable set. Database guards reject later insertion, update, deletion, or replacement, preventing runtime privilege expansion. / 套餐与权益按精确不可变集合初始化；数据库守卫拒绝后续插入、更新、删除或替换，防止运行时权限膨胀。
- Organization assignments form a contiguous append-only version history. Updating, deleting, replacing, skipping a version, or creating an organization without a current assignment fails closed. / 组织套餐分配形成连续仅追加版本历史；更新、删除、替换、跳号或创建无当前套餐的组织均失败关闭。
- Only a live platform administrator can assign a plan. The command checks the expected version in the same transaction, writes the new assignment, and records a bounded `organization_plan_assigned` audit event atomically. / 只有实时平台管理员可分配套餐；命令在同一事务检查期望版本、写入新分配并原子记录字段有界审计事件。
- All entitlement-controlled routes for the seven governed modules resolve current organization facts and entitlements on every request. Missing or inconsistent plan state denies the operation instead of reverting to browser or legacy defaults. / 七个受管模块的全部权益受控路由均在每次请求时解析当前组织事实和权益；套餐状态缺失或不一致时拒绝操作，不回退到浏览器或旧默认值。
