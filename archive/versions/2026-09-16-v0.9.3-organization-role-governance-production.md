## Delivered / 已交付

- Added immutable `organization_authority` and one-to-one `organization_member_policy` records without changing the existing platform, organization, or team role enums. Migration initializes an owner only when an organization has exactly one active platform-administrator member; ambiguous organizations remain unassigned for explicit initialization. / 新增不可变组织所有者与一对一成员策略记录，不修改既有角色枚举；仅在组织恰有一位有效平台管理员成员时确定性初始化所有者，存在歧义时保持未设置。
- Added live server projections for platform administrator, company owner, administrator, manager, member, and read-only roles. Platform administrators remain globally protected, company owners cannot be changed in this version, organization administrators cannot modify peer administrators, and manager assignment requires an active team. / 新增六类角色的实时服务端投影；平台管理员受保护、企业所有者本版不可变更、组织管理员不能修改同级管理员，经理必须已有有效团队。
- Added authenticated organization/member governance APIs with scoped search, status filtering, cursor pagination, session revocation, and transaction-bound audit records. Organization status changes preserve existing team assignment states. / 新增带组织范围、搜索、状态筛选、游标分页、会话撤销和事务审计的组织成员治理接口；组织成员启停不会改写既有团队授权状态。
- Added a central live read-only barrier for authenticated `POST`, `PUT`, `PATCH`, and `DELETE` requests. Logout remains available; a read-only platform administrator keeps narrowly scoped recovery access to platform administration and organization governance while ordinary business writes remain blocked. / 新增针对全部认证写方法的实时只读拦截；注销保持可用，异常只读平台管理员仅保留平台管理和组织治理恢复通道，普通业务写入仍被拒绝。
- Upgraded the accepted management UI in place to expose “组织与成员” to authorized owners and administrators, show the authoritative owner and role, and provide role/status controls only when the server projects the action as allowed. The latest CRM, M3/M4, AI/knowledge, influencer, Feishu, workflow, export, and frozen PPT paths remain intact. / 在现有管理界面原位升级组织成员治理，只有服务端明确允许时才显示可操作控件；其他业务功能与冻结 PPT 均保持不变。
