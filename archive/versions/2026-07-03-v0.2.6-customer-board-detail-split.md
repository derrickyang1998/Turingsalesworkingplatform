# v0.2.6 Customer Board / Detail Split

Date: 2026-07-03
Branch: `codex/ai-knowledge-foundation`

## Scope

This release splits the M0 CRM customer workspace into two independent interfaces: an operating board and a customer detail workspace. The goal is to preserve the latest UI baseline while removing the mixed dashboard/list layout from the customer library.

## Changes

- Replaced the single `客户库` sidebar entry with:
  - `客户看板`
  - `客户明细`
- Kept `page-m0` as the board-only customer operating center:
  - customer metrics
  - stage funnel
  - focus customer
  - AI insight
- Added `page-m0-detail` for operational customer work:
  - customer list
  - personal/team/admin scope filters
  - stage filters and search
  - public pool
  - opportunity board
  - customer add/edit modal path
- Updated workflow-task customer jump links to open `客户明细`, so the customer detail panel opens in the correct page context.
- Updated CRM page switching so the board refreshes stats/insights while the detail page initializes the selected list/public-pool/opportunity view.
