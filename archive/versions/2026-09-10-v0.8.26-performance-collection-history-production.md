## Delivered / 已交付

- Added a compact, collapsible recent-update history to the existing freshness section. It shows successful, partial, and failed content imports, metric imports, and manual metric updates without adding a page or changing the approved shell. / 在既有新鲜度区域增加紧凑、可折叠的最近更新记录，展示成功、部分完成和失败的内容导入、指标导入及人工指标补录，不新增页面，也不改变已批准壳层。
- Added the campaign-authorized read endpoint `GET /api/campaigns/:id/performance/collection-runs`. It projects existing append-only audit events into safe counts and timestamps while excluding file hashes, mapping names, provider payloads, credentials, and internal diagnostics. / 新增受活动权限约束的只读接口，将既有只追加审计事件投影为安全计数与时间，同时排除文件哈希、映射名称、服务商响应、凭据和内部诊断。
- The service accepts the null-prototype query objects used by Express 5, validates unknown query fields, verifies manual publication ownership against the current organization and campaign, and marks malformed audit counts as failed instead of successful. / 服务兼容 Express 5 的空原型查询对象，拒绝未知查询字段，按当前组织与活动核验人工补录内容归属，并将异常审计计数明确标记为失败。
- Database work is bounded to the newest 25,000 audit rows and the newest 5,000 matching history records. The response and UI disclose either truncation so older records cannot be mistaken for complete history. / 数据库读取限定为最近 25,000 条系统审计及最近 5,000 条匹配记录；接口与界面均披露截断状态，避免把有限窗口误认为完整历史。
