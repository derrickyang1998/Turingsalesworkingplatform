# 发布与分发流程 / Publishing & Distribution Workflow

> **主要平台:** 抖音 / 小红书 / 视频号
> **内容类型:** 10-13分钟深度人物专访长视频

---

## 一、发布前检查 / Pre-Publish Checklist

### 视频终稿检查
- [ ] 时长: 10-13分钟 (允许±30秒浮动)
- [ ] Hook (前3秒) — 足够强吗？
- [ ] 字幕校对 — 无错别字，金句已标注
- [ ] 配色一致性 — 黑白主色调
- [ ] Logo: "Derrick" 文字标识已添加
- [ ] Channel名称: "Derrick" (非 D's Lounge)
- [ ] 音乐版权检查 — 使用免版权素材
- [ ] 片尾引导 (关注/点赞/评论话术)

---

## 二、封面制作规范 / Cover Design

### 封面要素
- **人物:** 黑白肖像（高对比度）
- **关键词:** 大字（2-3个核心词）
- **期数:** EP0X 标注
- **嘉宾名 + 身份:** 小字标注

## 三、标题策略 / Title Strategy

### 标题公式
| 平台 | 风格 | 公式 |
|------|------|------|
| 抖音 | 悬念式 | [反常识观点] + [人物身份] |
| 小红书 | 清单式 | [数字] + [人群] + [痛点/收益] |
| 视频号 | 人物标签式 | [人物名]：[行业]的[X年] |

### 标题示例 / Title Examples

`
抖音:
- "做了15年Google优化，她发现大部分出海品牌都在浪费钱"
- "从工地到千人大会，一个农村小伙的SEO十年"

小红书:
- "跟500个出海品牌聊完，Lisa总结了3个致命错误"
- "若凡：写了200万字后，我敢说SEO不是玄学"

视频号:
- "若凡Devin：跨境SEO的十年破局之路"
- "Lisa郭美珠：中国第一批Google优化师的15年"
`

## 四、标签策略 / Hashtag Strategy

### 通用标签 (每期必加)
`
#跨境电商 #品牌出海 #人物专访 #出海营销
`

### 嘉宾专属标签
`
EP01: #GEO #Google优化 #独立站出海
EP02: #Gordon #小棉花 #出海增长
EP03: #Rhea
EP04: #若凡 #SEO #出海SEO
EP05: #Lisa #艾维广告 #Google广告
`

### 平台差异
- **抖音:** 3-5个标签，前2个最重要
- **小红书:** 5-8个标签，加#职场 #创业 等泛标签
- **视频号:** 2-3个标签，偏行业精准

## 五、发布时间 / Publishing Schedule

### 最佳发布时段 (北京时间)
| 平台 | 最佳时段 | 次优时段 |
|------|----------|----------|
| 抖音 | 12:00-13:00 / 18:00-19:00 | 20:00-22:00 |

| 视频号 | 8:00-9:00 / 12:00-13:00 | 20:00-21:00 |

### 发布节奏
- **首发:** 抖音 (最大流量池)
- **1小时后:** 小红书
- **2小时后:** 视频号
- **第二天:** 在个人朋友圈/微信群转发

## 六、发布后运营 / Post-Publish Operations

### 首日 (0-24h)
- [ ] 发布后1小时内在评论区置顶引导评论
- [ ] 回复前50条评论
- [ ] 在嘉宾社群/朋友圈联动转发
- [ ] 监测数据：播放量、完播率、互动率

### 第2-7天
- [ ] 根据数据表现决定是否追投 (dou+/薯条)
- [ ] 截取金句片段发短视频 (15-60秒) 做二次传播
- [ ] 小红书同步发图文版访谈精华

### 长期
- [ ] 将嘉宾金句整理到知识库
- [ ] 更新嘉宾名录和状态
- [ ] 分析数据：本期 vs 往期对比
