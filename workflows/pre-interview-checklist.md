# 访前准备清单 / Pre-Interview Checklist

> **使用时机:** 每次访谈拍摄前 1 周开始准备
> **负责人:** Derrick (主持 & 制片)

---

## 一、拍摄前 1 周 / 1 Week Before

### 嘉宾沟通
- [ ] 发送**嘉宾准备稿** (包含访谈主题、板块结构、希望多讲/少讲的内容)
- [ ] 确认嘉宾已阅，收集反馈（哪些想谈、哪些想避开）
- [ ] 确认拍摄地点（建议在嘉宾办公室/工作场景）
- [ ] 确认拍摄时间（建议留出2-3小时，实际拍摄60-90分钟）
- [ ] 沟通着装建议（商务休闲，有质感）

### 内容准备
- [ ] 完成**主持人脚本/口播稿**（问题大纲 + 板块过渡语）
- [ ] 研究嘉宾背景：履历、过往采访、社交媒体
- [ ] 准备"敲门问题" — 能让他/她眼前一亮的第一个问题
- [ ] 准备"情感触发器" — 至少1个能让嘉宾停顿思考的问题

### 设备检查
- [ ] 相机/手机：确认存储空间、电池
- [ ] 麦克风：测试收音效果
- [ ] 灯光：确认现场光源，必要时带补光灯
- [ ] 备用设备：备用电池、备用SD卡

---

## 二、拍摄前 1 天 / 1 Day Before

- [ ] 再次确认时间地点
- [ ] 给嘉宾发温馨提醒（明天见，大概2-3小时，放轻松）
- [ ] 检查天气预报（如需外景）
- [ ] 设备全部充电
- [ ] 导出入住：清空存储卡

---

## 三、拍摄当天 / Shoot Day

### 到场后（提前30-45分钟）
- [ ] 提前到场，感受空间氛围
- [ ] 观察环境中可用作叙事元素的细节（桌上的书、墙上的白板、团队状态）
- [ ] 确定拍摄机位 — 让嘉宾在舒适位置，不要面壁
- [ ] 测试灯光和收音
- [ ] 正式开机前与嘉宾闲聊10-15分钟，建立信任

### 拍摄中
- [ ] ✅ 听比问重要 — 追问细节，不急着进入下一个问题
- [ ] ✅ 允许沉默 — 情感类问题不催
- [ ] ✅ 控制专业术语 — "用外行能听懂的话讲一遍"
- [ ] ✅ 当嘉宾进入"讲师模式"时用情感问题拉回
- [ ] ❌ 不要替嘉宾总结/下结论
- [ ] ❌ 不要问刻板印象问题
- [ ] ❌ 不要追问明显不想谈的话题
- [ ] 每完成一个板块，稍作休息，喝水，调整状态

### 收工后
- [ ] 感谢嘉宾
- [ ] 问嘉宾感受 — 收工后往往有彩蛋
- [ ] 如果嘉宾说了精彩的话，问"能补录一下吗？"
- [ ] 确认后续剪辑沟通流程（何时看初稿、是否有修改权）

---

## 四、拍摄后 / Post-Shoot

### 当天
- [ ] 素材备份（双备份：电脑 + 硬盘/云盘）
- [ ] 简要笔记：哪些段落印象深刻、哪些有剪辑价值

### 48小时内
- [ ] 素材导入剪辑软件
- [ ] 音频转逐字稿（AI工具 + 人工校对）
- [ ] 发给嘉宾确认是否有需要删除的部分

### 1周内
- [ ] 完成逐字稿分析
- [ ] 输出4个剪辑方案
- [ ] 选定方案 → 进入粗剪

## 五、常见问题预案 / FAQ

**Q: 嘉宾紧张怎么办？**
→ 先闲聊，不要一上来就开机。如果是双机位，先开"备用机位"让嘉宾适应。

**Q: 嘉宾进入"讲师模式"怎么办？**
→ 用情感类问题打断："你当时累不累？""你后悔过吗？""有没有人质疑过你？"

**Q: 嘉宾回答太简短怎么办？**
→ 追问"那具体是什么样？""比如说？""然后呢？" 用具体场景引出故事。

**Q: 设备出问题怎么办？**
→ 立刻换备用设备。真诚告知嘉宾"设备出了点小问题，我们稍等一下"，反而能拉近距离。
