# 视频剪辑工作流 / Video Editing Workflow

> **目标平台:** 抖音 / 小红书 / 视频号
> **成片时长:** 10-13分钟（单条长视频）
> **参考风格:** 程前朋友圈

---

## 一、剪辑全流程 / Full Editing Pipeline

`
原始素材 (60-90min 访谈)
    │
    ├── 1. 音频转逐字稿 (AI转录 + 人工校对)
    │      工具: 飞书妙记 / 剪映 / Whisper
    │
    ├── 2. 逐字稿分析 → 确定价值方向
    │      输出: 内容价值判断报告
    │
    ├── 3. 剪辑方案设计 (4个方案)
    │      - 3个单一价值方向方案
    │      - 1个综合方案
    │      每个方案标注时间点和剪辑理由
    │
    ├── 4. 粗剪 (按选定方案剪出骨架)
    │      工具: 剪映 / Premiere Pro
    │
    ├── 5. 精剪 (节奏调整 + 情绪强化)
    │
    ├── 6. 后期 (字幕 + 调色 + 音效 + BGM + Logo)
    │      配色: 黑白为主
    │      Logo: "Derrick" 文字为主 (弱化图标和罗盘)
    │
    ├── 7. 封面制作
    │      风格: 黑白人物 + 关键词大字
    │
    └── 8. 发布 + 分发
`

## 二、剪辑方案设计原则 / Editing Plan Design Principles

### 4个方案法则 (从 Claude Code 对话中确立)

每个访谈素材至少输出4个剪辑方案：

| 方案 | 类型 | 说明 |
|------|------|------|
| 方案一 | 单一价值方向 A | 例如："创业逆袭"叙事线 |
| 方案二 | 单一价值方向 B | 例如："行业干货/方法论"叙事线 |
| 方案三 | 单一价值方向 C | 例如："情感/人性"叙事线 |
| 方案四 | 综合方案 | 多线交织，完整人物画像 |

### 方案格式要求

每个方案必须包含：
- **方案名称:** 清晰描述方向
- **目标受众:** 谁会看这个？为什么会看完？
- **剪辑时间点:** 格式 分:秒-分:秒
- **剪辑理由:** 为什么保留/删除这一段？（需满足至少1项病毒传播要素）

### 病毒式传播要素 (每段保留内容至少满足1项)

1. **信息差:** "原来如此" — 普通人不知道的行业内幕
2. **情感共鸣:** "这说的就是我" — 能代入的叙事
3. **身份认同:** "我们XX人就是这样" — 圈层认同
4. **争议性:** "我不认同但我想听听" — 有立场
5. **实用价值:** "看完就能用" — 可操作的干货

## 三、剪辑技术规范 / Technical Specifications

### 时间分配 / Time Allocation
| 时间段 | 内容 | 关键点 |
|--------|------|--------|
| 0:00-0:30 | Hook | 最有冲击力的一句话/画面 |
| 0:30-3:00 | 人物引入 | 快速建立"他是谁" |
| 3:00-8:00 | 核心叙事 | 转折点、具体故事 |
| 8:00-11:00 | 升华 | 反思、行业观点 |
| 11:00-13:00 | 收尾 | 一句话总结、情绪闭环 |

### 字幕规范
- 关键金句放大/变色强调
- 嘉宾人名标注在首次出场
- 行业术语需加简要注释（方便外行观众）

### 视觉风格
- **主色调:** 黑白
- **Channel标识:** "Derrick" 文字Logo（弱化图标和罗盘）
- **字幕字体:** 简洁现代（如思源黑体/阿里巴巴普惠体）
- **封面:** 黑白人物肖像 + 关键词大字 + 期数标注
