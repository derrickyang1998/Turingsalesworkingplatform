# v0.9.15 Influencer Data Export Permission / 网红数据导出权限

## Goal / 目标

Ship one bounded Phase 8 permission slice: require the live organization-scoped
`influencer.data.export` action before delivering the existing influencer CSV
export.

交付一个独立的 Phase 8 权限切片：现有网红 CSV 导出在交付前，必须通过实时
组织范围的 `influencer.data.export` 权限。

## Product Contract / 产品契约

- Writable company owners, organization administrators, managers, and members
  may export influencer data.
- Read-only and platform-admin-only identities may not export.
- All, filtered, and selected export modes retain their current filtering,
  active-row, approved-header, and empty-selection behavior.
- Denied and completed exports write bounded audit evidence. Audit failure is
  fail-closed before response headers or CSV bytes leave the server.
- The exact influencer export endpoint passes the generic read-only mutation
  classifier so its stricter named permission gate can deny and audit it. This
  exception never grants export access by itself.
- The current influencer inventory is a shared global dataset with no
  organization ownership column. This release gates the actor's export action;
  row-level tenant isolation requires a separate schema migration.
- Import, saved views, table columns, Feishu synchronization, collaboration
  ordering, database schema, PPT generation, and the current UI layout remain
  unchanged.

- 可写的企业所有者、组织管理员、经理和成员可以导出网红数据。
- 只读账号和仅平台管理员身份不得导出。
- 全部、当前筛选、选中三种导出模式继续保持现有筛选、仅活动数据、批准表头及
  空选中集语义。
- 拒绝与完成的导出均写入有界审计；审计不可用时，在响应头或 CSV 字节发出前
  失败关闭。
- 网红导出精确端点跳过通用只读写入分类器，交由更严格的命名权限门禁拒绝并
  记录审计；该例外本身不授予任何导出权限。
- 当前网红主表是没有组织归属字段的全局共享数据集。本版本限制操作者的导出
  动作；行级租户隔离需要单独的数据结构迁移。
- 导入、保存视图、表格字段、飞书同步、下单合作资源、数据库结构、PPT 生成及
  当前 UI 布局均不变。

## Test-First Tasks / 测试优先任务

1. Add failing policy tests for writable, read-only, platform-only, and malformed
   organization scopes.
2. Add failing route tests proving authorization precedes export, bounded audit
   evidence is emitted, and audit failure never leaks headers or bytes.
3. Add failing login and `/api/auth/me` projection assertions.
4. Add failing frontend contract checks for permission-aware controls and direct
   call guards.
5. Implement the smallest runtime wiring, run exact affected tests, obtain an
   independent review, back up production, deploy immediately, and perform
   focused online acceptance.

## Acceptance / 验收

- Requests denied by the named permission return `403 INFLUENCER_EXPORT_FORBIDDEN`
  without invoking the exporter or emitting attachment headers/bytes.
- Audit failure returns `503 INFLUENCER_EXPORT_AUDIT_UNAVAILABLE` before any CSV
  headers or bytes are sent.
- Allowed exports retain the existing CSV content contract for all three modes.
- The login and `/api/auth/me` projections expose `influencer.data: ['export']`
  for writable members and an empty action list for read-only members.
- The current M4 layout, import workflow, Feishu workflow, and PPT flow remain
  intact.
