# Token Usage Tenant Ownership Implementation Plan / Token 用量租户归属实施计划

> Ship one independently useful function, run only affected tests plus required schema/tenant gates and one independent review, then back up and deploy immediately. / 每轮只交付一个可独立验收功能，仅执行受影响测试、Schema/租户必要门禁和一次独立审查，随后立即备份上线。

**Goal / 目标:** Release schema v26 so every AI token ledger row has immutable organization ownership and ordinary reads/quotas cannot cross the active organization. / 发布 schema v26，使每条 AI Token 台账都具备不可变组织归属，普通读取和额度计算不得跨越当前组织。

**Architecture / 架构:** Backfill `token_usage.org_id` from the authoritative performance-review audit when available; use the sole historical organization only when the database has exactly one organization; fail closed for unresolved multi-organization history. All runtime writers use one server-side token usage service, and platform-wide reads require an explicit audited admin mode. / 优先依据权威绩效复盘审计回填 `token_usage.org_id`；仅当历史库只有一个组织时才允许默认归属；多组织历史数据无法确定时中止迁移。所有运行时写入统一经过服务端 Token 用量服务，全平台读取必须由管理员显式开启并写审计日志。

## In Scope / 本轮范围

- Add and register migration `026_token_usage_tenant_ownership`.
- Add immutable organization ownership, tenant indexes, append-only ledger guards, and organization-aware performance audit validation.
- Centralize token writes, active-organization reads, user quota totals, and explicit global admin aggregation.
- Pass trusted organization context through AI chat, one-shot generation, PPT outline, brand enrichment, and performance analysis/review.
- Update the admin token view to request explicit global audit mode.
- Advance exact sanitizer, trusted-source, migration, deployment, and replay inventories to schema v26.

## Out of Scope / 本轮不做

- No quota-plan redesign, billing price rules, payment settlement, vector database, UI redesign, or PPT renderer changes.
- No broad unrelated browser/PPT regression suite in this round.

## Acceptance / 验收

- Existing single-organization history migrates deterministically; authoritative multi-organization audit links migrate correctly; unresolved multi-organization history aborts without partial schema changes.
- New token rows derive organization ownership from server context, reject invalid membership, and cannot be updated or deleted.
- Ordinary users only read and consume quota inside the active organization; platform admins only get global aggregation with `admin_audit=global`, and that access is logged.
- Focused migration/runtime/release tests, syntax checks, SQLite integrity/FK checks, one independent review, production backup, deploy, and remote smoke tests pass.
