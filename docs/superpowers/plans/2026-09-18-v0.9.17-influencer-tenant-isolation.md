## Global Constraints

- Preserve the accepted latest UI, import template, field mapping, saved views, Feishu fallback, AI/knowledge behavior outside new batch namespacing, proposal/report flows, and frozen PPT bytes.
- Never trust an organization ID supplied by the browser; use only live `req.authContext` or Campaign access facts.
- Preserve all v22 influencer IDs and legacy column values; migration must fail before commit on ambiguous default organization or projection drift.
- Ordinary feature tests remain focused, but schema v23 triggers the approved migration/sanitizer/replay risk gates.
- Do not perform real external Feishu writes during tests or production acceptance.
