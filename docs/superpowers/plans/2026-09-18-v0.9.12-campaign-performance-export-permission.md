# v0.9.12 Campaign Performance Export Permission

## Goal

Ship one Phase 8 permission slice: require the live organization-scoped
`campaign.performance.export` action for the existing campaign performance CSV
and approved Feishu snapshot CSV downloads.

## Product Contract

- Writable company owners, organization administrators, managers, and members
  may pass the named permission gate.
- Read-only and platform-admin-only identities may not export.
- The named permission is necessary but not sufficient. Existing campaign
  organization, owner, and team custody checks remain authoritative.
- The Feishu snapshot keeps its stricter owner/organization-admin management
  requirement and approved-mapping requirement.
- No schema, influencer export, customer report, PPT, or external Feishu write
  changes are included.

## Test-First Tasks

1. Add failing central policy tests for writable, read-only, platform-only, and
   malformed organization scopes.
2. Add failing route tests proving both download endpoints authorize before an
   exporter runs and record bounded denial evidence.
3. Add failing login and `/api/auth/me` projection assertions.
4. Add failing frontend contract checks for hidden controls and direct-call
   guards.
5. Add the missing bodyless request contract for content CSV export.
6. Implement the smallest runtime wiring, run affected tests, obtain an
   independent review, then back up and deploy production.

## Acceptance

- Denied requests return `403 PERFORMANCE_EXPORT_FORBIDDEN`, emit no CSV headers
  or bytes, and do not call either exporter.
- Audit failure returns `503 PERFORMANCE_EXPORT_AUDIT_UNAVAILABLE` before data
  leaves the server.
- Existing filtered/all behavior, row limit, BOM, formula protection,
  commercial redaction, and Feishu approved projection remain unchanged.
- The current UI and frozen `ppt.js` remain intact.
