# 图灵集市商务新人红人营销知识与认证体系设计

- 设计日期：2026-09-08
- 状态：待用户评审
- 适用对象：商务新人、商务主管、参与方案评审的运营与策略人员
- 对应流程：《商务团队客户全生命周期与日常作业 SOP v2.0》培训章节
- 已确认能力边界：商务负责达人初筛、推荐逻辑与重大风险识别；运营负责最终达人名单专业复核

## 1. 背景与问题

现有五周培养计划列出了学习主题，但平台、产品、达人和营销基础集中在第一周，缺少统一判断模型、分层教材、实战校准和可量化认证。两本内部手册已有大量知识素材，但部分平台功能、内容名称、用户数据、价格和互动率会快速变化，也存在把经验判断写成普遍结论的风险。

本设计把培训从“阅读资料和背话术”升级为“能理解、能判断、能实操、能说明边界、能通过认证”的知识系统。

## 2. 目标与成功标准

完成培训的商务新人应能够：

1. 从客户目标、受众、产品和商业模式出发诊断营销问题。
2. 解释不同平台在发现、信任、转化和复购链路中的角色。
3. 根据产品购买阻力提出有条件的平台、达人与内容假设。
4. 使用统一评分卡完成达人初筛并识别一票否决风险。
5. 设计基本的内容、CTA、链接、数据和归因路径。
6. 区分平台事实、图灵经验、项目假设和未经验证的数据。
7. 在客户沟通中不做效果、价格、资源或平台能力的绝对承诺。

正式独立上岗门槛：理论考试不低于 85 分，红线题全部正确；平台与产品案例不低于 80 分；达人评估实操不低于 85 分；Roleplay 不低于 80 分；完整项目答辩无重大漏判。

## 3. 设计原则

### 3.1 先看客户生意，再选平台

统一决策链：

客户目标 → 目标市场与受众 → 产品购买阻力 → 平台角色 → 达人类型 → 内容证据 → 商业合作形式 → 链接与转化路径 → 指标与归因 → 合规和风险

平台和达人不是起点。新人不得仅凭行业名称、粉丝量或通用互动率做推荐。

### 3.2 稳定知识与动态知识分层

| 层级 | 内容 | 更新频率 |
|---|---|---:|
| 稳定原则层 | 营销漏斗、产品诊断、指标公式、达人评估方法、合规原则 | 半年或制度变化时 |
| 平台事实层 | 内容格式、链接能力、商业工具、数据字段、市场和账号限制 | 每季度，提案前复核 |
| 图灵基准层 | 报价、CPM、CPE、回复率、交付率、转化和毛利 | 每月或每季度 |
| 案例经验层 | 行业打法、达人组合、内容假设、失败原因 | 每个项目复盘后 |

用户量、互动率、达人报价和 ROI 不作为闭卷背诵题，也不得直接成为客户承诺。

### 3.3 学、判、练、考闭环

每个知识模块都必须同时包含：

- 学：概念、框架和来源。
- 判：判断题、反例和边界条件。
- 练：真实账号、真实内容或脱敏项目练习。
- 考：评分标准、合格线和红线题。

## 4. 交付物架构

### 4.1 主培训手册

拟新建：《商务新人海外红人营销基础培训手册 v1.0》。手册包含：

1. 营销基础与客户生意理解
2. 红人营销在完整营销体系中的作用
3. 平台选择与内容机制
4. 产品—平台—达人—内容匹配
5. 达人质量判断
6. 商业合作形式、链接与转化路径
7. 指标、归因与项目经济性
8. 合规、版权、授权和品牌安全
9. 行业案例与错误示范
10. 五周课程与认证规则

### 4.2 动态平台档案卡

每个平台使用完全一致的字段，避免不同章节各讲一套：

1. 平台定位和用户使用心智
2. 平台特性：流量分发、社交关系、搜索属性、内容节奏和商业化成熟度
3. 主要受众：年龄、地区、语言、兴趣、购买力及使用场景
4. 发现机制：搜索、推荐、关注、话题、视觉搜索或社区
5. 内容类型、内容寿命和原生内容语法
6. 各内容类型对应的商业合作形式
7. 常规商业合作要求与平台资格
8. 链接能力：可放位置、是否可点击、资格及地区限制
9. 转化路径：从内容触达到站内或站外成交的完整路径
10. 创作者合作、广告授权和付费放大能力
11. 核心数据、指标定义及不可直接比较的指标
12. 适合的客户目标、产品条件和达人类型
13. 局限、品牌安全、披露、版权和监管风险
14. 官方来源、核验日期、适用市场和维护 Owner

### 4.3 产品适配案例库

覆盖公司常见行业：3C、储能、智能家居、美妆、户外、出行与 eBike、医疗健康、宠物。每个案例按同一结构编写：

- 产品、价格、市场和购买场景
- 核心购买阻力
- 可视化速度与解释深度
- 主平台、辅助平台及分工
- 推荐达人原型和排除条件
- 内容证据、CTA和链接
- 预算与测试假设
- 合规、物流、样品和归因风险
- 正确答案、可接受替代方案和错误答案

行业矩阵只能作为起始假设；同一行业内不同价格、功效、合规和使用场景的产品必须重新判断。

### 4.4 达人质量评分卡

采用“硬门槛＋100分评分＋证据置信度”：

| 维度 | 权重 |
|---|---:|
| 目标市场与受众匹配 | 25 |
| 数据真实性与稳定性 | 20 |
| 内容创作与产品说服能力 | 20 |
| 历史商单表现 | 10 |
| 品牌安全与合规 | 15 |
| 沟通及交付可靠性 | 10 |

价格、档期、授权和项目毛利属于商业可行性门禁，不计入“质量分”，避免把便宜误认为优质。

证据置信度分为：

- H：平台后台或可核验导出，包含账号、周期和提取日期。
- M：第三方工具与公开内容可以交叉验证。
- L：只有主页公开数字或达人自述。

伪造数据、身份与收款主体严重异常、拒绝必要披露、重大品牌安全问题、竞品排他冲突、可核实跑单或恶意删商单为一票否决。

### 4.5 题库与Roleplay

拟保留原《商务新人 Roleplay—销售场景模拟考核方案》作为历史版本，另建 v2.0。新版增加：

- 平台判断题
- 产品适配题
- 达人评分校准题
- 指标与归因计算题
- 链接、授权与商业披露题
- 客户信息不足时的追问题
- 绝对承诺、效果保证和过时平台口径扣分规则

- TikTok
- Instagram

### 5.2 标准扩展平台

必须完成完整档案卡和至少一个适用场景：

- Facebook

### 5.3 特殊场景平台

## 6. 平台档案的商业化内容标准

每个平台必须逐项判断以下合作形式是否成立、怎样成立以及需要什么权限：

| 合作形式 | 培训要点 |
|---|---|
| 赠品与测评 | 是否保证发布、是否需要披露、样品退还和税务责任 |
| 付费原生发布 | 内容格式、修改权、发布时间、保留期和数据回传 |
| Dedicated/Integration | 独立内容与植入内容的适用场景、时长、位置和排他 |
| UGC内容生产 | 达人是否发布、素材交付规格、剪辑权、署名和使用范围 |
| 佣金与联盟 | 链接或折扣码、归因窗口、退货冲回、付款和披露 |
| 直播与站内电商 | 市场、账号、类目、库存、客服、结算和平台资格 |
| 长期品牌大使 | 内容频次、排他、品牌安全、复盘和续约 |
| 付费放大 | Spark Ads、Partnership Ads、品牌合作访问或其他授权 |
| 素材授权 | 平台、地域、期限、媒体、剪辑、字幕、翻译和转授权 |
| 活动与社区合作 | AMA、Spaces、群组、直播、线下活动和社区规则 |

“常规合作要求”至少包括：账号与身份、合同主体、报价和税费、交付物、修改轮次、发布时间、内容保留、披露、链接、数据回传、素材和广告授权、竞品排他、取消与延期、付款节点、平台和地区限制。

## 7. 链接与转化路径设计

每个平台不得只写“可以放链接”或“不可以放链接”，而要记录：

1. 链接出现在哪里。
2. 是否可点击。
3. 是否需要账号、地区、粉丝量、广告或商店资格。
4. 自然内容与付费内容是否不同。
5. 是否支持商品标签、站内店铺或联盟商品。
6. 如何进行 UTM、折扣码、联盟链接、Pixel/CAPI或平台内归因。
7. 用户点击后经过哪些页面和摩擦点。

统一转化链表达：

内容触达 → 有效观看或互动 → 主页/描述/贴纸/商品标签/评论等入口 → 平台店铺或站外落地页 → 商品详情 → 加购或留资 → 支付 → 退货期结束 → 有效收入与毛利

平台档案必须区分：

- 站内闭环：内容 → 商品标签/直播/平台商店 → 支付。
- 站外转化：内容 → 可点击链接/主页 → 独立站或亚马逊 → 支付。
- 辅助归因：折扣码、品牌搜索提升、直接流量和调研。
- 长决策转化：内容 → 搜索/比较/多次触达 → 数天或数周后成交。

## 9. 五周培养重构

| 周期 | 知识模块 | 实战任务 | 验收标准 |
|---|---|---|---|
| 第1周 | 营销基础、客户旅程、品牌阶段、指标、归因、合规和公司服务 | 拆解两个项目的目标、购买阻力和KPI树 | 理论≥85，红线题100% |
| 第2周 | 核心和扩展平台的受众、内容、商业合作、链接及转化路径 | 为同一产品完成三平台分工；拆解10条平台原生内容 | 平台案例≥80，无绝对化承诺 |
| 第3周 | 产品适配、达人原型、达人评分、异常识别和商业可行性 | 完成3个产品策略和10张达人评分卡 | 达人实操≥85，重大红旗零漏判 |
| 第4周 | 客户研究、需求诊断、CRM、方案、报价、异议和承诺边界 | 陪访、需求会Roleplay和初步方案 | Roleplay≥80，CRM和证据完整 |
| 第5周 | 从线索到交接的完整商业闭环 | 完成研究、诊断、平台策略、达人短名单、方案和交接答辩 | 无重大流程、合规或承诺错误 |

## 10. 来源权威与维护治理

### 10.1 权威顺序

1. 法律法规和平台官方政策、Help、Business与Creator文档。
2. 图灵CRM、财务和项目复盘形成的内部真实数据。
3. 经Owner批准的公司手册、标准和案例。
4. 可信第三方行业研究。
5. 未验证文章、达人自述和经验数字，只能作为线索。

### 10.2 维护规则

- 平台档案必须标记核验日期、来源链接、适用国家和账号条件。
- 平台 Owner 每季度检查格式、链接、商店、广告授权、音乐和披露变化。
- 正式客户提案前，Sales或Strategy再次核验目标市场的功能可用性。
- 报价、CPM、互动率和转化基准优先使用同市场、同品类、同量级、同格式的内部数据。
- 每个结论标记为：官方事实、内部事实、经验判断或项目假设。
- 过时内容保留版本记录，但不得继续出现在当前速查卡。

## 12. 质量控制与验收

### 12.1 内容验收

- 所有12个平台都有定位、受众、内容、商业化、要求、链接、转化、指标和风险。
- 核心3个平台具备完整案例和考试题。
- 8个重点行业各有至少一个条件式案例。
- 达人评分卡字段、权重、红旗、证据置信度和复核边界完整。
- 五周课程的每周产出都有量化评分标准。

### 12.2 事实验收

- 动态平台事实仅引用截至编写日期仍有效的官方来源。
- 不保留“永远最好、一定爆、一定转化最高、固定价格”等绝对结论。
- 不同平台和内容格式的观看、触达与互动指标不直接混算。
- 平台市场、账号、类目和资格限制被明确标记。
- 商业披露、音乐、素材权、广告权和链接资格均有风险提示。

### 12.3 文件验收

- Markdown使用UTF-8，表格、链接、标题和代码围栏结构通过检查。
- 新版文件不覆盖或删除旧版。
- 工作区和Obsidian归档副本哈希一致。
- 版本记录说明日期、状态、来源、主要变化和后续维护Owner。

## 13. 已批准的默认决策

1. 采用独立培训手册和平台档案，不把全部知识塞入主SOP。
2. 平台以核心、标准扩展、特殊场景三级组织。
3. 商务达到达人初筛与风险识别能力，运营保留最终复核责任。
4. 平台数据、价格和互动率作为动态信息，不作为固定答案。
5. 采用条件式产品匹配，不使用“行业等于平台”的死规则。
6. 新版文件与旧版并存，完成后再由受控版本替代。
