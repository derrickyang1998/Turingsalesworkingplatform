## Delivery And Scope / 交付与范围

- Migration 029 adds a contiguous, append-only organization AI quota policy. `null` is unlimited, `0` disables organization AI, and a positive safe integer is the UTC calendar-month token limit; existing and new organizations remain unlimited by default. / 迁移 029 新增连续、仅追加的组织 AI 配额策略；`null` 表示不限、`0` 表示停用、正安全整数表示 UTC 自然月 Token 上限，现有及新建组织默认不限。
- Central admission now evaluates live identity and membership, organization monthly shared quota, and then the personal legacy lifetime backstop before every trusted DeepSeek path. Organization usage comes from immutable tenant-owned token rows and does not depend on current membership. / 中央准入依次校验实时身份与成员关系、组织月度共享配额及个人历史终身配额兜底；组织用量来自不可篡改的租户归属 Token 记录，不依赖当前成员关系。
- `GET /api/organization-ai-quota` exposes member status. `PUT /api/admin/organizations/:organizationId/ai-quota` is platform-admin-only, exact-body validated, strict-number checked, optimistic-concurrency protected, atomic, and audited. / 成员查询返回组织配额状态；更新入口仅平台管理员可用，具备严格请求体、数字类型、乐观并发、原子操作及审计保护。
- The Admin organization directory shows monthly usage, limit, state, UTC boundary, overage, utilization, and compact editing. Personal quota remains explicitly labeled as lifetime. / 管理控制室组织目录展示本月用量、上限、状态、UTC 边界、超额、利用率及紧凑编辑控件；个人配额继续明确标注为终身配额。
- The legacy no-Campaign PPT path now performs quota admission before RAG, Tavily, or LLM work and honors explicit `allowWeb`; denied requests create no conversation, knowledge, token-usage, or web-cache writes. / 旧无 Campaign PPT 路径现会在 RAG、Tavily 或 LLM 前完成配额准入并遵循显式 `allowWeb`；被拒请求不产生对话、知识、Token 用量或联网缓存写入。
- This is a soft monthly limit. Persistent concurrent reservation, a hard concurrency overage bound, billing, pricing, and dynamic catalog editing remain outside this release. The accepted CRM, M3/M4, AI/knowledge, proposal/report, and frozen PPT interfaces are unchanged. / 本版为月度软上限，不包含持久并发预留、并发超额硬边界、账单、价格和动态套餐编辑；已验收业务界面未回退。
