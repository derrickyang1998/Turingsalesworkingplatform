# v0.2.1 - AI Knowledge Vault Bridge

日期：2026-06-30

## 目标

把平台的 AI 对话、业务动作、Obsidian 资料和平台方案产出串联进统一知识库，并提供一个可在平台后台管理、可导出到本地 Markdown Vault 的知识管理能力。

## 主要变更

- 新增统一业务归档服务，覆盖 CRM 线索、客户、商机、品牌画像、达人档案、合作记录、工作流模板/实例/任务动作。
- 新增 Obsidian 导入服务，默认读取 `D:\主盘\图灵集市`，支持 dry-run，跳过私密目录和疑似密钥文件。
- 新增平台 Vault 导出服务，默认写入 `D:\图灵商务在线平台`，按 `entry_type/source_type` 生成 Markdown 文件和 `知识库索引.md`。
- 导入/导出路径必须落在服务端白名单根目录内，并有文件数、目录深度、单文件大小和总读取字节限制。
- Admin 知识库页增加 Obsidian 导入、平台 Vault 导出、业务来源、业务对象、更新时间展示。
- M3 需求上传改为优先后端解析并归档；M4 网红上传解析后调用后端导入并生成知识摘要。
- AI/RAG 降级策略加强：DeepSeek 或 Tavily 不可用时，仍基于平台知识库上下文给出可审查回复。

## 风险与后续

- v0.2.1 仍使用 SQLite FTS/标签过滤，尚未接入向量数据库。
- 权限模型仍是 `private/team/public/shared`，后续应升级为 ACL/部门/项目级策略。
- 线上部署前必须确认生产环境 `DEEPSEEK_API_KEY`、`TAVILY_API_KEY`、`JWT_SECRET` 由环境变量提供，不能写入仓库。
