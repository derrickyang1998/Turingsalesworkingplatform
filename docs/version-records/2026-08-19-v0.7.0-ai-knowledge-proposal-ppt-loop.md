## Contracts / 合同

- Retrieval uses the user prompt and uploaded demand content, not the JSON formatting instructions. / 检索使用用户提示和上传需求内容，不使用 JSON 格式指令污染检索。
- Accessible team knowledge can be cited; another user's private knowledge cannot enter the model context or references. / 可访问的团队知识可引用，其他用户私有知识不得进入模型上下文或引用。
- `allow_web=false` performs zero web-provider calls and stores zero web references. / `allow_web=false` 时联网 provider 调用和联网引用均为零。
- Existing `analysis`, `fallback`, and `warning` fields remain; additive `ai` data exposes the audit identifiers and references. / 保留既有字段，并以新增 `ai` 投影返回审计标识和引用。
- Provider degradation and invalid JSON preserve a safe provider reason when one exists. / 模型降级或 JSON 无效时优先保留安全的 provider 原因。
