## Delivery / 交付

- M5 renders a compact promotion action only for persisted assistant messages. Automatically archived replies are locked as already retained; AI text remains escaped before rendering. / M5 仅对已持久化的 assistant 消息展示紧凑沉淀操作；自动归档的回复显示已沉淀且不可重复操作，AI 文本继续先转义再渲染。
- Owners can promote their own answer, and platform administrators can curate an authorized answer. Ordinary users receive concealed `404` for another owner's conversation. / 所有者可沉淀自己的回复，平台管理员可整理已有授权回复，普通用户访问他人会话时返回受限 `404`。
- Promotion accepts private/team backend visibility and defaults M5 to private. The source message is the idempotency identity, so replay returns the same knowledge entry. / 后端支持个人/团队可见性，M5 默认个人；来源消息作为幂等身份，重放返回同一知识条目。
- Campaign-linked answers preserve Campaign custody, knowledge links, and capacity rules. Unlinked answers use the existing personal knowledge contract. / Campaign 关联回复保留原活动归属、知识关联和容量规则；未关联回复沿用个人知识契约。
- Promoted, replayed, and rejected attempts append bounded mutation audits. Audit persistence is inside the successful mutation transaction and failures roll back the knowledge write. / 成功、重放和拒绝请求均追加有界变更审计；成功审计与知识写入处于同一事务，审计失败会回滚知识写入。
