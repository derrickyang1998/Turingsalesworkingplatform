## 变更 / Change

The existing admin operations health projection now exposes explicit server-owned states: `healthy`, `pending`, `attention`, and `no_data` for Provider, Feishu, imports, and workflows. Security events are shown as `recorded` rather than treated as failures. The existing shell, platform-admin authorization, filters, paging, organization projection, and read audit remain unchanged.
