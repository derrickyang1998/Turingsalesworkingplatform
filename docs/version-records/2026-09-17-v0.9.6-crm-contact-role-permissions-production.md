## Delivered / 已交付

- Added organization-scoped `crm.contact.read`, `crm.contact.create`, and `crm.contact.update` to the fail-closed central permission service. Company owner, organization administrator, manager, and member roles receive read/create/update; read-only receives read; platform-admin status alone grants no tenant contact access. / 在默认拒绝中央权限服务中增加组织范围的联系人读、建、改；企业所有者、组织管理员、经理和成员可读建改，只读角色仅可读，纯平台管理员身份不能取得租户联系人权限。
- Protected the contact collection embedded in customer detail plus create, update, and archive routes. Case variants and malformed identifiers are denied before body parsing; permission denials write bounded audit evidence without storing raw paths, bodies, contact values, tokens, or credentials. / 保护客户详情内嵌联系人以及新增、更新和归档路由；大小写变体和非法标识在请求体解析前拒绝，拒绝审计不保存原始路径、请求体、联系人值、令牌或凭据。
- Preserved transactional primary-contact replacement and archived-contact history. A preferred-contact change cannot leave multiple active primary contacts, and archive remains a reversible historical state rather than hard delete. / 保持主联系人替换的事务原子性和联系人归档历史，不会产生多个有效主联系人，也不执行硬删除。
- Preserved the current customer board/detail split and added contact empty state, cards, create/edit modal, permission-aware controls, focus handling, escaping, and explicit API error handling inside the existing detail drawer. / 保留客户看板与客户明细双页面，在现有详情抽屉中增加联系人空态、卡片、新增/编辑弹窗、权限控件、焦点管理、转义和明确错误处理。
- Added request-generation invalidation so a slower earlier detail response cannot replace the latest selected customer or reopen a drawer the user closed. / 增加请求代次失效，较慢的旧详情响应不能覆盖最新客户或重新打开已关闭抽屉。
- CRM tasks, ownership transfer, entitlements, quotas, layout redesign, M3/M4, AI/knowledge, influencer, Feishu, workflow, exports, and frozen PPT remain outside this release. / CRM 任务、所有权转移、权益、配额、布局改版及其他业务模块和冻结 PPT 均未扩改。

## Delivery Cadence / 交付节奏

- Every independently useful feature now receives only its affected unit/API/contract, syntax, migration-if-applicable, secret, and focused UI checks; one independent review; a verified backup; immediate production deployment; and a named online feature smoke. / 每个可独立使用的功能只执行受影响的单元/API/契约、语法、适用迁移、密钥和定向 UI 检查，完成一次独立审查、可验证备份后立即上线并执行明确的线上功能冒烟。
- Full local/remote/browser/performance matrices run only for phase closeout, planned release windows, or broad-risk boundaries such as authentication, authorization, schema, shared infrastructure, or external writes. Mandatory safety failures still block or roll back release. / 完整本地、远端、浏览器和性能矩阵仅在阶段收口、计划发布窗口或鉴权、授权、schema、共享基础设施、外部写入等高风险边界执行；强制安全项失败仍会阻止发布或触发回滚。
