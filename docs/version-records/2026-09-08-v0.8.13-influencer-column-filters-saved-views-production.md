## Delivered

- The existing M4 shortlist now exposes per-column filters for every currently displayed data column: ID, handle, platform, followers, project, product, region, type/tags, parent record, profile link, deliverable, and canonical displayed cost.
- List and filtered export use one validated, parameterized query builder. Text filters are bounded; exact numeric filters reject malformed, negative, array, object, or oversized inputs with `400 INVALID_INFLUENCER_FILTER`. The list keeps its 200-row display cap while filtered export returns the full matching set.
- The table shell and two-row header remain mounted while only result rows refresh. A shared fixed header-height variable, stable column tracks, clipped overflow, 220 ms debounce, and immediate stale-request invalidation prevent header loss, input focus loss, overlap, and old responses replacing newer filters.
- Users can save, apply, replace, delete, and clear up to 20 allowlisted filter views in the current browser. Storage keys include the authenticated user ID, malformed or unavailable storage degrades safely, and changing login users clears the prior user's active filter values.
- Historical 20/19-column imports, all/filtered/selected exports, campaign context, collaboration ordering, Feishu fallback, AI/knowledge, proposal, and PPT behavior remain in place. No external write, provider, business-data mutation, schema change, or new page was introduced.
