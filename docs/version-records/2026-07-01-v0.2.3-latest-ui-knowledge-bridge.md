# v0.2.3 Latest UI Knowledge Bridge

Date: 2026-07-01

## Goal

Recover the latest 2026-06-30 PPT/UI baseline after the AI knowledge-base rollout accidentally deployed an older frontend from the GitHub sync directory, then connect the knowledge-base foundation into that latest interface without changing its visual structure.

## Root Cause

- The previous rollout used `C:\Users\29272\Documents\在线商务平台-github-sync\platform` as the complete deployment baseline.
- That checkout had older `index.html`, `app.js`, and `ppt.js` than the latest working UI in `C:\Users\29272\Documents\海外品牌推广-红人营销-图灵\platform`.
- Deploying from the older baseline overwrote the latest v9.14 light deck/PPT interface and made visible features appear to regress.

## Changes

- Restored latest `index.html`, `app.js`, and `ppt.js` from the 2026-06-30 PPT/UI baseline.
- Removed frontend DeepSeek key/URL usage and routed AI assistant traffic through `/api/ai/chat`.
- Added `/api/brands/enrich` so brand enrichment uses backend DeepSeek/Tavily with quota accounting and graceful fallback.
- Added latest UI compatibility service for demand file parsing, demand analysis, strategy generation, PPT outline generation, and similar-knowledge lookup.
- Added Admin AI conversation audit UI backed by `/api/ai/conversations` and `/api/ai/conversations/:id`.
- Extended upload parsing for TXT/MD/CSV/JSON/XLSX/XLSM/XLS/PDF/DOCX/PPTX/images with fallback metadata when full extraction is unavailable.
- Made AI strategy rendering escape model/knowledge output before limited markdown formatting.
- Normalized latest PPT outline payloads so PPTX export converts `sections[].points` to the existing Python generator's `sections[].items`.
- Added CRM `scope=my/team/all` support in customer list and stats APIs.
- Removed restored legacy fixed-password UI text and preserved backend-generated temporary passwords for admin user creation/reset.
