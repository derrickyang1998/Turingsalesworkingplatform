## Release Cadence / 发布节奏

Effective immediately, each ordinary finished feature follows: affected-scope tests, required syntax/contract and credential checks, one independent review, verified rollback backup, same-cycle production deployment, and non-mutating online core-path smoke. Full-platform regression is not required for every ordinary slice. / 自即刻起，每个普通完成功能按“受影响范围测试、必要语法/契约/凭据检查、一次独立审查、可验证回滚备份、当轮上线、无业务写入的线上核心路径冒烟”推进；普通切片不要求每轮完整平台回归。

Schema migration, authentication/authorization, security, shared runtime, external writes, broad cross-module behavior and phase closeout remain high-risk gates that retain isolated migration rehearsal, replay and candidate acceptance. / 数据库迁移、认证/授权、安全、共享运行时、外部写入、广泛跨模块行为和阶段收口仍为高风险门禁，保留隔离迁移演练、回放和候选验收。
