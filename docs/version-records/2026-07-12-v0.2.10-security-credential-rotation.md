# v0.2.10 Security Credential Rotation / 安全凭据轮换

- Date / 日期: 2026-07-12
- Branch / 分支: `codex/ai-knowledge-foundation`
- Release / 版本: `v0.2.10-security-credential-rotation`
- Production target / 生产目标: protected TuringMarket production host / 受保护的图灵商务生产主机

## Goal / 目标

Close the credential portion of the v0.2.9 static-exposure incident without changing CRM, AI, knowledge-base, influencer, or PPT behavior. / 在不改变 CRM、AI、知识库、网红和 PPT 行为的前提下，关闭 v0.2.9 静态暴露事件中的凭据风险。

## Engineering Changes / 工程变更

- Added one transactional credential-rotation service over existing `users`, `sessions`, and `activity_log` tables. / 基于现有三张表新增统一事务轮换服务，无数据库结构变更。
- Added a stdin-only batch CLI; passwords never enter process arguments, stdout, stderr, Git, or public evidence. / 新增仅标准输入 CLI，密码不进入参数、输出、Git 或公开证据。
- Administrator reset, administrator user creation, registration, and production seed paths now share one password policy and secure generator. / 管理员重置、新建用户、注册与生产初始化统一使用同一密码策略和生成器。
- Added random JWT `jti`, removed query-string token authentication, and require a valid Bearer scheme. / JWT 增加随机 `jti`，移除 query token，仅接受规范 Bearer 认证。
- Added redaction tests for username/password collision failures and atomic rollback tests. / 增加用户名与密码碰撞脱敏、失败原子回滚测试。
- Hardened deploy SSH host verification, native exit-code checks, first-upgrade directory creation, backup coverage, and rollback behavior. / 强化 SSH 主机校验、原生命令退出码、首次升级目录、备份覆盖和回滚行为。
- Added a bilingual credential-rotation runbook and static contracts for private payload paths, ACLs, provider classification, and code-only rollback. / 新增双语运行手册及私有载荷、ACL、供应商分类和仅代码回滚契约。

## Production Operations / 生产操作

- Created and verified a root-only consistent SQLite backup plus code/Nginx archive and checksums. / 创建并验证 root-only SQLite 一致性备份、代码/Nginx 归档和校验和。
- Confirmed the general backup contained zero `.env` files. / 确认常规归档中 `.env` 文件为 0。
- Rotated all 11 active users, including the single administrator, in one atomic batch. / 原子轮换全部 11 个活动账号，其中管理员 1 个。
- Verified the old administrator password returns HTTP 401. / 验证旧管理员密码返回 HTTP 401。
- Replaced `JWT_SECRET` with a new high-entropy value of at least 96 characters and removed `DEFAULT_ADMIN_PASSWORD`. / 轮换不少于 96 字符的 JWT 密钥并移除默认管理员密码。
- Removed three plaintext `.env.bak-*` files; zero remain. / 清理 3 份明文环境备份，剩余 0。
- Preserved DeepSeek and Tavily only after evidence classification and live provider smoke; Feishu remains unconfigured. / 完成证据分类和线上冒烟后保留 DeepSeek/Tavily；飞书仍未配置。

## Security Handling / 安全处理

- Real user credentials exist only in the ACL-protected local `99-private` manifest. / 真实账号凭据仅保存在 ACL 受限的本机私有清单。
- The temporary rotation payload was deleted after successful smoke. / 冒烟成功后已删除临时轮换载荷。
- No password, JWT, provider key, webhook, bearer token, AI response body, production host, or exact protected-backup path appears in this public record. / 本公开记录不包含任何敏感值、生产主机或精确备份路径。
- Rollback may restore code only and must never restore old password hashes, JWT secrets, or plaintext environment backups. / 回滚只允许恢复代码，不得恢复旧密码哈希、JWT 密钥或明文环境备份。
