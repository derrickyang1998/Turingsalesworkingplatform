## Delivery / 交付

- Tavily queries are normalized and bounded. Only canonical absolute HTTP/HTTPS sources survive; credentials, fragments, common tracking parameters, duplicates, unsafe schemes, oversized fields, and out-of-range scores are removed. / Tavily 查询统一规范化并限制长度；只保留规范绝对 HTTP/HTTPS 来源，移除凭据、锚点、常见追踪参数、重复项、异常协议、超长字段和越界评分。
- Provider `response`, `answer`, raw payloads, and exception text do not enter API results, references, cache rows, or release evidence. / Provider 原始响应、回答、载荷和异常文本不进入接口、引用、缓存或发布证据。
- Web search now has an 8-second default timeout, one bounded retry, a three-failure circuit breaker, stable safe reason codes, and governed 24-hour cache fallback. A derived child signal aborts the underlying Tavily request even when AI supplies an outer deadline signal. / 联网搜索增加默认 8 秒超时、一次有界重试、连续三次失败熔断、稳定安全原因码和受治理的 24 小时缓存降级；即使 AI 提供总截止信号，独立子信号也会真正中止底层 Tavily 请求。
- Raw AI conversations, messages, references, and usage remain fully retained. Only substantive, non-degraded answers with governed internal or web evidence become reusable `ai_chat_summary` knowledge by default. Unconfirmed, low-value, no-evidence, and degraded results remain conversation-only. / 原始对话、消息、引用和用量继续全量保留；默认只有内容充分、非降级且具有受治理内部或联网证据的回复才晋升为可复用知识，未确认、低价值、无证据和降级结果只留在会话审计中。
- Promotion decisions persist exact counts, scalar lengths, reason, and policy version `ai-summary-promotion-v1` in knowledge metadata. M5 marks cached web sources and successful automatic promotion. / 晋升决定将计数、字符长度、原因和策略版本写入知识元数据；M5 标记缓存来源及成功自动沉淀。
