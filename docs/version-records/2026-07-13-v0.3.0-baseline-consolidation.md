# v0.3.0 Baseline Consolidation / 基线收敛

- Date / 日期: 2026-07-13

- Release / 版本: `v0.3.0-baseline-consolidation`
- Production target / 生产目标: protected TuringMarket production host / 受保护的图灵商务生产主机

## Goal / 目标

Preserve the latest CRM, brand intelligence, demand/PPT, influencer, AI, workflow, task, admin, and knowledge-base behavior before the V1 structural and visual upgrade. / 在 V1 结构与视觉升级前，完整保留最新 CRM、品牌智库、需求/PPT、网红、AI、流程、待办、管理和知识库行为。

## Baseline And Frontend Consolidation / 基线与前端收敛

- Added a deterministic manifest covering build markers, route contracts, seed-fixture version, viewport metadata, and SHA-256 values for `index.html`, `app.js`, and `ppt.js`. / 新增确定性清单，覆盖构建标记、路由契约、种子夹具版本、视口元数据和三个核心前端文件的 SHA-256。
- Captured 72 role-aware screenshots across `1440x900`, `1920x1080`, and `390x844`, with comparison tooling and a `0.005` behavior-preserving pixel threshold. / 在三个视口冻结 72 张角色化截图，并增加对比工具与 `0.005` 行为保持阈值。
- Inventoried duplicate top-level functions and event bindings, then consolidated customer navigation, PPT bridge ownership, M4 influencer workflow, brand workspace, and shared workflow bindings in covered slices. / 盘点重复顶层函数与事件绑定，并在有回归覆盖的切片中收敛客户导航、PPT bridge、M4 网红流程、品牌工作区和公共流程绑定。
- Added one deterministic navigation state owner for direct links, refresh, back/forward, role visibility, and idempotent initialization. / 新增唯一导航状态管理，覆盖深链接、刷新、前进后退、角色可见性和幂等初始化。
- Added explicit public assets for build metadata and navigation only; unknown client files and server-private paths remain `404`. / 仅显式开放构建元数据和导航资源，未知客户端文件及服务端私有路径继续返回 `404`。
- Preserved the frozen PPT implementation and added strict HTML/PPTX browser contracts, including Unicode download-name fallback validation on Linux. / 冻结 PPT 实现不变，并增加严格 HTML/PPTX 浏览器契约及 Linux Unicode 下载名降级验证。

## Production Runtime And Deployment Gate / 生产运行时与部署门禁

- Externalized environment, SQLite, uploads, and temporary files under protected system paths while preserving the root-owned PM2 service for this release. / 将环境、SQLite、上传和临时文件外置到受保护系统路径，本版本保持 root PM2 运行方式不变。
- Added an idempotent runtime bootstrap with persistent migration journal, SQLite Backup API snapshots, integrity checks, failure recovery, and exact runtime-link validation. / 新增可幂等运行时引导，包含持久迁移日志、SQLite Backup API 快照、完整性校验、失败恢复和精确运行时链接校验。
- Added a locked non-login gate account and sealed candidate releases; the writer rechecks candidate hashes before atomic exchange. / 新增锁定且禁止登录的门禁账号和封存候选发布；写入者在原子切换前再次核对候选摘要。
- Candidate Nginx validation now rewrites exactly one listen directive into a root-owned private Unix socket, validates without privileged bind, cleans all temporary state, and rechecks the untouched candidate hash. / 候选 Nginx 校验仅将一个监听指令改写为 root 所有的私有 Unix socket，在无特权绑定下校验，清理全部临时状态并复验原候选哈希。
- Root installs and validates the original Nginx configuration before reload; database and application rollback artifacts remain independent of secrets. / root 安装原始 Nginx 配置并在 reload 前复验；数据库与应用回滚产物不包含密钥。
