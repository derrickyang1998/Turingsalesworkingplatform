## Delivered

- The existing M4 shortlist now displays and filters cost, client quote, CPM, and CPV independently. The historical `filter_cost` contract retains its displayed-cost meaning instead of being silently rewritten as client quote.
- Users can hide/show columns, reorder them, and save the current filters, visible columns, and order as a reusable account workspace. The responsive control stays inside narrow viewports and does not create a new page.
- `GET`, `POST`, and `DELETE /api/influencer-views` persist at most 20 views per active account. Names update case-insensitively, each update increments `row_version`, ownership is enforced on every read/write, and cross-owner deletes return concealed not-found behavior.
- Migration 015 creates `influencer_saved_views` with strict user ownership, a user/update-time index, and a case-insensitive user/name unique index. Empty and existing databases are supported through the managed migration path.
- Legacy browser-local views merge incrementally into server state rather than only when the server starts empty. Existing 20/19-column import, partial-row fallback, global/field search, all/filtered/selected export, campaign context, collaboration ordering, Feishu, AI/knowledge, proposal, and frozen PPT workflows remain available.
