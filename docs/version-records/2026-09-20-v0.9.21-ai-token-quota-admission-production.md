## Delivered / 已交付

- Added one server-owned `ai_quota_service` for live user, role, active-organization, and trusted-ledger admission before any DeepSeek provider call. Platform administrators are explicitly exempt; a non-administrator with quota `0` receives `429 AI_QUOTA_DISABLED`, and exhausted quotas fail closed. / 新增统一服务端 `ai_quota_service`，在任何 DeepSeek provider 调用前按实时用户、角色、活动组织和可信账本执行准入；平台管理员明确豁免，普通用户配额为 0 时返回 429，配额耗尽时失败关闭。
- Unified AI chat, proposal/PPT, brand strategy, manual performance analysis, and content analysis on trusted provider usage accounting. Successful responses with missing, negative, unsafe, or inconsistent token usage fail with `AI_USAGE_ACCOUNTING_FAILED` instead of silently recording zero. / AI 对话、方案/PPT、品牌策略、绩效手工分析和内容分析统一使用可信 provider 用量记账；成功响应缺失、为负、越界或总量不一致时失败关闭，不再静默记为 0。
- Preserved linked-conversation idempotent replay before admission. Provider failures can record explicit zero usage only as a failure audit; successful generation cannot use that fallback. / 保留链接会话在准入前的幂等重放；只有 provider 真实失败审计可显式记录 0，用量成功路径不能使用该降级。
- Added `PUT /api/admin/users/:userId/ai-quota`, atomic audited quota updates, and Admin directory projections for used, limit, remaining, and status. Blank UI input is rejected rather than converted to zero. / 新增管理员配额接口、原子审计更新及已用/上限/剩余/状态投影；空输入会被拒绝，不会误转为 0。
- Reused schema v26, `users.api_quota`, and organization-owned `token_usage`. The current accounting period is explicitly `legacy_lifetime`. / 复用 schema v26、`users.api_quota` 与具备组织归属的 `token_usage`；当前计量周期明确为 `legacy_lifetime`。
- Preserved the latest product shell, CRM, M3/M4, AI/knowledge, proposal/report workflows, and frozen PPT. / 保留最新产品壳层、CRM、M3/M4、AI/知识库、方案/报告流程及冻结 PPT。
