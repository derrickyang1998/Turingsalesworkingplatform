## Delivered / 已交付

- Added organization-scoped `crm.task.read`, `crm.task.create`, and `crm.task.update` to the fail-closed central permission service. Company owner, organization administrator, manager, and member roles receive read/create/update; read-only receives read; platform-admin status alone grants no tenant task access. / 在默认拒绝中央权限服务中增加组织范围的任务读、建、改；企业所有者、组织管理员、经理和成员可读建改，只读角色仅可读，纯平台管理员身份不能取得租户任务权限。
- Protected the existing task create, complete, and cancel routes. Complete and cancel map to update; CRM custody rules continue after named permission succeeds. / 保护既有任务创建、完成和取消路由，完成与取消归为更新权限，命名权限通过后仍继续执行 CRM 归属规则。
- Added exact case-insensitive and trailing-slash pre-parser matching. Invalid and noncanonical identifiers are denied without parsing the request body, and audit entries store only bounded actor, organization, permission, outcome, reason, request ID, target type, and canonical target ID. / 增加精确的大小写兼容与尾斜杠解析前匹配；非法及非规范 ID 在读取请求体前拒绝，审计只保存有界字段。
- Denied requests with unread bodies now set `Connection: close` and destroy the incomplete socket after the response finishes, preventing a slow client from retaining the application connection. / 对仍有未读请求体的拒绝请求设置连接关闭，并在响应结束后销毁未完成连接，避免慢请求占用应用连接。
- Login and `/api/auth/me` now project `crm.task` actions from live organization facts. No task read API or task UI was added in this backend-only slice. / 登录与当前用户接口按实时组织事实投影任务权限；本轮为纯后端切片，未新增任务读取接口或界面。
- The current customer board/detail split, contact and opportunity behavior, M3/M4, AI/knowledge, influencer, Feishu, workflow, exports, and frozen PPT remain unchanged. / 现有客户看板/明细双页面、联系人、商机及其他业务模块和冻结 PPT 均未修改。
