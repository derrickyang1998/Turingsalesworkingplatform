## Delivery / 交付

- Requirement sheets, influencer import batches, confirmed proposals, completed PPT files, project reviews, promoted AI summaries, and manually selected conclusions now share `tm-business-artifact-v1`. Every producer records artifact type, lifecycle state, business custody, immutable identity, and reusable lineage. / 需求表、网红导入批次、确认方案、PPT 成品、项目复盘、AI 晋升摘要和人工精选统一使用 `tm-business-artifact-v1`，记录产物类型、生命周期、业务归属、不可变身份和复用血缘。
- Exact legacy replay reuses the existing knowledge entry. A changed immutable projection under the same source identity fails with `KNOWLEDGE_SOURCE_CONTENT_CONFLICT` instead of overwriting accepted knowledge. Campaign proposal and PPT producers preserve atomic base-row, archive, link, event, and rollback behavior. / 旧版精确重放复用原知识条目；同一来源身份下不可变投影变化会确定性冲突，不覆盖既有知识。Campaign 方案与 PPT 生产者保持业务、归档、关联、事件及回滚原子性。
- Legacy PPT identity includes both canonical request SHA-256 and the actual generated artifact SHA-256. Repeated input can therefore retain distinct valid nondeterministic outputs, while exact byte replay deduplicates. Failed rendering or archival removes both temporary JSON and PPT files. / Legacy PPT 身份同时包含规范请求哈希和实际成品哈希；同一输入的不同有效成品可分别归档，精确字节重放仍去重，生成或归档失败会清理全部临时文件。
- Manual AI promotion uses new selected-conclusion source types while recognizing Task 4C legacy rows only when `promotion.trigger=manual`. Automatic summaries remain separate and cannot satisfy manual idempotency lookup. / AI 人工精选使用新的精选结论来源类型，同时仅兼容带 `promotion.trigger=manual` 的 Task 4C 旧记录；自动摘要保持独立，不会误命中人工幂等查询。
- The legacy UI's filename-valued influencer batch is converted to an upload SHA-derived batch. Revised files with the same name are distinct, while an explicitly different custom batch retains immutable replay/conflict semantics. Influencer rows and batch knowledge are committed in one transaction. / 旧前端以文件名填充的网红批次改由上传 SHA 派生；同名新版文件可形成不同批次，显式不同的自定义批次继续保持不可变重放/冲突语义，网红行与批次知识在同一事务提交。
- The explicit `local-worker` test adapter supplies a deterministic capacity projection so functional tests do not depend on workstation free space. The production path still enforces the real 2 GiB free-space floor. The accepted `app.js` and frozen `ppt.js` bytes are unchanged. / 严格本地测试适配器使用确定性容量投影，避免功能测试依赖开发机剩余空间；生产路径仍执行真实 2 GiB 安全线。已验收 `app.js` 与冻结 `ppt.js` 字节未变。
