# v0.8.1b Performance Content CSV Export Production Record

## Scope / 范围

- Implementation commit / 实现提交: `4799328`.
- The performance monitor now exports either the current filtered view or every content record in the selected campaign. The current view respects the same search, platform, and tag filters as the table; the all-content scope only removes those filters and never escapes campaign or organization access. / 内容监控现可导出当前筛选视图或所选活动的全部内容。当前筛选复用表格的搜索、平台和标签条件；全部内容仅移除这些内容过滤，不会越过活动或组织权限。
- The API returns a UTF-8 BOM CSV directly, records a `performance_content_export` audit event, and limits export volume to 5,000 rows. The UI keeps one export request in flight and disables both controls during the download. / API 直接返回 UTF-8 BOM CSV，记录 `performance_content_export` 审计事件，并将导出限制为 5,000 行；前端保持单飞并在下载期间禁用两个操作。
- Commercial values, financial KPI columns, and correction reasons are included only for commercial-capable users. Team-member exports remain limited to public content and observation data. / 商业数值、财务 KPI 列与商业纠正原因仅提供给具有商业查看权限的用户；团队成员导出只保留公开内容和观测数据。
- CSV cells neutralize formula prefixes after any leading JavaScript whitespace, including Unicode whitespace, so exported business text is not interpreted as a spreadsheet formula. / CSV 单元格会处理中任意 JavaScript 空白后的公式前缀（包括 Unicode 空白），避免业务文本被电子表格解释为公式。
