## Delivered / 已交付

- Added a server-side YouTube Data API provider for public video views, likes, and comments. Saves and shares remain explicitly unavailable from this provider; clicks, spend, revenue, ROI, and ROAS remain manual or approved-business inputs. / 新增服务端 YouTube Data API provider，采集视频公开播放、点赞和评论；收藏和转发明确标记为该 provider 不可用，点击、花费、收入、ROI 与 ROAS 继续由人工或经批准的业务数据提供。
- Kept the accepted content-monitoring interface and added provider status, guarded collection controls, source labels, and collection history inside the existing workspace. Manual import and dashboard flows remain available when the provider is disabled. / 保留已验收的内容监控界面，仅在现有工作区增加 provider 状态、受控采集按钮、来源标签和采集历史；provider 停用时人工导入与看板流程仍可使用。
- Added bounded collection with a maximum of 50 items per run, concurrency `4`, timeout/retry handling, a five-minute manual cooldown, and per-user, per-organization, and shared-provider daily limits. / 增加有界采集：单次最多 50 条、并发数 `4`、超时与重试、五分钟人工冷却，以及用户、组织和共享 provider 的每日限额。
- Added crash-safe quota custody. Worst-case quota is reserved before external I/O in the same immediate transaction as the durable claim; the default shared YouTube allowance is `9,000` units/day and each selected item reserves up to `3` units. / 增加崩溃安全配额保管：最坏情况配额在外部请求前与持久领取记录于同一即时事务内预留；YouTube 默认共享限额为每日 `9,000` 单位，每条选中内容最多预留 `3` 单位。
- Added append-only collection runs, provider observations, and quota reservations with update/delete prevention triggers. Raw provider attempts and provenance are retained for review. / 新增只追加采集运行、provider 观测与配额预留记录，并以触发器禁止更新和删除；原始 provider 尝试及来源链保留供审查。
- Provider observations overlay manual values only when newer. The canonical snapshot, history, dashboard, export, review evidence, and Feishu projection now read the same lineage-aware result. / provider 观测仅在时间更新时覆盖人工值；标准快照、历史、看板、导出、复核证据和飞书投影读取同一套来源感知结果。

## Delivery Cadence / 交付节奏

- Normal features are now deployed in the same development round after affected tests, necessary syntax/contracts, one independent review, a verified backup, and online smoke. / 普通功能完成受影响测试、必要语法/合同、一次独立审查和可验证备份后，即在当轮部署生产并执行线上冒烟。

Migration safety, rollback readiness, HIGH/CRITICAL findings, and failed production smoke remain hard blockers. / 完整测试保留给阶段收口，或数据库迁移、鉴权、共享基础设施、真实外部写入等高风险改动；迁移安全、回滚就绪、HIGH/CRITICAL 发现和线上冒烟失败仍是硬阻断。
