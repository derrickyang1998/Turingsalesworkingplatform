## Delivered

- Added the “批量更新指标” workflow in Content Monitor, including a downloadable CSV template and CSV/XLSX upload.
- Added `POST /api/performance/metrics/upload` under the existing authenticated campaign content-management boundary and established upload isolation.
- Accepted only canonical video links that match content already monitored in the current authorized campaign.
- Required a strict UTC ISO observation timestamp and at least one metric per row; accepted nonnegative safe-integer values only.
- Appended immutable performance observations for views, impressions, likes, comments, saves, shares, clicks, and conversions.
- Rejected unknown content, invalid links, invalid timestamps, invalid metrics, and unsupported mappings per row without persisting those rows.
- Deduplicated exact CSV/XLSX replay snapshots so repeated imports cannot create a second observation.
