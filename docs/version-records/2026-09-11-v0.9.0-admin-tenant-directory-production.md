## Delivered / 已交付

- Added an Organization tab to the existing Admin Control Room. Administrators can search and page through organizations, inspect team/member/revoked-member counts, and open a member directory without replacing the current product shell. / 在现有管理控制室增加“组织”页签；管理员可检索和分页查看组织、团队/有效成员/撤销成员数量，并打开成员目录，不替换当前产品壳层。
- The member directory supports member identity, platform role, organization role, status, and multi-team-role search and display. Filters reset pagination, requests are locked while loading, and failed requests preserve the current page. / 成员目录支持成员身份、平台角色、组织角色、状态及多团队角色的检索与展示；筛选会重置分页，请求期间锁定翻页，失败时保留当前页。
- Added admin-only `GET /api/admin/organizations` and `GET /api/admin/organizations/:organizationId/members`, with bounded keyset pagination and no cross-tenant access for normal users. / 新增两个管理员专用接口，使用有界游标分页，普通用户不能跨租户读取。
- Every directory read writes a `tenant_admin` audit entry in the same transaction. Audit metadata retains field names, target/count, and cursor state without raw search terms or reversible search hashes; audit persistence failure fails the read. / 每次目录读取均在同一事务写入 `tenant_admin` 审计；只保留字段名、目标/数量及游标状态，不保存原始检索词或可逆摘要，审计落库失败则读取失败。
- Existing CRM, M3/M4, AI conversation, knowledge base, proposal, and frozen PPT paths remain unchanged. / 既有 CRM、M3/M4、AI 对话、知识库、方案与冻结 PPT 路径保持不变。
