## Atomic Audit And Degradation / 原子审计与降级

- Unlinked one-shot analysis uses private-only knowledge, one shared deadline/cancellation signal, and one SQLite transaction for both messages, references, usage, status, and latency. / 未关联的一次性分析仅使用私有知识，并以共享截止/取消信号及单个 SQLite 事务保存成对消息、引用、用量、状态和延迟。
- Provider exceptions and timeouts return a bounded degraded JSON result without exposing raw provider errors or leaving half-written conversations. / Provider 异常与超时返回受限降级 JSON，不泄露原始错误，也不留下半写会话。
- Linked requests retain existing campaign access and idempotency authorization. Demand analysis suppresses automatic summaries while unrelated AI chat keeps its existing archive behavior. / 关联请求继续执行既有 Campaign 权限与幂等鉴权；需求分析不自动归档摘要，其他 AI 对话的既有归档行为不变。
- Administrators can list and inspect all authorized conversations; each privileged list/detail read writes an `ai_audit` activity record. Ordinary users remain owner-only. / 管理员可查询和查看全部授权会话，列表与详情读取均写入 `ai_audit`；普通用户仍只能读取自己的会话。
