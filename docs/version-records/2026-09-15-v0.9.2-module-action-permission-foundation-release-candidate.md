## Delivered / 已交付

- Added a closed, fail-closed `platform_administration.manage` policy service. It re-reads the active user from SQLite and rejects ordinary, inactive, missing, mismatched, malformed, unknown, or unavailable authoritative identity facts. / 新增封闭、默认拒绝的 `platform_administration.manage` 策略服务；每次从 SQLite 重读有效用户，并拒绝普通、失活、缺失、角色不一致、畸形、未知或权威事实不可用的身份。
- Existing `adminOnly` now delegates to the policy service while preserving exactly HTTP `403` with `{ error: 'Admin only' }`. Existing route URLs, authentication payloads, service-level rechecks, and privileged audit behavior remain unchanged. / 既有 `adminOnly` 已委托策略服务，同时精确保留原 `403` 返回；路由、登录返回、服务层复核和特权审计行为不变。
- Roles are projected only from live platform, organization, and team records. Browser-supplied role/permission/context fields cannot grant platform access. Company owner and read-only are reserved but unassignable until an explicit persistence migration is delivered. / 角色只从实时平台、组织与团队记录投影；浏览器提交的角色、权限或上下文不能授予平台权限。企业所有者与只读角色在显式持久化迁移前保留但不可分配。
- The guarded deploy inventory contains the new service and focused test, and the remote candidate gate explicitly runs the test. No frontend, CRM, M3/M4, AI/knowledge, influencer, Feishu, workflow, export, database, or PPT source changed. / 受控发布清单包含新服务和聚焦测试，远端候选门禁会显式执行该测试；前端及其他业务模块、数据库和 PPT 源码均未改动。
