## Delivery / 交付

- Schema v7 adds strict `knowledge_entry_governance` records for every existing and future knowledge entry. Quality is `candidate`, `confirmed`, or `rejected`; retention is `protected` or explicitly scheduled with a bounded timestamp. / Schema v7 为所有既有和新增知识增加严格治理记录；质量状态为候选、已确认或已拒绝，保留策略为受保护或带明确期限的计划保留。
- Governance records preserve a single linear lineage with root, predecessor, version number, current-version flag, and optimistic `governance_version`. Historical records remain readable to existing citation audits but cannot be governed again. / 治理记录通过血缘根、前序版本、版本号、当前版本标记和乐观治理版本保持单线版本关系；历史记录继续供既有引用审计读取，但不能再次治理。
- The administrator API and knowledge UI support confirm, reject, retention, and supersession actions. Ordinary users receive `403`; every successful change appends a bounded `knowledge_governance_updated` activity record. / 管理员 API 与知识库界面支持确认、拒绝、保留和替代操作；普通用户返回 `403`，每次成功变更均追加有界治理审计。
- Retrieval excludes rejected, inactive, superseded, and expired knowledge, and ranks confirmed knowledge before candidates. Historical citations retain their original title, source, and governance projection. / 检索排除已拒绝、非当前、已替代和已过期知识，并优先排序已确认知识；历史引用保留原始标题、来源和治理投影。
- The accepted v0.6 shell and frozen PPT renderer remain unchanged. / 已验收 v0.6 产品壳层与冻结 PPT renderer 均保持不变。
