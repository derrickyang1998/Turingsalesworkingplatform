## Goal And Scope / 目标与范围

Deliver a behavior-preserving responsive product shell and shared design/accessibility baseline on top of the latest v0.3.0 product behavior. CRM, brand intelligence, demand/PPT, influencer, AI, workflow, task, admin, and knowledge-base domain contracts remain owned by their existing modules. / 在 v0.3.0 最新功能基线上交付不改变业务行为的响应式产品壳层和共享设计/无障碍基线；九类业务模块继续保持原有职责与契约。

No database migration, API redesign, or business-data rewrite was introduced. The latest customer board/detail split, M4 import/search/order/Feishu surfaces, AI/knowledge links, administrator conversation visibility, and PPT generation behavior were preserved. / 本阶段未引入数据库迁移、API 重构或业务数据改写；客户看板/明细拆分、M4 导入搜索与合作/飞书界面、AI/知识关联、管理员对话可见性及 PPT 生成行为均保持。

## Product Shell / 产品壳层

- Added shared tokens and component/layout layers for typography, spacing, color, borders, focus, controls, tables, dialogs, responsive navigation, and reduced-motion/forced-colors behavior. / 新增共享令牌和组件/布局层，统一字体、间距、颜色、边框、焦点、控件、表格、弹窗、响应式导航及减少动画/强制色彩行为。
- Replaced the mobile-displacing desktop sidebar with a compact top bar and an inert, focus-trapped drawer at narrow widths; retained the dense desktop work surface. / 窄屏改为顶部栏与具备 inert、焦点限制和恢复的抽屉，消除桌面侧栏挤压，同时保留桌面高密度工作台。
- Preserved canonical routes, deep links, browser history, role gates, CRM/M4 manual-activation tabs, native file choosers, and the single frozen PPT owner. / 保留规范路由、深链接、历史、角色门禁、CRM/M4 手动激活标签、原生文件选择器和唯一冻结 PPT 所有者。
- Kept fixed table headers and compact checkboxes in M4, searchable customer details, and distinct CRM board/detail surfaces. / 保留 M4 固定表头与紧凑复选框、客户明细搜索及独立 CRM 看板/明细界面。

The correction aligned both browser test entrypoints with `playwright-deploy`, restricted the AppArmor wildcard to versioned deploy paths, and added executable install/restore/cleanup tests. An interrupted pre-mutation attempt was recovered through the reviewed lock lifecycle before the final guarded deployment. / 首次候选因部署浏览器别名与 AppArmor 路径契约不一致而在生产变更前安全拒绝，线上保持健康；随后统一部署浏览器入口、窄化 profile 路径并补齐安装/恢复/清理实测。一次变更前中断也通过受审查锁生命周期完成恢复，之后才执行最终受控发布。
