## Delivered / 已交付

- M4 now loads the current user's accessible campaigns and lets the operator choose an execution context. When a campaign is selected, collaboration orders, execution, publication, and settlement stay linked to that campaign. The independent legacy collaboration path remains available when no campaign is selected. / M4 现会加载当前用户可访问的活动，并允许操作人员选择执行上下文。选择活动后，合作下单、执行、发布和结算会保持关联；未选择活动时，原有独立合作记录路径继续可用。
- `GET /api/collaborations` accepts a bounded `campaign_id` filter and optional campaign context projection. The server rejects invalid campaign IDs before querying, applies existing custody authorization, and hides inaccessible collaboration records before list aggregation. / `GET /api/collaborations` 支持受限的 `campaign_id` 筛选和可选活动上下文投影。服务端会在查询前拒绝无效活动 ID，沿用既有归属权限，并在列表聚合前隐藏无权合作记录。
- The M4 client keeps its existing import, Feishu fallback, resource order, lifecycle, and settlement controls wired while adding campaign selection, context rendering, request de-duplication, stale-response isolation, and replay-safe actions. / M4 客户端在保留现有导入、飞书降级、合作资源下单、生命周期和结算控制的同时，新增活动选择、上下文展示、请求去重、陈旧响应隔离和可重放动作。

## Delivery Cadence / 交付节奏

Normal features now ship in the same development round after affected verification, one independent approval, a recoverable backup, online deployment, and a core-path smoke check. Full regression remains for schema/data work, authentication or authorization, shared runtime/deployment controls, security changes, broad cross-module changes, and phase closeout. A cross-boundary release may still deploy promptly, but it must not mark a missing business transaction smoke as accepted. / 常规功能现会在同一开发轮完成受影响验证、一次独立批准、可恢复备份、线上部署和核心路径冒烟后立即上线。完整回归保留给数据库/数据、认证或权限、共享运行时/部署控制、安全、广泛跨模块变更和阶段收口。跨边界发布仍可快速上线，但不得把尚未执行的业务交易冒烟标记为已验收。
