## Delivered

- Added the compact “活动飞书连接配置” panel inside Content Monitor.
- Added a versioned configuration store and SQLite migration `v11` for current and daily projection tables plus a validated public-field mapping.
- Added protected read, draft-save, and approval APIs. Campaign Owner and organization administrators may draft; only organization administrators may approve.
- Made approval transactional: the selected draft becomes approved while the former approved record is superseded; configuration history remains append-only.
- Recorded draft and approval activity in the existing audit trail.
- Redacted table identifiers, mappings, and snapshot details for team members without administrative access.
- Guarded save and approval render paths with both request sequence and current campaign ID, so a stale response cannot populate a newly selected campaign.
