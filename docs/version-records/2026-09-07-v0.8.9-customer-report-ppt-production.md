## Delivered / 已交付

- Each sealed `customer_safe_v1` report in the Performance Dashboard now has a compact customer PPT action. Campaign owners and organization administrators with write access can generate/download it; readers remain denied.
- 每个已封存客户安全报告现可生成并下载一份客户版 PPT；成品严格绑定该不可变快照，重复请求回放同一份已验证文件，不会读取后续实时活动数据。
- Schema `v14` adds the append-only `customer_report_ppt_artifacts` table. The dedicated renderer and private artifact namespace are isolated from the frozen campaign proposal PPT path.
- PPT 内容仅来自七章节脱敏报告，不包含原始视频链接、达人联系方式、成本/报价等商业指标、内部提示词、飞书凭据或外部收件信息。
- The backup ledger now covers both legacy campaign PPTs and nested customer-report PPT artifacts without changing the established proposal PPT generator.

This release does not call DeepSeek, web search, video/media providers, Feishu, or scheduled synchronization. Production acceptance did not create a real customer artifact.
