## Delivered / 已交付

- Added an additive “Authorized Content Evidence Analysis” section to the existing Performance Dashboard. A campaign owner or organization administrator can select a registered publication, submit client- or creator-authorized caption/transcript and optional human observations, generate an AI draft, edit it, and confirm it into the same Campaign knowledge base. Existing metric-only review, customer report, HTML, and PPT flows are unchanged. / 在现有效果数据看板增量加入“授权内容证据分析”。项目负责人或组织管理员可选择已登记内容，提交客户或达人授权的文案/字幕与可选人工观察，生成并编辑 AI 草稿，再确认归档到同一 Campaign 知识库；既有纯指标复盘、客户报告、HTML 与 PPT 流程不变。
- Accepts only `client_supplied` and `creator_supplied` evidence with an explicit rights attestation. Public-access acquisition remains disabled until the server can verify a durable approval record. / 仅接受 `client_supplied` 与 `creator_supplied`，且必须明确确认授权；公开内容采集在服务端可验证长期批准记录建立前保持禁用。
- Sends raw evidence to DeepSeek only as transient provider input. AI messages, idempotency responses, knowledge metadata, and audit records retain only hashes, evidence types/lengths, rights/acquisition metadata, performance lineage, generated conclusions, and the approved text. The platform does not fetch or retain raw video, images, audio, subtitle files, or frames. / 原始证据只作为 DeepSeek 瞬时输入；AI 消息、幂等响应、知识元数据和审计仅保留哈希、证据类型/长度、授权与采集元数据、效果血缘、生成结论及确认稿。平台不抓取或保存视频、图片、音频、字幕文件或画面帧。
- Keeps web search disabled and retrieves only confirmed Campaign methodology. Performance-linked findings, reuse recommendations, tests, and actions require both CONTENT and PERF citations; unsupported dimensions and external/commercial/causal claims are rejected. / 本功能关闭联网搜索，仅检索已确认 Campaign 方法论。效果相关发现、复用建议、测试与行动项必须同时包含 CONTENT 与 PERF 引用；缺失证据维度及外部、商业、因果型无依据结论会被拒绝。
- Added owner/admin-only confirmation, stale snapshot and form-change guards, full-offset raw-evidence leak detection, and a dedicated approval idempotency scope. Same-key same-request replays the exact response without duplicate audit; same-key different-request returns a controlled conflict. / 增加负责人/组织管理员确认、快照与表单变更防护、全偏移原文泄漏检测及独立确认幂等范围。同 key 同请求原样重放且不重复审计，同 key 不同请求受控冲突。
