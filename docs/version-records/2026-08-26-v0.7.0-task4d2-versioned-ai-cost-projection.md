## Delivery / 交付

- DeepSeek now defaults to `deepseek-v4-flash` and sends `thinking: { type: "disabled" }` so the accepted non-thinking product behavior remains stable. / DeepSeek 默认模型现为 `deepseek-v4-flash`，并显式发送 `thinking: { type: "disabled" }`，保持已验收的非思考式产品行为。
- Every non-degraded DeepSeek completion stores an immutable cost snapshot in the existing AI-message metadata. It records provider, returned model, completion time, pricing policy version, peak/off-peak window, exact integer nano-USD rates, cache-hit/cache-miss/output token counts, and computed total. / 每次非降级 DeepSeek 完成均在现有 AI 消息元数据中保存不可变成本快照，记录 Provider、返回模型、完成时间、定价策略版本、峰谷时段、整数 nano-USD 费率、缓存命中/未命中/输出 Token 及总额。
- Policy `deepseek-v4-usd-2026-08-13-v1` freezes the documented V4 Flash and V4 Pro weekday UTC peak/off-peak prices. Integer arithmetic prevents floating-point drift. The policy source is the official [DeepSeek pricing documentation](https://api-docs.deepseek.com/quick_start/pricing). / 策略 `deepseek-v4-usd-2026-08-13-v1` 固化官方文档中的 V4 Flash 与 V4 Pro 工作日 UTC 峰谷价格，并以整数运算避免浮点漂移；来源为 DeepSeek 官方计价文档。
- Projection validates the complete snapshot instead of trusting persisted totals. Invalid, incomplete, forged, inherited-name, unsupported-model, inconsistent-window, inconsistent-rate, inconsistent-token, and unsafe-integer data fails closed. Historical messages without a valid snapshot remain unavailable and are never repriced with mutable current rates. / 投影会完整复算快照而非信任已存总额；无效、不完整、伪造、继承名称、不支持模型、时段/费率/Token 不一致及非安全整数数据均失败关闭。无合法快照的历史消息保持不可用，不使用会变化的当前价格追溯计价。
- Administrator list aggregation reuses the exact JavaScript projector through one deterministic SQLite function, so list and detail stay consistent without loading unbounded historical messages into Node.js. Aggregate overflow returns `overflow` with no false capped amount. / 管理员列表通过单一确定性 SQLite 函数复用同一 JavaScript 投影器，列表与详情保持一致且不无界载入历史消息；汇总溢出返回 `overflow`，不会显示错误的封顶金额。
- The UI distinguishes projected, partially projected, unavailable, and overflow cost states. There is no schema migration; the accepted shell, Campaign RAG contracts, and frozen PPT renderer remain intact. / 界面区分投影成本、部分投影、不可用与溢出状态；无数据库迁移，已验收壳层、Campaign RAG 契约与冻结 PPT renderer 均保持不变。
