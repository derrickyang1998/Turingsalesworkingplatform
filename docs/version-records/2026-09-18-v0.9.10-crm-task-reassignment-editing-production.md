## Delivered / 已交付

- Added `GET /api/customers/:customerId/tasks/:taskId/assignee-candidates` for active, read-write members in the task's current organization and team. Quarantined or teamless tasks expose no writable projection. / 新增负责人候选接口，仅返回任务当前组织和团队内有效、可写成员；隔离或无团队任务不暴露可更新投影。
- Added `PUT /api/customers/:customerId/tasks/:taskId` with an exact seven-field contract for title, due time, description, target owner, and expected task timestamp/owner/team snapshots. / 新增任务更新接口，使用精确七字段合同更新标题、截止时间、说明和负责人，并携带预期任务时间戳、负责人及团队快照。
- Organization administrators, the customer owner, or the current task owner may update an open task. The update uses compare-and-swap and commits the task plus bounded `task_updated` activity/audit atomically. / 组织管理员、客户负责人或当前任务负责人可更新待处理任务；更新使用 compare-and-swap，并与有界 `task_updated` 活动/审计原子提交。
- Closed, stale, cross-team, inactive, read-only, null-due-time, and invalid-snapshot requests fail with stable client errors. / 已关闭、陈旧、跨团队、停用、只读、空截止时间及非法快照请求均返回稳定客户端错误。
- The existing customer-detail task cards now show Edit only when allowed. The modal pre-fills all fields, loads candidates, preserves draft input on `409`, refreshes the latest compare-and-swap state, and ignores late refreshes after a newer modal generation. / 现有客户明细任务卡仅在有权时显示编辑；弹窗完整回填并加载候选，`409` 后保留草稿、刷新最新并发状态，且忽略旧代次迟到刷新。
- The customer dashboard/detail split, M3/M4, AI/knowledge, influencer, Feishu, workflow, exports, and frozen PPT were not replaced or expanded. / 客户看板/明细双页面、M3/M4、AI/知识库、网红、飞书、工作流、导出及冻结 PPT 均未替换或扩改。
