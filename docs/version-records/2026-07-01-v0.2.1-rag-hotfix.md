# v0.2.1 RAG Hotfix - Chinese Knowledge Retrieval

Date: 2026-07-01

## Goal

Fix the online RAG retrieval gap found during production smoke testing: long Chinese business questions could return an AI answer without `knowledge_references` because the v1 keyword matcher treated the full sentence as one query term.

## Changes

- Updated `knowledge_service` query term extraction to derive 2-6 character Chinese business keywords from long Chinese questions.
- Added regression coverage: `rag service extracts Chinese business terms from long questions`.
- Kept the fix scoped to retrieval recall; no database schema or API contract changes.
