一功能一上线 / One feature, one release

功能完成后当轮上线，不等待阶段结束，也不等待无关的繁重全量测试。

1 · 单功能One useful slice
2 · 定向测试Affected tests only
3 · 独立审查One reviewer approval
4 · 验证备份Verified rollback point
5 · 立即上线Deploy in same round
6 · 线上冒烟Health, login, feature
执行规则：普通功能只跑受影响测试、必要安全检查和一次独立审查，通过后验证备份并在同一轮立即上线。完整回归仅由阶段收口或 schema、认证/授权、租户权威、共享基础设施、真实外部写入等高风险边界触发；即使触发，也只增加该风险所需门禁。失败的安全门禁、备份和线上验收仍然阻断发布。
