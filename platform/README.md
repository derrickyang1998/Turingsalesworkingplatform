# TuringMarket 商务工作平台 v1.0

> 为商务团队打造的线上工作平台 — 行业智库 + 策略规划 + 方案生成 + 网红匹配

## 快速开始

双击 `index.html` 即可在浏览器中打开完整平台。无需安装任何依赖，纯前端运行。

## 四大功能模块

### 📊 模块一：行业品牌智库

商务在对接客户需求的第一时间，可按行业标签筛选出海品牌案例：

- **行业标签筛选** — 覆盖 3C、储能、智能家居、美妆、户外、宠物、医疗等 12+ 行业
- **品牌详情展示** — 含用户量、年营收预估、海外声量（Amazon评分、社媒粉丝、月搜索量）
- **社媒内容数据** — 月发帖量、互动率、平均观看、主力平台
- **创意拆解** — 脚本创意方向、主推产品清单
- **对比模式** — 多品牌横向对比
- **数据导出** — 一键导出CSV

### 🧠 模块二：客户策略规划

换位思考 — 如果你是客户，希望获得什么：

- **四种客户画像** — 新品牌出海 / 增长期 / 成熟品牌 / 新品上市
- **策略自动推演** — 基于行业+预算+目标生成框架建议
- **商务沟通要点** — 客户在想什么？核心顾虑是什么？
- **行业对标** — 自动匹配内部品牌案例库
- **重点注意事项** — 预算、合规、风险提示

### 📋 模块三：需求接入 & 方案生成

三步走：填写需求 → AI分析 → 自动生成方案：

- **需求表单** — 结构化采集客户信息（品牌、行业、产品、预算、目标、竞品等）
- **AI分析报告** — 下一步工作建议 + 重点注意事项 + 落地建议
- **4套方案模板**：
  1. 全案战略方案（大客户版）— 完整ROI模型+竞品分析+分层红人矩阵
  2. 测试期方案（新品/新市场版）— 验证方向+控制风险
  3. 执行方案（竞标/落地版）— 需求理解+交付保障
  4. 红人专项匹配方案 — 快速匹配推荐
- **一键生成** — 自动填充品牌/产品/市场信息，基于12份历史方案提炼的模板结构
- **导出/复制** — Markdown格式下载，可直接粘贴到飞书文档

### 👥 模块四：网红匹配 & 资源管理

- **批量导入** — 支持 CSV/JSON 格式上传网红数据
- **导入模板** — 提供标准模板下载
- **智能筛选** — 按平台、类别、粉丝量、国家筛选
- **多选导出** — 勾选后导出CSV
- **飞书集成指南** — 含API接入文档指引

## 数据维护

### 添加新品牌

编辑 `data/industry_brands.json`，在 `brands` 数组中添加：

```json
{
  "id": "b013",
  "name": "BrandName",
  "name_cn": "品牌中文名",
  "industry_tags": ["3C", "智能家居"],
  "market": "global",
  "estimated_annual_revenue": "$500M+",
  "user_base": "描述",
  "overseas_presence": { ... },
  "social_content_monthly": { ... },
  "case_study_available": false
}
```

### 更新社媒数据

每月更新 `social_content_monthly` 字段中的 `last_12_months` 数据即可实现"自动更新过去12个月"。

## 飞书集成

### 方案一：CSV导出（推荐起步）
1. 在模块四勾选匹配的网红 → 导出CSV
2. 飞书表格 → 导入CSV文件

### 方案二：飞书API自动化（需开发）
详见模块四中的"飞书集成指南"按钮，包含完整的API接入步骤。
