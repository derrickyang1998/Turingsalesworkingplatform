# Phase 6 管理驾驶舱验收清单

## 验收目标
- 管理控制室首页展示可运营的商务驾驶舱，而不是只有基础用户统计。
- 驾驶舱覆盖客户总数、推进中客户、商机金额、待办完成率、活跃成员、需求数、AI策略/方案、Token消耗。
- 页面展示客户阶段漏斗、商机阶段分布、待办健康度、AI与知识库、团队商务排行、最近平台活动。
- 后端 `/api/admin/overview` 返回完整经营指标，前端只依赖该接口渲染首页。

## 自动化测试
在 `platform` 目录执行：

```bash
node tests/phase6_admin_dashboard_acceptance.js
```

通过标准：
- 管理员可访问 `/api/admin/overview`。
- 接口包含客户、商机、待办、AI产物、知识库、团队排行等字段。
- 浏览器登录后进入管理控制室，指标卡不为空。
- 客户阶段漏斗、待办健康度、AI与知识库、团队排行面板可渲染。
- 浏览器没有前端运行时错误。

## 人工验收
1. 登录管理员账号。
2. 点击左侧“管理控制室”。
3. 确认顶部指标卡显示客户总数、推进中客户、商机金额、待办完成率。
4. 确认第二排指标显示活跃成员、需求数、AI策略/方案、Token消耗。
5. 查看客户阶段漏斗和商机阶段分布，确认每个阶段有数量和金额。
6. 查看待办健康度，确认可看到全部、待处理、已完成、已逾期。
7. 查看 AI 与知识库，确认有知识条目和 AI 产物统计。
8. 查看团队商务排行和最近平台活动。

## 回归范围
- Phase 1 客户主链路仍可用。
- Phase 2 权限边界仍有效。
- Phase 3 AI 产物归档仍可用。
- Phase 4 自动待办仍可生成。
- Phase 5 待办中心仍可筛选、查看详情、打开客户和完成待办。

## 不通过判定
- 管理控制室首页仍只显示基础用户/Token统计。
- 任一核心指标卡显示 `-` 或空白。
- 漏斗、待办健康度、知识库或团队排行任一面板无法渲染。
- `/api/admin/overview` 缺少核心经营字段。
