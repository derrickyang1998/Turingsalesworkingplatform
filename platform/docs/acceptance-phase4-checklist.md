# Phase 4 工作流自动化验收清单

## 验收目标
- 客户阶段变化后，系统自动生成下一步商务跟进待办。
- AI 策略或方案归档后，系统自动生成后续确认/推进待办。
- 待办可在工作流模块查看、打开、完成，并留下日志。
- 管理员可查看所有待办，普通用户只查看自己负责或未分配待办。

## 自动化测试
在 `platform/server` 目录执行：

```bash
node phase4_workflow_automation_test.js
```

通过标准：
- 管理员登录成功。
- 测试客户从 `lead` 更新到 `proposal` 后，出现标题包含 `跟进方案输出` 的待办。
- 归档 `proposal` 类型成果后，接口返回 `task_id`。
- 待办列表中出现标题包含 `确认方案并推进客户反馈` 的待办。
- 调用完成待办接口后，待办详情状态变为 `completed`。

## 人工验收
1. 登录管理员账号，进入客户库。
2. 新建一个测试客户，阶段选择或更新到“方案输出”。
3. 进入工作流/待办列表，确认出现该客户的阶段跟进待办。
4. 从客户详情进入 AI 策略或方案模块，生成内容后点击保存到客户。
5. 回到待办列表，确认出现“确认方案并推进客户反馈”或“基于策略推进下一步”待办。
6. 打开该待办，确认能看到客户业务上下文。
7. 完成该待办，确认状态变为已完成，并有完成日志。

## 回归范围
- Phase 1 主业务链路仍可从客户详情进入品牌智库、AI 策略、需求/方案、达人匹配。
- Phase 2 权限仍满足“我的客户/团队客户/全部客户/公海”边界。
- Phase 3 AI 产物仍能归档到知识库和客户动态。

## 不通过判定
- 阶段变化没有生成待办。
- AI 产物归档成功但没有生成后续待办。
- 普通用户可看到无权限客户的待办。
- 待办完成后状态未更新，或详情页无法读取。
