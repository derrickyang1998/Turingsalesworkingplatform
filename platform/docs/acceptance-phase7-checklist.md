# Phase 7 知识库检索与复用验收清单

## 验收目标
- 历史策略、方案、笔记不只是归档，而是能被新客户策略和方案生成召回。
- 后端提供相似案例检索接口，按品牌、行业、产品、市场、类型返回打分结果。
- AI 策略生成会把相似历史案例加入上下文，并在页面展示参考案例。
- 方案生成会在输出中追加“可复用历史案例”，支持后续复用追踪。
- 点击“标记已复用”会增加知识库条目的 `usage_count`。

## 自动化测试
在 `platform` 目录执行：

```bash
node tests/phase7_knowledge_reuse_acceptance.js
```

通过标准：
- 创建一条测试方案知识库记录。
- `/api/knowledge/similar` 能返回该记录并包含正向匹配分。
- `/api/knowledge/:id/use` 能增加 `usage_count`。
- 浏览器生成方案后，页面显示“本次方案参考的历史案例”。
- 方案输出包含测试历史案例内容。

## 人工验收
1. 在客户详情中保存一份 AI 策略或方案到知识库。
2. 新建或打开相似行业/品牌/市场的客户。
3. 进入“客户策略规划”生成策略，确认输出上方出现历史案例参考。
4. 进入“需求接入 & 方案生成”生成方案，确认方案包含“可复用历史案例”。
5. 点击历史案例的“标记已复用”，确认没有报错。
6. 管理控制室的 AI 与知识库统计应继续正常显示。

## 回归范围
- Phase 1 客户主链路仍可用。
- Phase 2 权限边界仍有效。
- Phase 3 AI 产物归档仍可用。
- Phase 4 自动待办仍可生成。
- Phase 5 待办中心仍可用。
- Phase 6 管理驾驶舱仍可用。

## 不通过判定
- 相似案例接口返回空或没有匹配分。
- 策略或方案生成完全没有展示历史案例。
- 复用按钮不能更新 `usage_count`。
- 新功能导致既有 Phase 1-6 验收失败。
