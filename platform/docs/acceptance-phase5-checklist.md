# Phase 5 待办中心产品化验收清单

## 验收目标
- 侧边栏“我的待办”进入正式待办中心，而不是空白页面。
- 待办支持按状态、业务类型、逾期、关键词筛选。
- 待办卡片展示业务类型、业务 ID、流程、截止时间、状态和描述。
- 待办详情可查看客户上下文、处理日志和业务记录。
- 客户类待办可以一键打开客户详情。
- 待办可在页面内完成、批准或驳回，完成后列表状态刷新。

## 自动化测试
在 `platform` 目录执行：

```bash
node tests/phase5_tasks_ui_acceptance.js
```

通过标准：
- 测试脚本通过 API 创建客户并触发自动待办。
- 浏览器登录后进入“商务待办中心”。
- 使用关键词和状态筛选能定位测试待办。
- 待办详情包含测试客户上下文。
- “打开客户”能跳转客户库并打开客户详情。
- 页面内完成待办后，已完成筛选可看到对应记录。

## 人工验收
1. 登录平台后点击左侧“我的待办”。
2. 确认页面顶部有当前结果、待处理、已逾期、已完成统计。
3. 使用状态、业务类型、逾期和关键词筛选，确认列表正确刷新。
4. 点击任意客户类待办的“详情”，确认弹窗显示业务记录和日志。
5. 点击“打开客户”，确认跳转客户库并打开对应客户详情。
6. 输入处理备注并点击“完成”，确认待办状态变为已完成。
7. 管理员账号应能看到全部待办，普通账号只能看到自己负责或未分配待办。

## 回归范围
- Phase 1 客户主链路仍可从客户详情进入品牌、策略、方案、达人模块。
- Phase 2 客户权限边界仍有效。
- Phase 3 AI 策略/方案仍能归档。
- Phase 4 阶段变化和 AI 产物归档仍能自动生成待办。

## 不通过判定
- 点击“我的待办”后页面空白。
- 筛选条件无效或筛选后统计不刷新。
- 待办详情无法打开或缺少客户上下文。
- 客户跳转失败。
- 页面完成待办后状态没有变化。
